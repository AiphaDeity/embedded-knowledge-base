## 一、Linux 基础概念与环境搭建（对应 1.1 / 1.2）

### 基础概念题

1. 简述 Linux 操作系统的核心特点，以及嵌入式领域选择 Linux 作为系统的主要优势。

3. 解释内核与 Shell 的定义，说明二者的层级关系。
4. 虚拟机三种网络模式（桥接、NAT、仅主机）的核心区别与适用场景。
5. 简述 Linux 目录树结构，分别说明 `/root` `/home` `/etc` `/bin` `/usr` `/dev` `/proc` 目录的作用。

### 实操题

1. 配置虚拟机网络，实现 Windows 主机与 Linux 虚拟机双向 ping 通。
2. 配置共享文件夹，实现主机与虚拟机的文件互传。
3. 更换国内软件源，完成系统软件包的更新与升级。

1. 说明以下命令的核心作用：`ls` `cd` `pwd` `mkdir` `rm` `cp` `mv` `cat` `less` `tail`
2. 软链接与硬链接的本质区别是什么？分别用什么命令创建？
3. `chmod` 修改权限的两种方式（符号法、数字法），举例说明如何给文件添加所有者可执行权限。
4. `chown` 与 `chgrp` 命令的作用分别是什么？
5. `ps` `top` `kill` 的作用分别是什么？如何强制终止指定进程？
6. `find` 与 `grep` 的核心区别是什么？各自适用什么场景？
7. 管道符 `|` 的作用是什么？举一个实际开发中的使用例子。
8. 重定向 `>` 与 `>>` 的区别是什么？
9. `tar` 打包压缩的常用参数 `-c` `-x` `-z` `-v` `-f` 分别代表什么？
10. `df` `du` `free` 三条命令分别用于查看什么系统信息？

### 实操题

1. 在当前目录下创建多级目录 `project/src/inc`，并在 inc 目录下创建 `func.h` 文件。
2. 递归复制目录 `project` 为 `project_bak`，并删除原目录。
3. 用数字法将 `test.c` 权限设置为：所有者读写执行、同组读写、其他用户只读。
4. 查找 `/usr` 目录下所有后缀为 `.h` 的头文件。
5. 在当前目录所有 `.c` 文件中，查找包含 `main` 字符串的行并显示行号。
6. 将当前目录下所有 `.c` 和 `.h` 文件打包压缩为 `code.tar.gz`。
7. 解压 `code.tar.gz` 到指定目录 `/opt/arm_project`。
8. 查看系统所有运行进程，找到名为 `test_app` 的 PID 并强制终止。
9. 实时查看日志文件 `uart.log` 的末尾新增内容。
10. 用管道符统计当前目录下 `.c` 文件的总个数。

## 四、gcc 编译与 gdb 调试（对应 1.5，嵌入式核心）

### 基础概念题

1. 简述 gcc 编译 C 程序的四个阶段（预处理→编译→汇编→链接），说明每个阶段的输入输出与对应 gcc 参数。
2. 解释 gcc 常用参数的作用：`-o` `-c` `-g` `-Wall` `-I` `-L` `-l` `-O`
3. 什么是交叉编译？嵌入式开发为什么必须使用交叉编译工具链？
4. 静态库与动态库的核心区别是什么？分别如何用 gcc 生成？

### 实操题

1. 单步编译 HelloWorld 程序，分别生成预处理文件 `.i`、汇编文件 `.s`、目标文件 `.o`、最终可执行文件。
2. 多文件工程（`main.c` `func.c` `func.h`），用 gcc 直接编译生成可执行程序。
3. 将功能函数封装为静态库 `libfunc.a`，并链接到主程序生成可执行文件。
4. 用 gdb 调试程序：设置断点、运行到断点、查看变量值、单步执行、查看函数调用栈、退出调试。
5. 编写一个存在段错误的程序，用 gdb 定位出错的具体行号与原因。

5. 用 gdb 定位并修复一个模拟的嵌入式串口程序段错误。

## 核心通用模板

1. gcc 编译模板：`gcc 源文件 -o 目标文件 -I头文件路径 -L库路径 -l库名`
2. Makefile 通用框架：变量定义 + 模式规则 + 链接生成目标 + clean 伪目标
3. Shell 循环模板：`for 变量 in 集合; do 操作; done`
4. 查找过滤组合模板：`find 路径 条件 | xargs grep 关键字`
