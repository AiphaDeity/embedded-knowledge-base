## 模块一 Linux IO 编程（标准 IO + 文件 IO）

### 一、标准 IO 基础编程

1. 使用 `fopen/fputs/fgets` 实现：创建文本文件，写入字符串 `"Embedded Linux Config"`，再读取文件内容打印到终端。
2. 编写程序，统计任意文本文件中字母、数字、空格、其他字符的数量，全部使用标准 IO 函数实现。
3. 用 `fseek` 实现：打开二进制文件，读取从第 10 个字节开始的 20 个字节，以十六进制格式打印。
4. 逐行读取配置文件，为每一行添加行号后输出，格式为 `[行号] 内容`。
5. 实现一个简单的文件追加程序：每次运行都向指定日志文件末尾追加一行内容，不覆盖原有数据。

### 二、文件 IO 系统调用编程

1. 用 `open/read/write/close` 系统调用实现文件拷贝功能，将源文件完整复制到目标文件，支持二进制文件。
2. 编写程序：打开指定文件，在文件末尾追加写入 `"append test data"`，读取验证写入结果。
3. 仅通过 `lseek` 指针移动计算文件总大小，不读取文件全部内容。
4. 实现文件清空功能：将指定文件的内容全部清空，文件长度置为 0。
5. 用文件 IO 实现：创建一个设备节点风格的测试文件，写入固定长度的结构体数据，再读取解析出来。

### 三、进阶综合实战

1. 模拟 `ls` 命令基础功能：遍历指定目录，打印目录下所有普通文件、目录文件的名称，对应课程 2.9。
2. 嵌入式配置文件解析：解析 `key=value` 格式的配置文件，实现「根据 key 查询 value」的功能，支持注释行忽略。
3. 循环日志写入程序：每次运行向日志文件追加一行带时间戳的日志，格式为 `[YYYY-MM-DD HH:MM:SS] 日志内容`。
4. 递归统计目录总大小：遍历指定目录及其所有子目录，统计所有普通文件的总字节数。
5. 实现简单的 INI 配置文件读写：支持读取、修改、保存指定 section 下的键值对。

### 四、库制作编程

1. 将自定义实现的 `my_strlen / my_strcpy / my_strcmp` 字符串函数封装为静态库，编写主程序链接调用并验证功能。
2. 将上述字符串函数封装为动态库，编写主程序运行时动态加载调用。
3. 封装通用环形缓冲区库（数组实现），支持入队、出队、判空、判满、获取有效长度，打包为静态库，提供头文件供其他工程调用。
4. 封装通用 CRC8/CRC16 校验函数库，打包为静态库，用于通信协议数据校验。

## 模块二 Linux 多进程多线程编程

### 一、多进程基础编程

1. 用 `fork` 创建子进程：父进程打印 `"parent process, pid=%d"`，子进程打印 `"child process, pid=%d"`，分别输出各自 PID 与父 PID。
2. 父进程创建 2 个子进程：子进程 1 执行 `ls -l` 命令，子进程 2 执行 `pwd` 命令；父进程等待所有子进程退出后再结束。
3. 用 `execvp` 执行系统命令：程序接收命令行参数，调用 exec 族函数执行对应的系统命令。
4. 实现守护进程：将程序改造为后台守护进程，每隔 1 秒向 `/var/log/heartbeat.log` 写入一条心跳日志。
5. 编写程序：子进程异常退出时，父进程通过信号捕捉到子进程退出状态，并打印退出原因。

### 二、进程间通信编程

1. 管道：父进程写入字符串 `"hello child process"`，子进程读取该字符串并打印。
2. 命名管道（FIFO）：两个独立进程，进程 A 向 FIFO 写入数据，进程 B 从 FIFO 读取并打印。
3. 消息队列：进程 A 发送包含「设备 ID、温度值」的结构体消息，进程 B 接收消息并解析打印。
4. 共享内存：进程 A 向共享内存写入 10 个整数，进程 B 读取后计算求和并打印结果。
5. 信号量 + 共享内存：用信号量实现共享内存的互斥访问，保证同一时间只有一个进程修改共享内存数据。
6. 信号：进程 A 向指定 PID 的进程 B 发送 `SIGUSR1` 自定义信号，进程 B 捕捉信号后打印 `"收到设备控制信号"`。

### 三、多线程基础编程

1. 创建 2 个子线程：线程 1 循环打印 `"thread 1 running"`，线程 2 循环打印 `"thread 2 running"`，主线程等待两个线程全部结束。
2. 创建 5 个线程，每个线程对同一个全局变量累加 10000 次，复现无互斥锁时的数据异常问题。
3. 线程传参：主线程向子线程传入结构体（包含设备 ID、设备名称、状态），子线程打印结构体全部内容。
4. 实现线程分离：创建子线程并设置为分离状态，子线程执行完自动回收资源，主线程无需 `pthread_join` 等待。
5. 编写线程终止程序：主线程可向子线程发送取消请求，子线程在指定取消点退出。

### 四、线程互斥与同步编程

1. 用互斥锁修复上述多线程累加问题，保证最终计算结果正确。
2. 生产者 - 消费者模型（条件变量版）：用互斥锁 + 条件变量实现，生产者线程往环形缓冲区放数据，消费者线程取数据；缓冲区满时生产者阻塞，缓冲区空时消费者阻塞。
3. 生产者 - 消费者模型（信号量版）：用信号量实现上述功能，对比条件变量实现的差异。
4. 读写锁实现：模拟嵌入式参数配置场景，1 个写线程修改参数，5 个读线程读取参数，实现读共享、写互斥。
5. 实现线程池基础框架：固定数量的工作线程 + 任务队列，主线程往队列投递任务，工作线程依次取出执行。

## 模块三 Linux 网络编程

### 一、TCP 通信编程

1. TCP 回显服务器 / 客户端：客户端发送任意字符串，服务器原封不动返回给客户端，客户端打印回显结果。
2. TCP 文件传输：客户端向服务器发送本地文件，服务器接收后保存到指定路径，传输完成后双方校验文件大小。
3. 多进程 TCP 服务器：服务器端每收到一个客户端连接，就 fork 一个子进程处理该客户端的通信，支持多客户端同时接入。
4. TCP 心跳检测：客户端每隔 3 秒向服务器发送心跳包，服务器超时 5 秒未收到心跳则判定设备离线，断开对应连接并打印离线提示（嵌入式设备在线状态检测标准场景）。
5. 自定义协议 TCP 通信：设计帧格式 `帧头(2字节) + 长度(1字节) + 数据 + CRC8校验(1字节)`，实现完整的收发逻辑，解决 TCP 粘包问题。

### 二、UDP 通信编程

1. UDP 回显服务器 / 客户端：客户端发送数据，服务器收到后原封不动发回客户端。
2. UDP 广播设备发现：客户端向局域网广播设备发现报文，服务器收到后回复自身的设备 ID、IP 地址、型号（嵌入式局域网设备自动发现标准场景）。
3. 传感器数据上报：模拟温湿度传感器节点，每隔 1 秒通过 UDP 向服务器上报温度、湿度数据；服务器接收后打印设备 ID 与数据。
4. UDP 组播通信：多个客户端加入同一个组播组，服务器向组播地址发送数据，所有客户端都能收到。

### 三、IO 模型与并发服务器

1. select 实现多路复用服务器：单线程用 select 管理多个客户端连接，同时处理所有客户端的收发请求。
2. poll 实现并发 TCP 服务器：用 poll 重构上述多路复用服务器，对比 select 的优缺点。
3. epoll 水平触发服务器：用 epoll 实现高并发 TCP 服务器，支持数十个客户端同时接入。
4. epoll 边缘触发服务器：将上述服务器改为边缘触发模式，对比水平触发的差异与注意事项。
5. 简易 Reactor 模型：基于 epoll 封装事件回调机制，客户端连接、数据到来、断开事件均通过回调函数处理。

### 四、协议实战编程

1. TFTP 客户端实现：基于 UDP 实现 TFTP 协议客户端，支持从 TFTP 服务器下载文件，对应课程 4.6。
2. 简易 HTTP 客户端：实现 GET 请求，向指定 HTTP 服务器获取数据，可用于物联网设备简单上报。
3. 简易 MQTT 客户端：连接公共 MQTT 服务器，实现主题订阅与消息发布，模拟物联网设备数据上报。

## 模块四 Linux 驱动基础编程

### 一、内核模块基础

1. 编写最简内核模块：加载时打印 `"Hello Embedded Driver"`，卸载时打印 `"Goodbye Driver"`。
2. 带参数的内核模块：传入一个整数类型的模块参数 `device_id`，模块加载时打印该设备 ID 的值。
3. 编写内核模块，验证内核空间的打印、延时、内存分配函数，测试 `kmalloc/kfree`、`mdelay` 等基础内核 API。

### 二、字符设备驱动

1. 编写基础字符设备驱动：自动分配设备号，实现 `open/read/write/release` 四个接口，应用层程序可通过设备节点读写数据。
2. 内核环形缓冲区驱动：在驱动内部实现环形缓冲区，应用层 `write` 写入数据、`read` 读取数据，缓冲区满时写入阻塞。
3. ioctl 控制驱动：扩展字符设备驱动，支持多条 ioctl 命令，应用层可通过 ioctl 设置、读取驱动内部的配置参数。
4. 自动创建设备节点：在驱动中实现 `class/device` 创建，加载模块后自动在 `/dev` 下生成设备节点，无需手动 mknod。

### 三、硬件驱动入门（嵌入式核心）

1. LED 字符设备驱动：基于设备树编写 GPIO 驱动，应用层向设备节点写入 `0/1` 即可控制 LED 亮灭。
2. 按键中断驱动：编写按键输入驱动，采用中断方式检测按键按下，应用层 `read` 阻塞等待按键事件，按下后返回键值。
3. 通用 GPIO 驱动：实现应用层可配置 GPIO 方向、设置电平、读取电平的字符设备驱动，支持指定 GPIO 编号。
4. 定时器驱动：在内核中使用内核定时器，每隔 1 秒翻转一次 LED 电平，实现 LED 闪烁效果。
