# 嵌入式方向 C 语言练习题全集（可保存版）

[飞书原文](https://hcn4ticlccda.feishu.cn/docx/TJLgdwKhToKoKvxOHKxc4pSpnnZ)

按「入门→基础→核心→进阶→工程」分层排列，完全对应之前讲的 L1\~L3 能力标准，覆盖期末、计算机二级、嵌入式笔试、工作刚需场景。

---

## 一、基础语法与循环（L1 入门级）

考察分支、循环、基础逻辑思维，C 语言入门必练

1. 输入年份，判断是否为闰年
2. 输入整数 n，计算 1\~n 的累加和、n 的阶乘
3. 打印九九乘法表
4. 打印金字塔、菱形、空心矩形等字符图形
5. 判断一个整数是否为素数；输出指定区间内的所有素数
6. 输入两个正整数，求最大公约数（GCD）、最小公倍数（LCM）
7. 输出三位数中的所有水仙花数
8. 输入一个正整数，逆序输出其各位数字
9. 输入十进制整数，手动转换为二进制 / 八进制 / 十六进制输出（禁止调用库函数）
10. 猜数字游戏：系统生成随机数，用户输入猜测，提示偏大 / 偏小，直到猜对
11. 分段函数计算：根据输入的 x，按对应公式输出 y 值

---

## 二、数组专题（L1→L2 过渡）

考察连续内存访问、下标逻辑，是嵌入式缓存、寄存器操作的基础

### 一维数组

1. 输入一组整数，求最大值、最小值、平均值、总和
2. 实现冒泡排序、选择排序、插入排序
3. 在有序数组中实现二分查找
4. 数组去重：去除重复元素，输出去重后的结果
5. 数组奇偶分离：将奇数移到数组左侧，偶数移到右侧

### 二维数组

1. 遍历二维矩阵，分别计算每行、每列的和
2. 实现二维矩阵的转置
3. 固定长度循环缓存：新数据自动覆盖最旧数据，模拟硬件环形缓冲区

---

## 三、字符串专题（L2 应用级，嵌入式串口 / 协议核心）

考察 `\0` 结束符本质与字符串底层操作，全部要求禁止调用 `<string.h>` 库函数

1. 自定义实现 `strlen`：计算字符串长度
2. 自定义实现 `strcpy`：字符串拷贝
3. 自定义实现 `strcat`：字符串拼接
4. 自定义实现 `strcmp`：字符串大小比较
5. 字符串反转：输入字符串，逆序输出
6. 判断输入字符串是否为回文字符串
7. 字符串大小写转换：全转大写 / 全转小写
8. 数字频次统计：输入正整数，统计 0\~9 每个数字的出现次数
9. 字符频次统计：输入字符串，统计每个字符的出现次数，区分大小写 

   - 基础版：按 ASCII 码从小到大输出
   - 进阶版：按字符在原字符串中首次出现的顺序输出
10. 统计字符串中字母、数字、空格、其他符号的数量
11. 去除字符串中的所有空格
12. 数字字符串与整数互相转换（串口收发数据必备）
13. 字符串去重输出：每个字符只打印一次
14. 在字符串中查找指定字符 / 子串首次出现的位置

---

## 四、指针专题（L2 熟练级，嵌入式灵魂）

考察地址、解引用、内存操作，是寄存器访问、函数传参、回调机制的核心

1. 用指针实现：交换两个 int 变量的值（可扩展为不借助第三方变量的异或写法）
2. 用指针遍历一维数组、字符串，实现求和 / 求长度
3. 指针作为函数形参，修改主函数中变量的值
4. 区分字符指针 `char *` 与字符数组，理解常量字符串 `const char *` 的特性
5. 区分指针数组、数组指针，分别写出定义与适用场景
6. 函数指针基础：定义函数指针，实现简单的回调函数
7. 理解 `const` 修饰指针的三种形式：常量指针、指针常量、常量指针常量，区分用法
8. 用指针实现字符串拷贝、比较、反转，全程不使用数组下标 `[]`

---

## 五、位运算专题（L2 熟练级，寄存器操作重中之重）

考察硬件寄存器底层操作，嵌入式开发日常高频使用

1. 对一个整数的第 n 位，分别实现：置 1、清 0、翻转、读取位值
2. 用异或运算实现两个整数的交换（不借助第三方变量）
3. 统计一个整数二进制表示中 1 的个数
4. 拆分一个 16 位整数的高 8 位与低 8 位
5. 实现 16 位整数的高低字节互换
6. 用共用体 + 位运算判断系统的大小端模式
7. 封装寄存器操作宏：SET_BIT、CLEAR_BIT、READ_BIT（工业级工程标准写法）
8. 用位运算快速判断整数的奇偶性

---

## 六、结构体、枚举、共用体（L2→L3 工程级）

考察数据封装、协议解析、寄存器映射，是嵌入式工程代码的核心结构

1. 定义学生 / 设备参数结构体，实现结构体数组的录入、排序、查找
2. 用结构体指针做函数参数，对比值传递与地址传递的性能与区别
3. 用枚举 `enum` 定义设备状态、错误码、工作模式
4. 用共用体 `union` 实现：一个 32 位整数拆分为 4 个字节独立访问
5. 用位域定义寄存器结构体，映射外设寄存器的每一位功能
6. 手动计算结构体的内存大小，理解内存对齐规则与优化方法

---

## 七、递归专题（L2→L3 进阶）

考察分层逻辑、回溯思想，常用于协议解析、树状设备结构遍历

1. 递归实现阶乘、斐波那契数列
2. 递归实现字符串反转
3. 递归实现有序数组的二分查找
4. 递归实现整数的进制转换
5. 递归遍历简单二叉树的前 / 中 / 后序（设备层级管理基础）

---

## 八、内存管理专题（L3 精通级）

考察内存模型、动态分配，是 RTOS、复杂项目开发的必备知识

1. 用 `malloc` / `free` 动态创建一维数组、二维数组
2. 验证栈内存、堆内存、静态存储区的地址分布与生命周期差异
3. `static` 修饰局部变量、全局变量、函数的作用与区别
4. 分析野指针、数组越界、内存泄漏的常见场景与规避方法
5. 理解内存碎片产生的原因，掌握基础优化思路

---

## 九、工程化与多文件开发（L3 精通级）

考察模块化、可维护性，企业项目的标准开发规范

1. 将一个完整功能拆分为 `.h` 头文件 + `.c` 源文件，在主函数中调用
2. 编写头文件保护（条件编译），防止头文件重复包含
3. 封装宏常量、宏函数，对比宏函数与普通函数的差异
4. 设计统一错误码，函数通过返回值返回执行状态
5. 分层设计：将驱动层、业务层、应用层拆分，实现代码解耦

---

## 十、嵌入式高频工程实战题（L2→L3，工作直接复用）

考察真实工作场景组件，笔试面试高频手撕题

1. 实现环形缓冲区（FIFO）：支持入队、出队、判空、判满（串口 / ADC 缓存必备）
2. 用 switch-case 实现通用状态机框架（按键消抖、协议解析通用）
3. 实现 8 位 / 16 位校验和计算、简单 CRC 校验（通信数据校验）
4. 封装简易日志打印函数，支持不同等级日志输出
5. 实现大小端数据转换函数，适配跨设备通信
6. 无 FPU 单片机适配：浮点数转定点数运算，实现基础加减乘

---

## 通用核心解题模板（一类题通杀）

1. 计数数组模板：用数值本身作为数组下标统计次数 

   - 数字统计：数组长度 10，下标 0\~9 对应数字 0\~9
   - 字符统计：数组长度 256，下标对应字符 ASCII 码
2. 逐位拆解模板：`%10` 取个位、`/10` 去掉个位，循环拆解整数
3. 指针遍历模板：指针自增 + `\0` 判断，遍历字符串 / 连续内存
4. 位操作模板：与清位、或置位、异或翻转、移位对齐
