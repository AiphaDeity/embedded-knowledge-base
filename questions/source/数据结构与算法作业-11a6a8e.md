# 顺序表和链表的区别

顺序表是将数据按照逻辑顺序依次存储在连续空间内的数据结构。

链表是通过指针链接每一个元素的存储在不连续的空间的数据结构。

# 栈和队列的区别？

栈是后进先出，栈只能从一端进行插入和删除，栈的访问只能访问栈顶，要想访问栈顶下面的必须先弹出。

队列是先进先出，队列可以从一端插入，另一端删除，队列可以从队头到队尾进行遍历。

# 什么叫内存泄漏？怎么避免？

内存泄漏就是程序运行期间程序员手动申请的内存没有及时释放。通过申请和释放成对出现，在释放后立即置空，在使用前进行检查

# 什么叫段错误？怎么解决？

访问了不该访问的内存空间，严禁解引用空指针，野指针，返回局部变量的地址，堆栈溢出，访问数组越界。在使用前进行检查，在出现后进行gdb调试

# malloc、calloc和realloc区别？

mallco，申请一段内存空间，需要手动清零

calloc是申请一段内存空间并初始化全部清零

relloc是扩容，它是保留原本的数据，判断当前位置的内存空间够不够，够的话在原来的位置扩容，不够的话找一个新的地方，将原来的数据放在新内存空间

# 完全二叉树？满二叉树？

完全二叉树深度为k的二叉树，k-1层是满的，k层是从左到右依次排序的且没有空白

满二叉树是一种二叉树，每个层都有2的i-1次方个节点，除了叶子节点（终端节点）之外，每个节点都有两个子节点，深度为k的二叉树总共有2的K次方-1个节点

# 非递归如何实现二叉树的前序遍历？

先序遍历的要求是根左右，因此就必须先处理完整个左子树，才能处理右子树。然后根据栈的后进先出，就应该

先压根 → 栈中有根，弹出根并访问 → 栈空。再压右、压左（先右后左） → 此时栈顶是左，下一次循环“弹左” → 访问左，然后继续压左的右、左……。

# 冒泡排序的思想？

从无序数组的首元素开始，然后把首元素和第二个元素进行比较，如果首元素小于第二个，则不动，如果首元素大于第二个，则交换数值，然后再与下一个元素进行比较，第一轮得到的最后一个元素就是最大值，然后定为有序区固定不变，再进行下一轮从头开始，直至整个数组有序。

# 简单选择排序的思想？

简单选择排序的思想：把一个无序数组，假设第一个位置是最小值，然后找到这个数组的最小值，判断是否和第一个位置的相等，如果相等就直接进行下一轮，这时第一个位置就是有序区。然后再找出无序区最小的元素，与无序区的第一个元素交换。重复直到有序。

# 说下二分查找？

二分查找是有序数组的查找算法，每次查找中间的元素，如果目标值小于中间的元素，则在左边查找，同样按照目标值比较中间值的。如果目标值大于中间的元素，就去右边查找，再对比中间值。直到找到目标值或者范围为空。

# 哈希表为什么查找效率高？

因为哈希表是直接地址映射，通过哈希函数直接计算它在数组的位置。平均情况下只需要进行一次计算哈希值，就能直接访问该位置，平均时间复杂度能到O（1）。

# 快速排序思想？

对于一个数组，取数组的第一个元素作为枢轴（基准）。然后定义两个指针，代表小于枢轴的数的指针放在最左边，代表大的放在最右边。然后从右开始扫描，大于基准的放在右边，然后右指针减一，然后判断右指针指向的值是否大于枢轴，大于的话就不动，右指针再减一，再继续判断右指针指向的值，小于基准的话放在左指针的位置，左指针加一，然后判断左指针的值，重复进行。直到两个指针同时指向时，放入基准值，进入下一轮，对把左指针指向枢轴最左边，把右指针指向枢轴减一的位置，再以第一个元素为枢轴重复。然后再左往右重复。

# 时间复杂度什么作用？

本质是程序执行的次数，通过时间复杂度来判断一个程序的效率，时间复杂度越接近一个常数，执行效率就越高，这个程序的占用时间就越少

时间复杂曲线图就是输入规模n为横坐标，基本操作执行次数f(n)为纵坐标的函数图像。可以直观的查看不同时间复杂度的差异。

# 数据结构在学什么？

数据结构在学如何最短时间，最小内存，最适合当前功能的程序，当然是建立安全和稳定的基础上。

在学如何选择合适的数据存储结构和如何查找，删除，增加，改变数据的操作。本质还是对数据更好的管理

# 二叉树的遍历？

二叉树可以分为深度优先遍历（DFS）：先序遍历（根左右），中序遍历（左根右），后序遍历（左右根）。

还可以分为广度优先遍历（BFS）：层序遍历从上到下

while(curr) //循环只要不指向空

# 直接插入排序的思想？ 

给定一个数组，把数组分为有序区和无序区

把数组的第一个元素作为有序区，剩下的元素作为无序区

然后把无序区的第一个元素和有序区的元素从后往前依次比较

大于的话直接插入在有序区的后面，小于的话把有序区的元素后移。然后重复上面的动作

# 内部排序和外部排序？

内部排序是将待排序的数据一次性放在内存中排序完。

外部排序是待排序的数据一次性在内存中处理不完，要借助外存存储中间的结果。

# 排序算法的稳定性？哪些是稳定的？

排序算法的稳定性指的是：在待排序的序列中，如果存在两个相等的元素（不论是值相等还是其他的），排序后它们的相对前后顺序保持不变，则该排序算法是稳定的；否则是不稳定的

稳定的是插入排序和冒泡排序

不稳定的是快速排序和简单选择排序

# 如何将两个有序的单链表合并成一个有序的单链表？

就是有二个链表L1，L2

创建一个虚拟节点，再创建一个指针指向虚拟节点，然后同时遍历两个链表，当L1的节点小于等于L2的节点，就让这个指针的next指向这个节点（尾插法，始终指向最后一个节点），每次找到一个小的节点然后移动指针，直到一个链表为空，最后指向不为空的链表。
