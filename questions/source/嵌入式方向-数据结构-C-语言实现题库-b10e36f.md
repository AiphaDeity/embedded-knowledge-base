# 嵌入式方向 数据结构 C 语言实现题库

[飞书原文](https://hcn4ticlccda.feishu.cn/docx/ELusdn7jGogoepx67tRcZ53vndf)

这份题库完全贴合嵌入式开发实际需求，以「工程实用、笔试高频」为核心，不包含竞赛向的复杂图论、动态规划等高难度内容，重点覆盖单片机 / RTOS 开发中最常用的线性结构、缓存、查找排序，与前面的 C 语言能力层级无缝衔接：L2 对应基础题，L3 对应进阶题。

---

## 一、线性表：数组与链表（嵌入式核心基础）

考察指针操作、动态内存、边界条件处理，是设备管理、动态节点、数据缓存的底层支撑。

### 基础必做题（L2 入职达标）

1. 顺序表（数组实现）：实现动态数组的初始化、尾部插入、指定位置插入、按位置删除、按值查找、遍历打印、内存销毁。
2. 单链表（带头节点）：实现单链表的创建、尾插法、头插法、遍历打印、计算链表长度。
3. 单链表节点操作：按位置查找节点、按值查找节点、在指定位置插入节点、删除指定位置节点。
4. 单链表基础进阶：反转整个单链表、删除链表中所有值等于 x 的节点。
5. 双向链表：实现双向链表的创建、节点插入、节点删除、正向遍历、反向遍历。

### 进阶选做题（L3 笔试高频）

1. 判断单链表是否有环；若有环，找到环的入口节点。
2. 查找单链表的倒数第 k 个节点，要求只能遍历一次链表。
3. 合并两个有序的单链表，合并后链表依然保持有序。
4. 删除有序单链表中的重复节点，每个值只保留一个。
5. 循环单链表：实现循环链表的插入、删除、遍历。
6. 双向循环链表的基础增删改查操作。

## 二、栈与队列（嵌入式缓存、中断处理核心）

重点掌握环形队列，是串口、ADC、按键、日志缓存的标准实现方案，嵌入式开发最高频。

### 基础必做题（L2 入职达标）

1. 顺序栈（数组实现）：完成初始化、入栈、出栈、获取栈顶元素、判空、判满。
2. 链栈（单链表实现）：完成初始化、入栈、出栈、判空、内存销毁。
3. 普通顺序队列：完成初始化、入队、出队、判空、判满。
4. 环形队列（循环队列）：数组实现，支持入队、出队、判空、判满、获取有效元素个数（嵌入式必背模板）。

### 进阶选做题（L3）

1. 用两个栈实现一个队列的全部功能。
2. 用两个队列实现一个栈的全部功能。
3. 链式队列：用单链表实现队列，支持无限动态扩容。
4. 栈的应用：括号匹配校验，输入包含`{}`的字符串，判断括号是否合法闭合。
5. 环形缓冲区进阶：支持覆盖旧数据模式，队列满时新数据自动丢弃最旧数据。

## 三、查找与排序（传感器数据处理核心）

嵌入式日常数据处理、参数检索的核心能力，重点掌握二分查找与基础排序算法。

### 查找专题

#### 基础必做（L2）

1. 顺序查找：在无序数组中查找指定值，找到返回下标，未找到返回 - 1。
2. 二分查找（非递归实现）：在有序数组中查找指定值，返回对应下标。
3. 二分查找（递归实现）。

#### 进阶选做（L3）

1. 二分查找变种：查找有序数组中第一个等于目标值的元素下标。
2. 二分查找变种：查找有序数组中最后一个等于目标值的元素下标。
3. 二分查找变种：查找有序数组中第一个大于等于目标值的元素下标。

### 排序专题

#### 基础必做（L2）

1. 冒泡排序（优化版：增加有序标志位，数组已有序则提前退出）。
2. 选择排序。
3. 直接插入排序。
4. 能口述分析三种排序的时间复杂度、空间复杂度、稳定性。

#### 进阶选做（L3）

1. 快速排序（递归实现，掌握分区核心思想）。
2. 归并排序。
3. 通用排序函数：支持任意类型数组排序，通过函数指针自定义比较规则。

## 四、树与哈希表（进阶工程能力）

用于设备层级管理、配置参数快速检索，嵌入式进阶开发必备，不用深入复杂平衡树。

### 基础必做（L3 入门）

1. 定义二叉树结构体，实现前序、中序、后序遍历（递归实现）。
2. 二叉树层序遍历，借助队列实现逐层打印。
3. 计算二叉树的总节点数、叶子节点数、树的深度。
4. 简单哈希表：用「数组 + 链表」链地址法实现，支持插入、查找、删除，解决哈希冲突。

### 进阶选做（L3）

1. 二叉树前序、中序、后序遍历的非递归实现。
2. 二叉搜索树（BST）：实现节点插入、按值查找、节点删除。
3. 哈希表进阶：设计字符串哈希函数，实现字符串键值对的快速查找。

## 五、嵌入式场景综合实战题（工作直接复用）

完全贴合真实开发场景，写完可直接放进自己的项目代码库，也是面试手撕高频题。

1. 串口环形 FIFO 缓冲区：封装为独立模块（.h + .c），支持中断中入队、主循环出队，适配串口数据不丢包场景。
2. 设备链表管理：用单链表管理外设节点，节点包含设备 ID、名称、运行状态，支持设备添加、删除、按 ID 查找、遍历在线设备。
3. 按键事件队列：用队列存储按键触发事件，主循环循环取出事件处理，实现按键按下不丢事件、异步处理。
4. 有序参数快速检索：设备配置参数按 ID 有序存储，用二分查找快速读取指定 ID 的配置项。
5. 日志环形缓存：实现固定大小的日志缓冲区，新日志自动覆盖最旧日志，支持批量读取历史日志。

## 核心解题模板（一类题通杀）

1. 链表操作模板：统一用带头节点实现，简化头插、头删的边界判断；操作节点先找前驱节点。
2. 环形队列模板：用「读指针 + 写指针 + 数组」实现，空满判断用预留空位或计数变量两种方案。
3. 二分查找模板：闭区间写法 `left=0, right=len-1`，循环条件 `while(left <= right)`，边界移动清晰可控。
4. 递归模板：先写终止条件，再写递归子问题，避免无限递归与栈溢出。
