# 11、指针数组 与 数组指针的区别，并举例说明

指针数组：一个数组，其元素类型是指针

数组指针：指向数组的指针

```c
int a = 10, b = 20, c = 30;// 指针数组：包含3个 int* 类型的指针
int *ptrArr[3] = { &a, &b, &c };  // 数组元素是指针，分别指向 a、b、c

int arr[5] = {1, 2, 3, 4, 5};// 先定义一个普通数组
int (*arrPtr)[5] = &arr; // 数组指针：指向含5个int元素的数组的指针
```

# 12、指针函数 与 函数指针的区别，并举例说明

指针函数：返回类型是指针类型的函数

函数指针：指向函数的指针

```c
void* func(int a, int b, int *res)//指针函数
{
    *res = a + b;
}

int add（int a,int b）//函数指针
{
    return a + b;
}
int (*p)(int ,int) = add;
```

# 13、指针常量 与 常量指针的区别，并举例说明

常量指针：指向常量的指针，值不能改，指向可以改

指针常量：指针是常量，值可以改，指向不能改

```c
int *const p//常量指针
*p = 20;//错误，值不可以改
p = &b;//指向可以改

int const *p//指针常量
*p = 20;//正确
p = &b;//错误，指向不能改
```

# 17、定义一个学生的结构体类型，使用typedef取别名，定义结构体变量并初始化，再定义结构体指针，分别使用变量和指针访问成员，再sizeof求一下结构体变量的大小

```c
#include <stdio.h>
#include <stddef.h>

struct Student
{
    char name[21];
    int age;
};

typedef struct Student Stu;

int main()
{
    Stu stu1 = {"hello", 21};
    Stu *p = &stu1;

    printf("%s\t", stu1.name);
    printf("%d\t", stu1.age);

    printf("%s\t", p->name);
    printf("%d\t", p->age);

    printf("%zu\t", sizeof(stu1));
    return 0;
}
```

# 22.什么时候用一级指针，什么时候用二级指针

一级指针：需要指针传递，修改变量的值

```c
void change(int *p)
{
    *p = 20;
}

int main()
{
    int a = 10;
    int b = change(&a)//b=20
}
```

二级指针：需要修改一级指针的指向

```c
void allocGood(char **pp) {
    *pp = (char*)malloc(100); 
    strcpy(*pp, "hello");
}

int main() {
    char *p = NULL;  
    allocGood(&p);//p指向了"hello"
}
```
