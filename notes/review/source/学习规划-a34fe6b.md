# 嵌入式全栈能力

嵌入式全栈能力：L0 \~ L6 就是嵌入式全栈能力的7 个递进层级，数字越小越偏向底层基础、越通用；数字越大越偏向高阶应用、产品化落地，整体是一条自底向上、从地基到量产的完整能力成长路径。

- DMA：乒乓缓冲、半完成/完成中断

- 抢占式调度、时间片轮转
- SysTick调度触发机制
### 任务间同步与通信
- 信号量：二值同步、计数资源池
- 互斥量：优先级翻转与优先级继承
- 消息队列：指针传递注意事项
- 事件标志组：多条件AND/OR触发
### 软件定时器
- 单次/周期触发模式
- 回调函数不可阻塞约束

- 文件IO、进程线程、网络Socket、epoll
### 应用架构
- 线程池、Reactor模型、状态机
### 内核与驱动
- 内核基础机制、字符设备驱动、设备树
### 系统移植
- U-Boot、内核裁剪、根文件系统构建

## L4 网络通信与物联网互联

# L0 编程语言与基础内功 核心考点体系
## 一、C语言嵌入式特性（与纯软件C核心差异）
### 关键字专项（嵌入式高频考点）
- volatile：禁止编译器优化，适配硬件寄存器、中断共享变量
- const：区分只读变量与常量，RAM 与 Flash 存储位置差异
- static：限定文件级作用域 + 延长函数内变量生命周期
- 补充：extern、register、inline 在嵌入式场景的用法
### 结构体与内存对齐
- 内存对齐原理：CPU 访问效率与空间开销的权衡
- 位域 Bit-field：定义语法与跨编译器兼容性问题
- 1字节对齐配置：#pragma pack(1) 适用寄存器映射场景
### 联合体 union 专项应用
- 大小端 Endianness 检测与转换实现
- 协议报文解包：多字段共用内存，按字节/位解析
- 寄存器高低位拆分读写
### 函数指针与工程化用法
- 回调函数设计逻辑与适用场景
- 转移表 Jump Table：替代多层 if-else 实现状态机
- 函数指针数组的标准化写法

## 二、数据结构与算法（嵌入式受限版）
### 线性结构核心实现（优先无动态内存）
- 单向/双向链表：侵入式与非侵入式实现差异
- 静态环形缓冲区 Ring Buffer：无 malloc 版，适配串口/通信缓冲
- 栈与队列的静态数组实现
### 查找与排序算法
- 二分查找：正序/逆序实现，边界条件处理
- 基础排序：冒泡、选择、插入排序的空间复杂度评估
- 快速排序：递归深度评估与栈溢出风险
### 进阶数据结构
- 哈希表：开放地址法、链地址法，基于静态内存池实现
- 二叉搜索树：插入与遍历，递归+迭代双实现
- 栈溢出临界点计算：递归深度与栈空间占用关系

## 三、内存布局与编译链接
### 程序存储分段（Flash/RAM 分布）
- .text 代码段：只读，存放程序执行指令
- .rodata 只读常量段：字符串常量、const 全局变量
- .data 段：已初始化全局变量，启动时从 Flash 拷贝到 RAM
- .bss 段：未初始化全局变量，启动时自动清零
### 栈与堆内存机制
- 栈 Stack：向下增长，存放局部变量、函数参数、返回地址
- 堆 Heap：向上增长，malloc/free 动态管理
- 栈溢出 Stack Overflow：成因、复现方法与系统危害
### 编译构建与工程工具
- Makefile 核心语法
  - 目标、依赖、命令三要素结构
  - 自动变量：$@、$^、$< 含义与用法
  - 条件编译：-D 宏定义传参
- CMake 基础：交叉编译配置逻辑
- 交叉编译工具链
  - objcopy：elf 镜像转 bin/hex 文件
  - objdump、size 工具的调试用途

# L2 实时内核（RTOS）与任务调度 核心考点体系
## 一、任务管理与调度器
### 任务核心概念
- 任务控制块TCB：栈指针、优先级、状态存储
- 任务五态：就绪、运行、阻塞、挂起、删除
### 调度机制
- 抢占式调度：高优先级任务抢占触发时机
- 时间片轮转：同优先级任务分时切换
- SysTick滴答定时器：调度器时钟触发源

## 二、任务间同步与通信
### 信号量Semaphore
- 二值信号量：中断与任务间同步
- 计数信号量：资源池计数管理
### 互斥量Mutex
- 优先级翻转现象三任务复现
- 优先级继承协议底层逻辑
- 互斥量与二值信号量的本质区别
### 消息队列Queue
- 队列传值 vs 传指针的差异
- 传递指针注意事项：禁止指向栈临时变量
### 事件标志组Event Flags
- 多事件等待：AND触发、OR触发模式
- 事件位清除机制

## 三、软件定时器
### 定时器模式
- 单次触发模式
- 周期性触发模式
### 使用约束
- 定时器回调函数禁止阻塞
