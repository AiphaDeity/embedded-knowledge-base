## 遍历的核心概念

遍历是指按一定顺序访问数据结构中每个元素恰好一次的操作。

C 语言没有内置迭代器或`foreach`语法，所有遍历方式的本质都是：

> 循环 + 地址运算 + 终止条件

理解这三个核心要素是掌握 C 语言遍历的关键，不同数据结构的差异仅在于地址运算的方式不同。

## 一维数组遍历

数组是 C 语言中最基础的连续存储结构，内存地址连续且元素类型相同。

### 2.1 下标法（最直观）

```text
int arr[5] = {1, 2, 3, 4, 5};
for (int i = 0; i < 5; i++)
{
    printf("%d ", arr[i]); // 编译器会自动转换为 *(arr + i)
}
```

> [!TIP] 优点 语法简洁，逻辑清晰，最适合初学者理解和使用
> 
> [!NOTE] 缺点 需要维护下标变量，硬编码长度会降低代码可维护性

### 2.2 指针移动法

```text
// 方式1：配合下标计数
int *p = arr;
for (int i = 0; i < 5; i++) {
    printf("%d ", *p++);
}

// 方式2：终止指针法（推荐）
int *end = arr + 5;
for (int *p = arr; p < end; p++) {
    printf("%d ", *p);
}
```

> [!TIP] 优点 更贴近底层内存模型，历史上效率高于下标法
> 
> [!NOTE] 缺点 存在指针越界风险，可读性略低于下标法

### 2.3 通用长度法（避免硬编码）

```text
int arr[] = {1, 2, 3, 4, 5, 6};
// 计算数组长度：总字节数 / 单个元素字节数
size_t len = sizeof(arr) / sizeof(arr[0]);

for (size_t i = 0; i < len; i++) {
    printf("%d ", arr[i]);
}
```

> [!DANGER] 致命警告 数组作为函数参数时会退化为指针，此时`sizeof(arr)`得到的是指针大小（64 位系统 8 字节），而非数组总大小！

错误示例（绝对不要这么写）：

```text
void printArray(int arr[]) {
    // 错误！结果永远是 2（64位系统）
    size_t len = sizeof(arr) / sizeof(arr[0]);
    for (size_t i = 0; i < len; i++) {
        printf("%d ", arr[i]);
    }
}
```

正确做法：必须单独传递数组长度

```text
void printArray(int arr[], size_t len) {
    for (size_t i = 0; i < len; i++) {
        printf("%d ", arr[i]);
    }
}
```

### 2.4 动态数组遍历

`malloc`/`calloc`分配的动态数组无法用`sizeof`计算长度，必须单独保存长度变量：

```text
size_t len = 10;
int *arr = (int*)malloc(len * sizeof(int));
if (arr == NULL) {
    perror("malloc failed");
    return 1;
}

// 初始化
for (size_t i = 0; i < len; i++) {
    arr[i] = i;
}

// 遍历（只能使用提前保存的 len 变量）
for (size_t i = 0; i < len; i++) {
    printf("%d ", arr[i]);
}

free(arr);
arr = NULL; // 避免野指针
```

## 字符串遍历

C 语言字符串本质是以`'\0'`结尾的字符数组，这一特性决定了其独特的遍历方式。

### 3.1 下标法（不推荐）

```text
char str[] = "hello world";

// 错误：每次循环调用 strlen，时间复杂度 O(n²)
for (size_t i = 0; i < strlen(str); i++) {
    printf("%c ", str[i]);
}

// 正确：提前计算长度
size_t len = strlen(str);
for (size_t i = 0; i < len; i++) {
    printf("%c ", str[i]);
}
```

### 3.2 直接判断结束符（推荐）

```text
// 下标版
for (int i = 0; str[i] != '\0'; i++) {
    printf("%c ", str[i]);
}

// 指针版（C语言标准风格，最简洁高效）
for (char *p = str; *p != '\0'; p++) {
    printf("%c ", *p);
}

// 极简写法（利用 '\0' 等价于 false）
char *p = str;
while (*p) {
    printf("%c ", *p++);
}
```

> [!TIP] 优点 单次遍历完成，无需提前计算长度，性能最高

### 3.3 宽字符串遍历

处理中文等 Unicode 字符时使用`wchar_t`：

```text
#include <wchar.h>
#include <wstdio.h>

wchar_t wstr[] = L"你好，C语言";
for (wchar_t *p = wstr; *p; p++) {
    wprintf(L"%lc ", *p);
}
```

### 3.4 常见坑

- 忘记字符串末尾的`'\0'`导致越界访问
- 修改字符串字面量（`const char*`指向只读内存，会触发段错误）
- 空字符串（`""`）的处理（第一个字符就是`'\0'`）

## 链表遍历

链表是链式存储结构，元素内存地址不连续，只能通过指针域访问下一个元素。

### 4.1 单链表遍历

节点定义：

```text
typedef struct Node {
    int data;
    struct Node *next;
} Node;
```

遍历代码：

```text
Node *curr = head; // head 指向链表头节点
while (curr != NULL) {
    printf("%d ", curr->data);
    curr = curr->next; // 移动到下一个节点
}
```

### 4.2 双向链表遍历

节点定义：

```text
typedef struct DNode {
    int data;
    struct DNode *prev;
    struct DNode *next;
} DNode;
```

正向遍历：

```text
DNode *curr = head;
while (curr != NULL) {
    printf("%d ", curr->data);
    curr = curr->next;
}
```

反向遍历：

```text
DNode *curr = tail; // tail 指向链表尾节点
while (curr != NULL) {
    printf("%d ", curr->data);
    curr = curr->prev;
}
```

### 4.3 循环链表遍历

终止条件变为回到头节点：

c

运行

```text
if (head == NULL) return;

Node *curr = head;
do {
    printf("%d ", curr->data);
    curr = curr->next;
} while (curr != head);
```

### 4.4 遍历中删除节点（高频考点）

> [!WARNING] 重要提醒 直接删除当前节点会导致链表断链，必须提前保存下一个节点指针

```text
Node *curr = head;
Node *prev = NULL;
int target = 3; // 要删除的节点值

while (curr != NULL) {
    Node *next = curr->next; // 提前保存下一个节点
    if (curr->data == target) {
        if (prev == NULL) {
            head = next; // 删除头节点
        } else {
            prev->next = next; // 删除中间/尾节点
        }
        free(curr);
    } else {
        prev = curr;
    }
    curr = next;
}
```

## 多维数组遍历

C 语言多维数组按行优先顺序连续存储。

### 5.1 双重循环下标法（最常用）

```text
#define ROWS 3
#define COLS 4

int matrix[ROWS][COLS];

// 初始化
for (int i = 0; i < ROWS; i++) {
    for (int j = 0; j < COLS; j++) {
        matrix[i][j] = i * COLS + j;
    }
}

// 遍历
for (int i = 0; i < ROWS; i++) {
    for (int j = 0; j < COLS; j++) {
        printf("%d ", matrix[i][j]);
    }
    printf("\n");
}
```

### 5.2 一维指针偏移法

利用二维数组内存连续的特性：

```text
int *p = &matrix[0][0];
for (int i = 0; i < ROWS * COLS; i++) {
    printf("%d ", p[i]); // 等价于 *(p + i)
}
```

> [!NOTE] 缺点 可读性差，容易混淆行和列，仅在特殊性能优化场景使用

### 5.3 行指针法

```text
// 指向包含4个int的数组的指针
int (*row)[COLS] = matrix;
for (int i = 0; i < ROWS; i++) {
    for (int j = 0; j < COLS; j++) {
        printf("%d ", row[i][j]);
    }
    printf("\n");
}
```

### 5.4 性能优化：行优先遍历

> [!TIP] 缓存友好性优化 遍历顺序应与存储顺序一致（行优先），可大幅提高 CPU 缓存命中率。当数组较大时（如 1000x1000），行优先与列优先的性能差异可达 10 倍以上。

```text
// 行优先（快）：访问顺序与内存布局一致
for (int i = 0; i < ROWS; i++) {
    for (int j = 0; j < COLS; j++) {
        matrix[i][j] = 0;
    }
}

// 列优先（慢）：频繁跳行导致缓存失效
for (int j = 0; j < COLS; j++) {
    for (int i = 0; i < ROWS; i++) {
        matrix[i][j] = 0;
    }
}
```

## 复合数据结构遍历

### 6.1 结构体数组遍历

实际开发中最常用的遍历场景之一：

```text
typedef struct {
    int id;
    char name[20];
    float score;
} Student;

Student students[] = {
    {1, "张三", 90.5f},
    {2, "李四", 85.0f},
    {3, "王五", 92.0f}

size_t count = sizeof(students) / sizeof(students[0]);

for (size_t i = 0; i < count; i++) {
    printf("ID: %d, 姓名: %s, 分数: %.1f\n",
           students[i].id, students[i].name, students[i].score);
}
```

## 高级遍历技巧

### 7.1 回调函数遍历（高阶函数）

将遍历逻辑与业务逻辑分离，实现代码复用：

```cpp
// 通用遍历函数
void forEach(int *arr, size_t len, void (*action)(int)) {
    for (size_t i = 0; i < len; i++) {
        action(arr[i]);
    }
}

// 业务逻辑1：打印元素
void printInt(int x) {
    printf("%d ", x);
}

// 业务逻辑2：平方元素
void squareInt(int x) {
    printf("%d ", x * x);
}

// 调用示例
int arr[] = {1, 2, 3, 4, 5};
size_t len = sizeof(arr) / sizeof(arr[0]);

printf("原数组: ");
forEach(arr, len, printInt); // 输出：1 2 3 4 5

printf("\n平方数组: ");
forEach(arr, len, squareInt); // 输出：1 4 9 16 25
```

### 7.2 类型无关的通用遍历

使用`void*`实现任意类型数组的遍历：

```text
// 类型无关的通用遍历函数
void forEach(void *arr, size_t elemSize, size_t len, void (*action)(void*)) {
    for (size_t i = 0; i < len; i++) {
        // 计算当前元素地址：基地址 + 偏移量
        void *elem = (char*)arr + i * elemSize;
        action(elem);
    }
}

// 打印Student的回调函数
void printStudent(void *elem) {
    Student *s = (Student*)elem;
    printf("ID: %d, 姓名: %s\n", s->id, s->name);
}

// 调用示例
Student students[] = {{1, "张三"}, {2, "李四"}};
size_t stuLen = sizeof(students) / sizeof(students[0]);
forEach(students, sizeof(Student), stuLen, printStudent);
```

## 树与图的遍历

非线性数据结构的遍历分为深度优先（DFS）和广度优先（BFS）。

### 8.1 二叉树遍历

节点定义：

```text
typedef struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;
```

#### 递归版 DFS

```text
// 前序遍历：根 -> 左 -> 右
void preorder(TreeNode *root) {
    if (root == NULL) return;
    printf("%d ", root->val);
    preorder(root->left);
    preorder(root->right);
}

// 中序遍历：左 -> 根 -> 右
void inorder(TreeNode *root) {
    if (root == NULL) return;
    inorder(root->left);
    printf("%d ", root->val);
    inorder(root->right);
}

// 后序遍历：左 -> 右 -> 根
void postorder(TreeNode *root) {
    if (root == NULL) return;
    postorder(root->left);
    postorder(root->right);
    printf("%d ", root->val);
}
```

#### 迭代版 DFS（避免递归栈溢出）

```text
// 迭代版中序遍历
void inorderIterative(TreeNode *root) {
    #define MAX_STACK 1000
    TreeNode *stack[MAX_STACK];
    int top = -1;
    TreeNode *curr = root;

    while (curr != NULL || top != -1) {
        // 遍历到最左节点
        while (curr != NULL) {
            stack[++top] = curr;
            curr = curr->left;
        }

        curr = stack[top--];
        printf("%d ", curr->val);
        curr = curr->right;
    }
}
```

#### 层序遍历（BFS）

```cpp
void levelOrder(TreeNode *root) {
    if (root == NULL) return;

    #define MAX_QUEUE 1000
    TreeNode *queue[MAX_QUEUE];
    int front = 0, rear = 0;
    queue[rear++] = root;

    while (front < rear) {
        TreeNode *node = queue[front++];
        printf("%d ", node->val);

        if (node->left != NULL) queue[rear++] = node->left;
        if (node->right != NULL) queue[rear++] = node->right;
    }
}
```

### 8.2 图的遍历

图的遍历需要记录已访问节点，避免重复访问和死循环：

- 邻接矩阵适合稠密图
- 邻接表适合稀疏图

## 常见错误与最佳实践

### ✅ 最佳实践

1. 始终使用`size_t`类型表示数组长度和下标（符合 C 标准，无符号整数）
2. 数组作为函数参数时，必须单独传递长度
3. 字符串遍历优先使用指针法判断`'\0'`
4. 链表修改 / 删除节点时，提前保存下一个节点指针
5. 多维数组遍历遵循行优先顺序，提高缓存性能
6. 递归深度超过 1000 时，使用迭代版避免栈溢出
7. 所有动态分配的内存使用后必须释放，并置空指针

### ⚠️ 常见错误

1. 数组越界访问（C 语言不做边界检查，导致未定义行为）
2. 函数参数中使用`sizeof`计算数组长度
3. 在 for 循环条件中调用`strlen()`导致 O (n²) 复杂度
4. 遍历链表时直接删除当前节点导致断链
5. 混淆二维数组和指针数组的内存布局
6. 递归深度过大导致栈溢出
7. 忘记释放动态内存导致内存泄漏

## 总结

C 语言遍历的核心是循环 + 地址运算 + 终止条件，不同数据结构的差异仅在于地址运算的方式：

- 连续存储（数组、字符串）：使用下标或指针加法
- 链式存储（链表、树）：跟随指针域
- 非线性存储（图）：使用栈或队列辅助

选择遍历方式时，优先考虑可读性和安全性，在性能瓶颈处再进行优化。现代编译器会对下标法进行充分优化，大多数情况下无需刻意使用指针法。
