# 基本指针

```c
int a = 10;
int *p = &a;
```

二级指针

```c
int a = 10;
int *p = &a;
int **p = &p;
```

一维数组和数组指针

在一维数组：arr是 int\*类型     &arr是 int (\*)[5]

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;
int (*p1)[5] = &arr;
```

二维数组和数组指针

在二维数组:  arr是 int（\*）[3]类型     &arr是 int (\*)[2][3]类型      
                   arr[0]是int \*                 &arr[0]是int (\*)[3]类型

```c
int arr[2][3] = {1, 2, 3, 4, 5, 6};
int *p = arr[0];
int (*p)[2][3] = &arr;
```

函数指针

```c
int add（int a,int b）
{
    return a + b;
}
int (*p)(int ,int) = add;
```

指针函数

```c
void* func(int a, int b, int *res)
{
    *res = a + b;
}
```

常量指针

```c
const int *p;
```

指针常量

```c
int *const p;
```
