# C语言内存地址

[飞书原文](https://hcn4ticlccda.feishu.cn/docx/SVENdXzTroyds3xkaj1c7t0cnMd)

高地址  (0x7FFFFFFFFFFF 附近)

┌──────────────────────────────────────────────────────────┐

│               🔒 内核空间 (Kernel Space)                   │

│                   用户态不可访问                              │

│    (x86_64: 位于 0xFFFF800000000000 以上)                   │

└──────────────────────────────────────────────────────────┘ ← 用户态栈顶方向

┌──────────────────────────────────────────────────────────┐

│                      📚 栈 (Stack)                        │  ⬇ 高地址→低地址增长

│                                                              │

│  ┌─────────────────────────────────────────────────┐     │

│  │  环境字符串 ("HOME=/home/user\0"、"PATH=...")      │     │

│  │  命令行参数字符串 ("./prog\0"、"arg1\0"...)       │     │

│  ├─────────────────────────────────────────────────┤     │

│  │  辅助向量 (auxv)    (如 AT_PHDR, AT_ENTRY 等)      │     │

│  │  envp[envc] = NULL                                 │     │

│  │  envp[envc-1] → 环境变量指针                         │     │

│  │  ...  envp[0]                                      │     │

│  │  argv[argc] = NULL                                 │     │

│  │  argv[argc-1] → 命令行参数指针                       │     │

│  │  ...  argv[0] → "./prog"                            │     │

│  │  argc           (main 的实参个数)                    │     │

│  ├─────────────────────────────────────────────────┤     │ ← \_\_libc_start_main 调用 main 前

│  │  main 的栈帧                                      │     │

│  │   · 返回地址  (回到 \_\_libc_start_main)             │     │

│  │   · 保存的 RBP (上一个帧指针)                       │     │

│  │   · 局部变量: int a; char buf[32];                 │     │

│  │   · 可能被调用者保存的寄存器                         │     │

│  ├─────────────────────────────────────────────────┤     │

│  │  函数 foo 的栈帧                                   │     │

│  │   · 参数 (按调用约定: 可能通过寄存器/栈传递)         │     │

│  │   · 返回地址 (call 指令压入下一条指令地址)           │     │

│  │   · 保存的 RBP                                     │     │

│  │   · 局部变量                                        │     │

│  │   · 临时变量 / 对齐填充                             │     │

│  ├─────────────────────────────────────────────────┤     │

│  │  ... 更深调用帧 ...                               │     │

│  └─────────────────────────────────────────────────┘     │ ← 当前 RSP (栈指针)

│                          (未使用空间)                       │

│                   栈随机偏移 (ASLR)                          │

└──────────────────────────────────────────────────────────┘ ← 栈底部附近 (0x7FFF...)

┌──────────────────────────────────────────────────────────┐

│                 🗂️ 内存映射段 (Memory Mapping)              │

│   · 动态链接库 .so (libc.so, libm.so, ld-linux.so)       │

│   · mmap 匿名映射 (大块内存分配, 如超过 128KB 的 malloc)    │

│   · 文件映射 (mmap 打开的文件)                              │

│   · 共享内存                                                 │

│   此区域通常从栈下方的高地址向低地址分配 (⬇)                │

└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐

│                     🧱 堆 (Heap)                           │  ⬆ 低地址→高地址增长

│  ┌─────────────────────────────────────────────────┐     │

│  │ 已分配块 (malloc 返回)                           │     │

│  │   · chunk 头部: [prev_size | size+标志位]        │     │

│  │   · 用户数据区 (user data)                       │     │

│  │ 空闲块 (已 free)                                 │     │

│  │   · chunk 头部 + fd指针(前向) + bk指针(后向)      │     │

│  │   · 被组织在 bins / fastbins 等空闲链表里         │     │

│  │ top chunk (堆顶未分配区域, 可向高地址扩展)         │     │

│  └─────────────────────────────────────────────────┘     │

│              program break (brk 系统调用可移动)              │

└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐

│                 🅱️ BSS 段 (.bss)                          │

│   · 未初始化或初始化为 0 的全局/静态变量                       │

│   · static int count;   // 在 .bss                     │

│   · int global_arr[1000] = {0};  // 也在 .bss           │

│   · 不占磁盘空间, 程序加载时由操作系统映射为全零页             │

│   · 属性: 读写 (RW)                                       │

└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐

│                📊 数据段 (.data)                           │

│   · 已初始化的全局/静态变量                                   │

│   · int x = 42; static char c = 'A';                   │

│   · 包含 .got (全局偏移表) 和 .got.plt (用于动态链接)       │

│   · 属性: 读写 (RW), 有初始值从 ELF 文件加载                │

└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐

│              📖 只读数据段 (.rodata)                        │

│   · 字符串字面量: "Hello, world!\n"                       │

│   · const 全局变量: const int table[] = {1,2,3};        │

│   · 虚函数表 (C++) 等只读数据                                 │

│   · 属性: 只读 (R)                                         │

└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐

│               ⚙️ 代码段 (.text)                             │

│   · 可执行机器指令                                           │

│   · 函数代码 (main, foo, ...)                               │

│   · 包含 .init (初始化代码), .fini (终止代码)               │

│   · 包含 .plt (过程链接表, 用于动态库懒绑定)                   │

│   · 属性: 读+执行 (R-X)                                     │

│   · 典型起始地址: x86_64 为 0x400000                         │

└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐

│             ⛔ 保留区 (零页, NULL 指针区域)                   │

│   · 地址 0x0 附近的一段不可访问区域                          │

│   · 用于检测解引用空指针导致的段错误 (Segmentation Fault)    │

└──────────────────────────────────────────────────────────┘

低地址  (0x00000000)



内存访问权限速记：

- 代码段：R‑X
- 只读数据段：R‑‑
- 数据段 / BSS：RW‑
- 堆：RW‑
- 栈：RW‑
- 内存映射段：取决于映射属性（通常 RW 或 R‑X 给动态库）

### 🔍 栈帧内部详细图（x86_64，函数调用时）

   高地址方向 (往栈底)

   ┌────────────────────────────┐

   │  调用者的局部变量 / 旧数据    │

   ├────────────────────────────┤

   │  参数2 (20)                 │  ← 调用者压入 (或寄存器暂存后入栈)

   │  参数1 (10)                 │

   ├────────────────────────────┤

   │  返回地址 (call 下条指令)    │  ← CPU 自动压入

   ├────────────────────────────┤  ← foo 函数帧开始

   │  保存的 RBP (调用者的 RBP)    │  ← push rbp

   ├────────────────────────────┤  ← 当前 RBP 指向这里

   │  foo 的局部变量 int result    │

   │  char buffer[16] (可能对齐)   │

   │  保存的寄存器 (RBX, R12..)    │

   │  临时空间 / 对齐填充          │

   ├────────────────────────────┤  ← 当前 RSP (栈顶)

   │    (向下为未使用栈空间)        │

   └────────────────────────────┘

   低地址方向 (向栈顶)

- 调用 `foo` 时，`RSP` 下移（地址变小）为局部变量留空间。
- 返回时，恢复 `RSP` 和 `RBP`，`ret` 指令弹出返回地址。

### 🧱 堆区 chunk 内部结构（glibc malloc 典型实现）

堆中的内存以 chunk 为单位管理，已分配块和空闲块共享头部结构。

  已分配 chunk (malloc 返回的用户指针)

  ┌──────────────────────┐

  │ prev_size (前一chunk大小,若前一块空闲) │  ← chunk 起始

  ├──────────────────────┤

  │ size    |A|M|P       │  (大小包含头部, 最低三位标志)

  ├──────────────────────┤ ← 用户指针 (malloc 返回地址)

  │ 用户数据              │

  │ ......               │

  └──────────────────────┘

  ┌──────────────────────┐

  │ prev_size (本chunk大小, 用于合并)  │  ← 下一 chunk 的头部开始

  │ ...                  │



  空闲 chunk (已 free 未分配)

  ┌──────────────────────┐

  │ prev_size (上一块大小)│

  ├──────────────────────┤

  │ size    |A|M|P       │

  ├──────────────────────┤ ← 用户指针位置 (但此时数据无用)

  │ fd (前向指针, 指向下一个空闲块)  │

  │ bk (后向指针, 指向上一个空闲块)  │

  │ (大块还有 fd_nextsize / bk_nextsize) │

  └──────────────────────┘

- A (NON_MAIN_ARENA)：非主分配区标志。
- M (IS_MMAPPED)：由 mmap 直接分配的大块。
- P (PREV_INUSE)：前一块是否正在使用（0=空闲，1=在用，用于合并判断）。
- 堆的空闲块被组织成 bins（如 fastbins、smallbins、largebins、unsorted bin），malloc 和 free 时在这些链表里快速查找。
