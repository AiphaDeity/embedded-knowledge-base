## 一、Type-C 16Pin 母座纯供电电路

### 1.1 这是什么

一个 Type-C 母座的「只取 5V 电、不传数据」的最小应用电路。插充电器或充电宝取电，给后级电路供电。

### 1.2 引脚分组

| 引脚 | 数量 | 接法 | 作用 |
|-|-|-|-|
| VBUS（A4/A9/B4/B9） | 4 个 | 并联接 5V_IN | 电源正极，多脚并联降电阻、过更大电流 |
| GND（A1/B1/A12/B12） | 4 个 | 并联接地 | 电源回流路径 |
| CC1 / CC2（A5/B5） | 2 个 | 各经 5.1kΩ 下拉到 GND | 与充电器握手，识别受电设备 |
| DP1/DP2/DN1/DN2（A6/B6/A7/B7） | 4 个 | 打叉不接 | USB 2.0 数据脚，本电路不用 |
| SBU1/SBU2（A8/B8） | 2 个 | 打叉不接 | Alt Mode 辅助脚，本电路不用 |
| SHELL（1\~4） | 4 个 | 接 GND | 金属外壳，屏蔽 + 泄放静电 |

### 1.3 为什么要两个电容：C10 (10µF) + C9 (100nF)

这是经典的「大小电容并联去耦」：

| 电容 | 容量 | 擅长 | 原因 |
|-|-|-|-|
| C10 | 10µF | 低频、储能 | 负载瞬间要大电流时临时放电补电压 |
| C9 | 100nF | 高频、滤噪 | 大电容引脚长、寄生电感大，高频失效，靠小电容补 |

电容两端电压不能突变，VBUS 上的尖峰通过电容泄放到 GND。

### 1.4 为什么 CC 脚必须接 5.1k 下拉

- Type-C 充电器内部有上拉电流源，检测到 CC 脚上被 5.1kΩ 拉到特定电压，才确认「对面是合法受电设备」，才肯输出 5V。
- CC1、CC2 两个都要接：因为正反插时只有一个脚连通，两面都接才能保证任意方向都被识别。
- **常见坑**：不接这两个电阻，充电器根本不输出电压；接成上拉，板子会变成「主机口」反向送电。

## 二、电源后级链路：保险丝 + 开关 + 磁珠

```text
5V_IN → F1 自恢复保险丝 → S1 拨动开关 → L1 磁珠 → C11 100nF → 5V 主干
```

### 2.1 F1（BSMD0805L-260）：自恢复保险丝 PPTC

- 正常电流时低阻相当于导线；过流/短路时发热变身高阻，把电流掐到 mA 级。
- 断电冷却后自动恢复，不用换件。
- 选型：按最大工作电流 × 1.2\~1.5 倍留余量。

### 2.2 S1（SS12D10G5）：拨动开关

- SPDT 单刀双掷，公共端 2 脚，拨到 1 通后级，拨到 3 悬空关断。
- 就是板子的总电源开关，不用每次拔 Type-C。

### 2.3 L1（BLM21PG121SN1D）：磁珠（不是电感！）

|  | 电感 | 磁珠 |
|-|-|-|
| 作用 | 储能，做电源变换 | 耗能，专杀高频噪声 |
| 对直流 | 短路 | 短路 |
| 对高频 | 感抗上升（还会反弹） | 阻抗上升，把噪声变成热 |

型号含义：BLM 是村田磁珠系列，121 = 在 100MHz 时阻抗 120Ω。  
作用：把充电器开关电源带来的 MHz 级噪声吃掉，避免 MCU 复位、ADC 采样不准、无线模块失灵。

### 2.4 C11 (100nF)：二次去耦

- Type-C 口那颗 100nF 离后级芯片太远，中间隔了保险丝、开关、磁珠这些串联元件，走线有电感。
- 所以在磁珠后、进入板载主干前再来一颗 100nF，给高频噪声一个就近入地的回路。
- 原则：**电容跟着电源路径一级一级放，不是一颗就够。**

## 三、Type-C 正反插与 CC 握手原理

### 3.1 物理上插头里是两组独立针脚

- 正面插：A 面针脚连通
- 反面插：B 面针脚连通
- 电源（VBUS/GND）两面都有，所以正反都能通电
- 但数据脚（D+/D-）只在对应面，MCU 必须知道这次是哪面朝上，才能把信号发到正确的那组针

### 3.2 CC 线在干嘛

- 正面插 → 充电器只碰到 CC1；反面插 → 只碰到 CC2
- 充电器检测到哪个 CC 上有 5.1k 下拉，就知道当前朝向，把数据路由到对应 D+/D-
- 对纯供电电路，数据路由用不上，但「握手授权」必须有：不接 5.1k，充电器不输出 5V

## 四、原理图符号 ≠ 实物封装

### 4.1 原理图是逻辑图

- 原理图把同类信号归拢到一起（VBUS 堆左边、GND 堆右边）是为了读图方便，引脚位置是画图画出来的。
- 真正的 Type-C 母座是长方形金属盒，引脚在两个长边底部，**交错排列**（A1/B1/A2/B2…）。
- 交错排列是故意的：VBUS 旁边就是 GND，电源回路包围面积最小，干扰最小。

### 4.2 网表连接原理图和 PCB

- 原理图记录「哪个引脚连到哪个引脚」，导出网表。
- PCB 封装按真实焊盘坐标摆元件，软件根据网表告诉你哪两个焊盘要走线。
- **名字是真的，位置是假的。**

## 五、STM32F103RET6 教学板整体架构

### 5.1 双路 3.3V 电源（整图最讲究的设计）

| 电源轨 | 来源 | 供电对象 | 为什么分开 |
|-|-|-|-|
| 3.3V | SY8089 DC-DC 开关电源 | MCU 数字 VDD、ESP8266、数字逻辑 | 效率高，但开关动作有 mV 级噪声 |
| 3.3V_A | LM1117-3.3 LDO | MCU 模拟 VDDA、光敏运放 | 效率低，但噪声极低，给 ADC/比较器用 |

- STM32 内部 ADC 以 VDDA 为参考电压，VDDA 上有开关噪声会导致采样值乱跳。
- 数字电路不怕噪声，用高效 DC-DC；模拟电路怕噪声，用干净 LDO。

### 5.2 DC-DC 反馈分压

- SY8089 内部基准 0.6V，R12=100K、R13=22.1K。
- Vout = 0.6 × (1 + 100/22.1) ≈ 3.3V。

### 5.3 两个 Type-C 口分工

- U2：纯取电口，D+/D- 不接。
- U10：USB 数据口，D+/D- 接 CH340E USB 转串口，连电脑下载/打印。
- U10 的 VBUS 串了 D3 (1N4148WS)：防止两边同时插电源时互相倒灌。

## 六、STM32 最小系统

### 6.1 两个晶振

| 晶振 | 频率 | 作用 | 负载电容 |
|-|-|-|-|
| X1 | 8 MHz | 主时钟，内部 PLL 倍频到 72MHz | C1/C2 各 12pF |
| X2 | 32.768 kHz | RTC 实时时钟 | C3/C4 各 12pF |

晶振需要外部电容配合起振，电容值按晶振标称负载电容匹配，选错会不起振或频率偏。

### 6.2 复位电路

- R1 (10K) 上拉 NRST 到 3.3V，KEY1 按键把 NRST 拉地复位，C5 (100nF) 防抖。
- 上电瞬间 C5 充电延迟，NRST 缓慢上升，给 MCU 稳定上电复位。

### 6.3 BOOT 启动配置

- 2 位拨码开关选 BOOT0/BOOT1：

| BOOT0 | BOOT1 | 启动位置 |
|-|-|-|
| 0 | X | 主 Flash（正常运行） |
| 1 | 0 | 系统存储器（串口 ISP 下载） |
| 1 | 1 | 内置 SRAM（调试） |

### 6.4 SWD 下载口

5 座针：SWDIO(PA13) / SWCLK(PA14) / NRST / 3.3V / GND。

## 七、传感器与外设

- **灯光模块**：PA3 → S8050 NPN 三极管 → 驱动 LED。GPIO 电流不够，用三极管当电子开关。R17 下拉防止复位时 LED 乱闪。
- **光敏模块**：GL5506 光敏电阻 + LM358 运放做比较，输出到 PC2。有光电阻小、黑暗电阻大。
- **火焰模块**：ST-5L5B 红外接收管 + LM393 比较器，输出到 PB4。电位器调检测阈值。
- **SHT40 温湿度**：挂 I2C2（PB10/PB11），R28/R29 各 10K 是 I2C 总线必备上拉电阻。
- **ESP8266**：UART 通信，EN 上拉使能，GPIO0/GPIO2/GPIO15 上下拉决定启动模式。
- **CH340E**：USB 转串口，让电脑通过 Type-C 跟 STM32 串口通信。

## 八、为什么 LDO/DC-DC 输出有电容了，MCU 旁边还要加？

### 8.1 两类电容任务不同

| 电容 | 位置 | 任务 |
|-|-|-|
| LDO/DC-DC 输出端的 µF 大电容 | 电源芯片旁 | 稳住芯片自己的输出，长期供电 |
| MCU 旁边的 100nF | 每个 VDD 脚旁 | 给芯片内部门电路翻转提供瞬间电流 |

### 8.2 核心原因：走线有寄生电感

- MCU 门电路翻转是 ns 级，瞬间要抽几十 mA。
- 1mm PCB 走线约 1nH 寄生电感，3cm 走线就是 30nH。
- 电感阻碍电流突变：V = L × di/dt。50mA/1ns 的突变，30nH 走线上会掉 1.5V，3.3V 直接被拉到 1.8V，MCU 复位。
- 大电容虽然储能多，但离得远，高频下被走线电感「隔开」，远水解不了近渴。

### 8.3 MCU 旁边的 100nF

- 趴在 VDD 脚边 2\~3mm，走线电感只有 2nH，同样电流突变只掉 0.1V。
- 100nF 虽小，但那一瞬间需要的电荷极少（Q = C×V），完全供得上。
- **每个 VDD 脚旁边就近放一颗 100nF**：这块板上 C20\~C23 对应 4 个数字 VDD，C24/C25 对应 VDDA/VSSA。

### 8.4 记忆口诀

> 电源芯片输出端的大电容是「水厂大水缸」，MCU 旁边的 100nF 是「你家饮水机」。水厂水再多，水管跑 ns 级电流也会被铜线电感憋住；只有每个房间门口放个小水杯，门电路闪电要水时才不断供。

## 九、画板时的判断清单

1. 每个 IC 的每个 VCC/VDD 脚旁，必须有一颗 100nF，距离 < 3mm。
2. 电源芯片输出端必须有 µF 级大电容（10\~22µF）。
3. 对外接口（Type-C、排针）入口处要有 ESD 保护器件。
4. 模拟电源和数字电源尽量分开，ADC 参考用 LDO。
5. 大电流路径线宽要够（1oz 铜箔，1A 约 0.8\~1mm），换层多打过孔。
6. 去耦电容先接地再进 VDD，回路包围面积越小越好。

## 十、火焰传感器电阻选型推导

以教学板火焰模块为例，拆清楚每个电阻是怎么定下来的。

### 10.1 电路结构

两支路并联在 3.3V 和 GND 之间：左支路 R20 + R18 电位器产生可调阈值 VREF；右支路 D2 红外接收管 + R19 产生随火焰变化的信号。LM393 比较两路电压：信号 > 阈值 → PB4 翻转、LED6 亮。

```text
3.3V
 │
 R20 (100Ω)
 │
 ├── R18 (10K电位器) ── GND
 │       │
 │     中间抽头 ──→ VREF ──→ LM393 IN1-
 │
 D2 ST-5L5B (NPN 红外接收管)
 │
 ├──→ IN1+ (信号)
 │
 R19 (2K)
 │
GND
```

### 10.2 R19（2K）为什么是 2K

ST-5L5B 是电流输出型光敏管：无火时漏电流 < 100nA，CE 间等效 MΩ 级；有火时光电流随红外强度增大到几十 µA \~ mA。

R19 的作用是把光电流翻译成电压：V_signal = I_light × R19。选型要同时满足四个约束：

1. **信号摆幅覆盖电位器调节范围**：希望有火时 V_signal 落在 0.3\~2V 中段，方便用户拧电位器。典型火焰距离下光电流约 100µA，R = 1V/200µA ≈ 5K，工程师取 2K\~10K 之间标准值。
2. **不能太早饱和**：R19 太大（如 100K），近距离强光就把 V_signal 顶到 3.3V，稍微拧一下就触发，阳光反射也会误报。2K 时中等光强下 V_signal ≈ 0.94V，正好在调节中段。
3. **信号不能太小**：R19 太小（如 100Ω），100µA 光电流只产生 10mV，阈值调不出来，远处小火检测不到。
4. **功耗**：R19=2K 时最大电流 ≈ 3.3V/2K = 1.65mA，可接受。

### 10.3 其他几个电阻

| 电阻 | 作用 | 选型理由 |
|-|-|-|
| R20 100Ω | 电位器上端串联 | 阻尼抗尖峰，对 VREF 范围几乎无影响（远小于 10K） |
| R18 10K 电位器 | 阈值设定 | 电流 0.33mA 功耗小，调整手感合适 |
| R21 10K | LM393 开漏输出上拉 | 太大上升沿慢易受干扰，太小灌电流费电；10K 是开漏输出标准值 |

### 10.4 通用选型步骤

1. 查传感器 datasheet：是电流输出还是电压输出？典型信号范围多大？
2. 确定分压目标：希望信号在 0\~3.3V 里占哪一段（一般取中段 0.3\~2V）。
3. 算下拉电阻：R = 目标电压 / 典型信号电流。
4. 校验边界：无信号时是否接近 0V？最大信号时是否饱和？功耗能否接受？
5. 就近选 E96 标准阻值（2K、4.7K、10K…）。
6. 开漏输出比较器必加上拉（4.7K\~10K）。


::: tip

R19=2K 不是拍脑袋，是拿"典型距离下光电流"除以"希望读到的信号电压"，再用不饱和、不太小、功耗低三个边界卡出来的折中标称值。换个传感器型号，光电流变了就要重算——不能照抄别人的 2K。

:::


## 十一、滤波电容选型原理：为什么到处是 100nF

### 11.1 真实电容不是理想电容

真实电容 = 电容 C + 等效串联电感 ESL + 等效串联电阻 ESR 串联。ESL 来自电极结构和引脚，封装越大、引脚越长，ESL 越大（0402 约 0.5\~1nH，0805 约 1.5nH，电解电容 >10nH）。

到了高频，ESL 占主导，电容反而变成电感——它失效了。

### 11.2 自谐振频率（SRF）

电容阻抗随频率变化：低频段 Z=1/(2πfC) 随频率升高而降低；过了 SRF 后 Z=2πf·ESL 随频率升高而增大。在 SRF 附近阻抗最低、旁路效果最好。

公式：SRF = 1 / (2π√(ESL × C))。

| 电容值 | 封装 | 典型 ESL | SRF |
|-|-|-|-|
| 10µF | 0805 | \~1.5nH | \~1.3 MHz |
| 1µF | 0603 | \~1nH | \~5 MHz |
| **100nF** | 0402 | \~0.7nH | **\~19 MHz** |
| 10nF | 0402 | \~0.7nH | \~60 MHz |
| 1nF | 0402 | \~0.7nH | \~200 MHz |

### 11.3 为什么偏偏是 100nF

STM32 这类数字电路门电路翻转的噪声主要落在 10\~100MHz，开关电源噪声在 1\~5MHz。100nF 0402 的 SRF ≈ 20MHz，正好踩在数字电路噪声最密集的频段。这就是为什么 MCU 电源脚旁边标配 100nF——不是规定，是频率匹配。

### 11.4 大小电容并联的本质

电源旁边总是 10µF + 100nF 组合，因为：

- 10µF 在 1\~5MHz 阻抗最低，负责滤开关电源低频噪声、储能。
- 100nF 在 10\~30MHz 阻抗最低，负责滤 MCU 门电路高频噪声。
- 不同容量在不同频段"值班"，并联后整条频率轴都保持低阻抗。

### 11.5 封装和介质材料

| 介质 | 特点 | 用途 |
|-|-|-|
| X7R | -55\~125℃，容量变化 ±15%，直流偏压下掉 30\~50% | 数字去耦首选 |
| X5R | 便宜，但直流偏压下容量掉 70% | 消费类便宜产品 |
| C0G/NP0 | 几乎不随温度电压变化，但容量做不大 | 晶振负载电容、高精度滤波 |
| Y5V | 温度一变容量掉 80% | 别用 |

封装越小 ESL 越小、高频越好，所以高速设计都用 0402/0201，不是为了省地方。耐压选 10V/16V 即可，不要盲目选 25V 以上（耐压越高介质越厚，同等封装容量越小）。

### 11.6 不同位置选不同电容

| 位置 | 选值 | 原因 |
|-|-|-|
| MCU 数字电源脚 | 100nF 0402 X7R | 覆盖 20MHz 数字噪声 |
| 电源芯片 bulk | 10\~22µF | 覆盖 1MHz 开关噪声 |
| 晶振负载电容 | 18pF/22pF C0G | 高频、容量要精确 |
| RF/天线 | 1pF\~100pF C0G | 几百 MHz\~GHz，要极低 ESL |
| DC-DC 输出 | 22µF + 100nF 组合 | 同时覆盖低频和高频 |


::: tip

看到一个电容位置先问三个问题：要滤什么频率的噪声？噪声频率在不在这个电容的 SRF 附近？封装够小吗？电源设计不是"每个 VCC 脚旁边放个 100nF"的无脑动作，是"看噪声在哪个频率，就选那个频率附近自谐振的电容"。

:::


## 十二、传感器输出类型与 MCU 接口选择

拿到一个传感器，第一件事不是接线，是判断它输出的是什么类型的信号——这决定了 MCU 用 ADC、I2C 还是普通 GPIO 去读。

### 12.1 光敏电阻为什么不能直接接 ADC

GL5506 本质是个随光照变化的电阻（有光 \~5KΩ，黑暗 >1MΩ）。但 ADC 读的是电压，不是电阻，必须先和固定电阻分压，把"电阻变化"翻译成"电压变化"：

```text
3.3V ── GL5506 ──┬── R26(1K) ── GND
                 │
                 └── 分压点电压随光照变化 → 运放放大 → MCU ADC
```

这块板还多了一步：LM358 运放把微弱信号放大，再送到 PC2，PC2 配置成 ADC 模式读 0\~4095。

### 12.2 SHT40 为什么只要 I2C

SHT40 是完整的数字传感器芯片，内部已经集成了：

```text
传感元件（电容测湿 / 带隙测温）
    ↓ 内部 ADC
    ↓ 校准系数
    ↓ I2C 接口电路
SDA / SCL  ← 你只接这两根线
```

分压、放大、ADC、校准全部在芯片内完成，I2C 读回来的就是已经算好的温度湿度数字。

### 12.3 三类传感器对比

| 类型 | 输出是什么 | 例子 | 你要做什么 | MCU 用什么读 |
|-|-|-|-|-|
| 模拟输出 | 电阻 / 电压 / 电流 | 光敏电阻、电位器、热敏电阻、热电偶 | 外部分压 + 运放 + 滤波 | ADC 引脚 |
| 数字接口输出 | 标准协议数据包 | SHT40(I2C)、MPU6050(I2C/SPI)、OLED(I2C) | 接上拉电阻，直接通信 | I2C / SPI / UART |
| 开关量输出 | 0 / 1 高低电平 | 按键、红外接收、火焰比较器、霍尔开关 | 直接接，可能加防抖 | 普通 GPIO |

### 12.4 火焰传感器为什么不算模拟

ST-5L5B 本身是模拟元件（红外接收三极管，电流随光强变），但后面接了 LM393 比较器：

```text
红外光强 → 模拟电压 → LM393 和电位器阈值比 → 输出高/低电平 → PB4(GPIO)
```

它只告诉你"有没有火"，不告诉你"火多大"。想要连续的光强值，就得去掉比较器，把分压电压直接接 ADC。教学板选比较器方案是为了做"阈值报警"实验。

### 12.5 代码写法完全不同

**模拟传感器（光敏）：**

```c
adc_read = ADC_Read(ADC1, CHANNEL_PC2);   // 读 0~4095
light = map(adc_read, 0, 4095, 0, 100);  // 自己换算
```

**数字传感器（SHT40）：**

```c
I2C_Start();
I2C_Send(0x44);              // SHT40 地址
I2C_Send(0xFD);              // 发测量命令
delay_ms(10);
I2C_Read(buf, 6);             // 读回来直接是校准后的值
```

**开关量（火焰）：**

```c
if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_4)) {
    alarm = 1;   // 检测到火
}
```

### 12.6 判断方法

拿到新传感器先翻 datasheet 第一页：

1. 写着 "Analog Output" / "Variable Resistor" → 模拟型，分压电路 + ADC。
2. 写着 "I2C" / "SPI" / "UART" / "OneWire" → 数字型，直接接对应总线（I2C 要 4.7K\~10K 上拉）。
3. 写着 "Digital Output" / "DO" → 开关型，接 GPIO，确认高有效还是低有效。
4. 模块板上带比较器/电位器引出 "DO" 口 → 别接 ADC 了，那是开关量。


::: tip

传感器内部有没有把模拟量变成数字量，决定了你接 ADC 还是接通信总线。光敏电阻内部没有，得自己搭分压+ADC；SHT40 内部有，只要会 I2C 读寄存器。

:::
