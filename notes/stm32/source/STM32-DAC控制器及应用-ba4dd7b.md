# DAC的基本概念

本节根据课件《DAC》第一部分整理，并结合参考手册补充了原理推导、关键公式与参数详解。

## 什么是 DAC

**数字-模拟转换器（DAC, Digital-to-Analog Converter）**是一种将数字信号（通常是二进制数）转换为模拟信号（连续变化的电压或电流信号）的电子设备。其核心作用是将离散的数字信号转换成可直接驱动物理世界的连续信号，通常用于音频、视频、传感器控制、测量等领域。

为什么需要 DAC：数字系统擅长存储、计算与传输，但真实物理世界是连续的模拟量（声音、温度、电压等）。DAC 是数字世界通往模拟世界的“输出桥梁”，与 ADC（模数转换器）互为逆过程。

### 信号转换链路

1. 声音由麦克风采集为**模拟信号**
2. 经 **ADC**（模数转换器）转换为**数字信号**（如 01001101）
3. 数字信号在数字域完成存储 / 处理 / 传输
4. 经 **DAC** 还原为**模拟信号**
5. 由扬声器 / 耳机播放

### 工作原理与输出公式

DAC 将二进制输入按位加权求和，再乘以参考电压得到模拟输出：

$$V_{out} = V_{REF} \times \frac{D}{2^{N&#125;&#125;$$

- D：数字输入值，取值范围 0 \~ 2^N − 1
- N：分辨率位数，输出电平数 = 2^N
- 1 LSB（最低有效位）对应电压：$V_{LSB} = \frac{V_{REF&#125;&#125;{2^{N&#125;&#125;$，即输出能分辨的最小电压变化
- 分辨率越高，输出阶梯越精细：16-bit 输出（65536 级）接近理想连续曲线，3-bit 输出（仅 8 级）呈明显台阶（见课件对比图）

## DAC 的种类

1. **R-2R 梯形 DAC**：最常见的 DAC 之一，基于电阻网络，只使用 R 和 2R 两种阻值，通过开关控制各分支电流分配；阻值种类少，易于制造和匹配
2. **加权电阻 DAC**：每个输入位权重不同，电阻按 2 的幂次取值，电流求和后经运放输出；位数增加时电阻值跨度极大，精度难以保证
3. **电流型 DAC**：通过控制电流源输出模拟信号；每位输入控制一个权重电流源（Iu、2Iu、…、2^(N−1)·Iu），总输出电流 Iout 按位求和；速度快，适合高速应用
4. **Sigma-Delta DAC**：基于过采样和噪声整形的 DAC，把多位数据调制为高速码流再经模拟滤波还原；精度高、线性好，音频领域（手机、音响的 Codec）广泛使用

补充：课件示例电路还包括**开尔文分压器**（2^N 个等值电阻串联分压，由开关 SW0\~SW7 选通、经输出缓冲器输出；精度高但面积大）与 R-2R 电路（D0\~D3 控制梯形网络、经 R_F 与运放输出）。

| 类型 | 基本原理 | 优点 | 不足 | 典型应用 |
|-|-|-|-|-|
| R-2R 梯形 | R / 2R 梯形电阻网络按位分配电流 | 电阻种类少、易制造、精度较好 | 受电阻匹配影响，高速时寄生效应明显 | 通用中精度转换 |
| 加权电阻 | 每位电阻按 2 的幂加权求和 | 结构简单直观 | 高位电阻过大，位数增多难做准 | 低位数 / 简易场合 |
| 电流型 | 权重电流源（Iu…2^(N−1)Iu）求和 | 速度快，适合高频 | 功耗较高，需电流—电压转换 | 通信、视频、高速信号 |
| Sigma-Delta | 过采样 + 噪声整形后滤波还原 | 精度极高、线性好 | 延迟较大、速度相对较低 | 音频 Codec、精密测量 |

## DAC 的性能参数

- **分辨率**：转换精度，通常用位数表示（8 位、12 位、16 位、24 位）；决定输出台阶数量 2^N
- **采样率（更新率）**：每秒钟处理的样本数（单位 Hz）；采样率越高，输出波形越接近理想信号（课件对比了低采样率与高采样率下的波形还原度）
- **信噪比（SNR）**：输出信号与噪声的比例；理想 N 位 DAC 的理论 SNR ≈ (6.02N + 1.76) dB，实际还会受参考电压噪声、毛刺等影响
- **总谐波失真（THD）**：输出模拟信号中，除理想信号基频之外其他频率成分（谐波）的相对强度；THD 越小输出越纯净
- **线性度**：输入与输出之间的关系是否线性；常用 INL（积分非线性）与 DNL（微分非线性）衡量，理想输出应落在以 V_REF × D/2^N 为斜率的直线上

补充参数：建立时间（输出进入终值误差带所需时间）、转换速率、毛刺脉冲能量、单调性（输入增加时输出始终不下降）、ENOB（有效位数）、SFDR（无杂散动态范围）。


::: tip

一句话记忆：分辨率看“台阶细不细”，采样率看“更新快不快”，SNR / THD 看“信号纯不纯”，线性度看“输入输出直不直”。

:::


## DAC 的应用场景

1. **音频设备**：将数字音频信号（如 MP3 文件、CD 中的音频数据）转换为模拟音频信号，驱动扬声器或耳机；智能手机、MP3 播放器、电视、音响系统等都依赖 DAC 进行高质量播放
2. **通信系统**：调制解调器、卫星通信、无线电发射与接收等设备中，数字数据经 DAC 转换为模拟信号后通过无线电波传输；DAC 需根据信号的调制方式生成正确的频率和幅度
3. **控制系统**：自动化控制中输出模拟信号，把微处理器 / PLC 的数字控制信号转换为模拟信号，驱动伺服电机、阀门控制系统等外部硬件
4. **视频系统**：图像处理和视频显示中，将数字图像 / 视频信号转换为模拟信号驱动电视、监视器、投影仪等显示设备；分辨率与色彩深度越高，DAC 的作用越重要
5. **测量和仪器设备**：信号发生器、示波器等测试测量设备用 DAC 生成精确模拟信号，以执行实验或测试
6. **医学设备**：超声波设备、心电图（ECG）仪等用 DAC 生成和控制医疗信号，用于诊断或治疗

# DAC控制器原理

本节依据课件第二部分（STM32 的 DAC 使用原理）与 STM32F4 参考手册 RM0090 整理。

## DAC 模块概述

STM32F4 系列内置 DAC 外设。根据 RM0090：DAC 模块是 **12 位电压输出数模转换器**，可以按 **8 位或 12 位模式**进行配置，并且可与 **DMA 控制器**配合使用。在 12 位模式下，数据可以采用左对齐或右对齐。

- **两个输出通道**：每个通道各有一个转换器（DAC_OUT1、DAC_OUT2）
- **双通道模式**：每个通道可以单独进行转换；当两个通道组合在一起同步执行更新操作时，也可以同时进行转换
- **参考电压**：可通过输入参考电压引脚 V_REF+（与 ADC 共享）来提高分辨率

### DAC 主要特性

- 两个 DAC 转换器：各对应一个输出通道
- 12 位模式下数据采用左对齐或右对齐
- 同步更新功能
- 生成噪声波
- 生成三角波
- 补充：DMA 请求与欠载（underrun）检测、外部触发转换

## 参考电压与引脚

- **V_DDA / V_SSA**：模拟电源与模拟地
- **V_REF+**：参考电压输入引脚，与 ADC 共享；决定输出满量程
- **DAC_OUTx**：模拟输出引脚（STM32F4 上 DAC_OUT1 对应 PA4、DAC_OUT2 对应 PA5，需配置为模拟模式）
- 12 位输出对应关系：V_out = V_REF+ × DHRx / 4096；8 位模式为 256 级

## 数据路径与对齐保持寄存器

转换数据流向：软件写入**对齐保持寄存器（DHR）** → 触发后搬运到**数据输出寄存器（DORx）** → 12 位 DAC 转换 → DAC_OUTx 输出。

对于 DAC 通道 x，必须将待转换数据写入以下三个寄存器之一（对应三种对齐方式）：

| 寄存器 | 对齐方式 | 写入位 | 对应 DHRx 位 |
|-|-|-|-|
| DAC_DHR8Rx | 8 位右对齐 | [7:0] | DHRx[11:4]（高 8 位） |
| DAC_DHR12Lx | 12 位左对齐 | [15:4] | DHRx[11:0]（低 12 位） |
| DAC_DHR12Rx | 12 位右对齐 | [11:0] | DHRx[11:0] |

补充：双通道模式下可使用 DAC_DHR8RD / DAC_DHR12LD / DAC_DHR12RD 一次写入，同时更新两个通道；DMA 搬运数据到 DHR 时也按上述寄存器选择对齐方式。

## 触发模式

**自动模式**：向对齐保持寄存器写入数据后，立即转换到 DORx 寄存器。

**触发模式**：等待触发事件到达后完成转换，分为软触发、定时器触发、外部引脚触发三类；由 DAC_CR 寄存器的 TSEL[2:0] 选择触发源。

表 58 外部触发器（RM0090 / 课件）：

| 源 | 类型 | TSEL[2:0] |
|-|-|-|
| Timer 6 TRGO event | 片上定时器内部信号 | 000 |
| Timer 8 TRGO event | 片上定时器内部信号 | 001 |
| Timer 7 TRGO event | 片上定时器内部信号 | 010 |
| Timer 5 TRGO event | 片上定时器内部信号 | 011 |
| Timer 2 TRGO event | 片上定时器内部信号 | 100 |
| Timer 4 TRGO event | 片上定时器内部信号 | 101 |
| EXTI line9 | 外部引脚 | 110 |
| SWTRIG | 软件控制位 | 111 |

### DAC_CR 控制寄存器要点

- **TSELx**：通道触发选择（对应表 58 中的触发源）
- **TENx**：DACx 通道传输模式（触发使能）
- **WAVEx**：噪声 / 三角波生成使能
- **MAMPx**：掩码 / 振幅选择器（LFSR 掩码或三角波振幅）
- **BOFFx**：输出缓冲器使能 / 禁止
- 补充：DMAENx（通道 DMA 使能）、DMAUDRIEx（DMA 欠载中断使能）

## 生成波

DHRx 中的数值不仅可以直接搬运到 DORx 寄存器输出，还可以**叠加生成波**来实现叠加信号输出。生成波分为三角波和噪声波。

- **噪声波**：基于 LFSR（线性反馈移位寄存器，XOR 异或反馈 + NOR 门）产生伪随机序列；WAVEx 使能噪声波，MAMPx[3:0] 选择 LFSR 掩码
- **三角波**：计数器以 DAC_DHRx 基值为中心，按 MAMPx[3:0] 设定的最大振幅递增 / 递减循环输出


::: tip

典型用法：三角波常用于扫描 / 测试信号；噪声波可用于音频测试与抖动注入。

:::


## 输出缓冲器

DAC 集成了两个输出缓冲器，可用来**降低输出阻抗**，并在不增加外部运算放大器的情况下直接驱动外部负载。通过 DAC_CR 寄存器中的相应 **BOFFx** 位，可使能或禁止各 DAC 通道输出缓冲器。

补充注意事项：

- 使能缓冲器时输出范围受限（靠近电源轨约 0.2 V 内无法满摆幅）；驱动低阻抗负载（如小于 10 kΩ）时建议禁止缓冲器并外接运放
- 禁止缓冲器时输出阻抗较高、负载能力弱，适合接高阻抗负载或高阻测量

## 寄存器速查

| 寄存器 | 名称 | 主要作用 |
|-|-|-|
| DAC_CR | 控制寄存器 | 触发选择、触发使能、波形使能、掩码 / 振幅、缓冲器、DMA 使能与欠载中断 |
| DAC_DHR8Rx / DHR12Lx / DHR12Rx | 对齐保持寄存器 | 按对齐方式写入待转换数据（8 位右对齐、12 位左 / 右对齐） |
| DAC_DORx | 数据输出寄存器 | 触发后 DHRx 数据搬运至此，供 DAC 转换输出 |
| DAC_SR | 状态寄存器 | DMAUDRx：DMA 欠载标志（可触发中断） |

# DAC的应用

本节结合课件第三部分（DAC 应用实验）与常见工程实践整理；课件该部分仅含目录页，实验框架为补充内容。

## DAC 的典型工程应用

- **波形发生器**：定时器触发 + 查表输出正弦波、三角波、任意波形；配合 DMA 可大幅降低 CPU 负担
- **音频播放**：数字音频样本流经 DAC 还原为模拟信号，驱动功放 / 耳机；输出更新率须与音频采样率匹配
- **可调电压输出**：软件设定输出电压，用作比较器基准、传感器偏置、可变电平参考
- **模拟量控制**：输出模拟指令驱动伺服电机、阀门开度等外部执行器（通常需配合功率驱动电路）
- **通信基带信号**：配合数字信号处理生成调制信号（课件示意：DATA → DSP → DAC 链路）
- **精密模拟输出**：外接精密 DAC（如 DAC120808A、DAC8568）扩展通道数或精度，用于位置传感器 + ADC 闭环 + 电机驱动等工业场景

## 课件实验框架：DAC 应用实验

课件第三部分“DAC 应用实验”展示了外接精密 DAC（DAC120808A、DAC8568）的应用链路，核心流程为：

## STM32 DAC 实验设计（补充）

1. **实验一：DAC 输出电压**——软件触发，配置 12 位右对齐，向 DHR 写入数据后在 PA4 测量输出电压，用 ADC 回读验证线性关系
2. **实验二：定时器触发输出正弦波**——构建 256 点正弦查找表，定时器 TRGO 触发转换，更新率决定输出频率
3. **实验三：DMA 循环输出波形**——波形表经 DMA 循环搬运到 DHR，CPU 几乎零参与（详见第 4 节）
4. **实验四：三角波 / 噪声波输出**——配置 WAVEx 与 MAMPx 生成内置波形，用示波器观察输出

### 输出波形频率计算

定时器触发模式下，DAC 更新率等于触发事件频率；若波形表共 N 个点，则输出基波频率为：

$$f_{out} = \frac{f_{trigger&#125;&#125;{N}$$

# DAC的DMA使用方式

课件仅提及 DAC“可与 DMA 控制器配合使用”，本节依据 RM0090 与 STM32 标准库 / HAL 实践补充展开。

## 为什么用 DMA

- 普通方式：CPU 每输出一个样本都要写一次 DHR 寄存器；高频波形或音频播放时占用大量 CPU
- DMA 方式：DAC 每次转换请求 DMA 自动搬运一个样本到 DHR，CPU 只需一次性配置；适合循环播放波形表 / 音频数据

## DAC DMA 机制

- 每个 DAC 通道都有独立 DMA 请求：DAC 通道 1 与通道 2 分别映射到不同的 DMA 流（以 STM32F4 为例，通道 1 通常为 DMA1 Stream5 Channel7，通道 2 为 DMA1 Stream6 Channel7，具体以所用型号参考手册为准）
- 只有**外部触发**（含定时器触发）可以产生 DMA 请求；软件触发不会产生 DMA 请求
- 相关控制位：DAC_CR 的 **DMAEN1 / DMAEN2**（通道 DMA 使能）、**DMAUDRIE1 / DMAUDRIE2**（欠载中断使能）；DAC_SR 的 **DMAUDR1 / DMAUDR2**（欠载标志）
- **DMA 欠载（underrun）**：当触发频率高于 DMA 搬运能力时，DAC 取不到新数据，置位 DMAUDR 标志，可触发中断提示

## 配置步骤（思路）

1. 使能 DAC、GPIO、DMA 时钟；将 DAC_OUTx（PA4 / PA5）引脚配置为模拟模式
2. 配置 DMA：数据方向内存→外设；外设地址 = DHR12R1（或所选 DHR 寄存器）；内存地址 = 波形表；循环模式；数据宽度与对齐方式匹配（12 位右对齐常用 16 位半字）
3. 配置 DAC：选择触发源（定时器 TRGO 等）、使能通道 TENx、使能 DMA（DMAENx）、按需使能欠载中断
4. 配置并启动定时器（作为触发源，决定更新率）
5. 启动 DMA 传输，DAC 开始自动输出
6. 需要时在 DMAUDR 中断中处理欠载（调整触发频率或 DMA 配置）

## 典型应用与注意事项

- **正弦波 / 任意波形循环播放**：波形表 + DMA 循环模式 + 定时器触发；输出频率由触发频率与点数决定（f_out = f_trigger / N）
- **音频播放**：触发频率 = 音频采样率；注意 DMA 缓冲大小与中断节奏，避免欠载导致输出异常
- 触发源频率不宜超过 DMA 搬运能力，否则持续欠载
- DMA 数据宽度须与对齐方式匹配：12 位右对齐用 DHR12R1，数据写入 [11:0]；12 位左对齐用 DHR12L1，数据写入 [15:4]
- 双通道场景：可分别为两个通道配置 DMA 流，也可用双通道 DHR 寄存器一次更新两路输出
