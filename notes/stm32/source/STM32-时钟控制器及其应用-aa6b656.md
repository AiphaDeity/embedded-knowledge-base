# STM32 时钟控制器及其应用的学习第一性原理

## 第一性原理：MCU 为什么需要时钟？


::: tip

**核心追问**：如果把所有寄存器位同时翻转，数字电路还能工作吗？

:::


### 从组合逻辑到时序逻辑

数字电路的本质是**状态的有序迁移**。组合逻辑（与/或/非门）没有记忆能力，输出仅取决于当前输入；而 CPU、寄存器、外设都需要"记住"上一个状态，这就需要**时序逻辑**——由触发器（Flip-Flop）构成。

触发器有一个关键输入：**时钟端（CLK）**。只有在时钟的有效沿（上升沿或下降沿），触发器才会采样输入并更新输出。没有时钟，触发器的输出永远不变，整个数字系统就是一块"死"的硅片。

### 时钟的三个不可替代的作用

1. **同步**：让数以亿计的触发器在同一时刻动作，避免"数据还没稳定就被采样"的亚稳态（Metastability）。
2. **节拍**：CPU 的取指、译码、执行、写回，每一步都需要一个明确的时间槽。时钟频率决定了每秒能完成多少条指令。
3. **度量**：定时器、UART 波特率、SPI 速率、ADC 采样率——所有"与时间有关"的外设，都以时钟周期作为最小时间单位。


::: tip

**第一性结论**：时钟不是 MCU 的"可选配件"，而是数字系统的"心跳"。没有时钟 = 没有状态迁移 = 系统不工作。理解了这一点，RCC（Reset and Clock Control）的一切设计都顺理成章。

:::


## 时钟源：从物理振荡到可用频率

### 四种时钟源的物理本质

| 时钟源 | 典型频率 | 精度 | 物理原理 | 典型用途 |
|-|-|-|-|-|
| **HSI**（内部高速） | 16 MHz | ±1%（校准后） | RC 振荡器：电阻电容充放电 | 系统启动默认时钟、低成本应用 |
| **HSE**（外部高速） | 4\~26 MHz | ±20 ppm | 晶体/陶瓷谐振器：压电效应 | 高精度系统时钟、USB 等 |
| **LSI**（内部低速） | 32 kHz | ±10% | 低功耗 RC 振荡器 | 独立看门狗（IWDG）、低功耗唤醒 |
| **LSE**（外部低速） | 32.768 kHz | ±20 ppm | 音叉晶体：2^15 = 32768 分频得 1 Hz | RTC 实时时钟、低功耗计时 |


::: tip

**为什么 LSE 是 32.768 kHz？**因为 32768 = 2^15，经过 15 级二分频正好得到 1 Hz（1 秒），这是 RTC 的天然选择。这不是巧合，而是工程上的精心设计。

:::


### 内部 vs 外部：第一性权衡

- **内部 RC（HSI/LSI）**：不需要外部元件，启动快（几微秒），成本低；但精度受温度和电压影响大，不适合需要精确时序的场景。
- **外部晶体（HSE/LSE）**：精度高、稳定性好；但需要外部元件（晶体 + 两个负载电容），启动慢（毫秒级，需要起振时间），成本高。

**选择原则**：能用内部就用内部（省成本、省 PCB 空间）；需要精确时序（USB、CAN、高精度 UART、RTC）时必须用外部。

## 时钟树：从源到外设的频率推导

### 时钟树的第一性结构

STM32 的时钟系统可以抽象为一条**"源 → 倍频/分频 → 总线 → 外设"**的流水线：

```text
        HSI(16M) ──┐
                   ├──► PLLM ──► PLL ──► PLLP ──► SYSCLK
        HSE(8M)  ──┘         (倍频N)
                              │
                    LSI(32k) ─┤
                    LSE(32k) ─┤
                              ▼
        SYSCLK ──► AHB Prescaler(/1,/2,.../512) ──► HCLK
                                                      │
                              ┌───────────────────────┤
                              ▼                       ▼
                     APB1 Prescaler           APB2 Prescaler
                     (/1,/2,/4,/8,/16)        (/1,/2,/4,/8,/16)
                              │                       │
                              ▼                       ▼
                          PCLK1                   PCLK2
                          (低速总线)              (高速总线)
                              │                       │
                              ▼                       ▼
                    定时器×2(APB1)           定时器×2(APB2)
                    USART2/3, SPI2/3...      USART1, SPI1, ADC1...

```

### 关键公式推导

**PLL 输出频率**（以 STM32F4 为例）：

$$SYSCLK = \frac{HSE \times PLLN}{PLLM \times PLLP}$$

其中：

- **PLLM**：输入分频系数，要求分频后输入在 1\~2 MHz 之间（降低 PLL 输入抖动）
- **PLLN**：倍频系数，范围 50\~432，VCO 输出 = 输入 × PLLN，要求在 100\~432 MHz
- **PLLP**：输出分频，可选 2/4/6/8


::: tip

**实例计算**：HSE = 8 MHz，目标 SYSCLK = 168 MHz
选 PLLM = 8 → 输入 = 8/8 = 1 MHz ✓
选 PLLN = 336 → VCO = 1 × 336 = 336 MHz ✓（在 100\~432 范围内）
选 PLLP = 2 → SYSCLK = 336/2 = 168 MHz ✓

:::


### 总线时钟与定时器时钟

AHB 总线时钟 HCLK = SYSCLK / AHB_Prescaler

APB1 时钟 PCLK1 = HCLK / APB1_Prescaler（最大 42 MHz @ F4）

APB2 时钟 PCLK2 = HCLK / APB2_Prescaler（最大 84 MHz @ F4）


::: tip

**定时器时钟的特殊规则**：当 APB 预分频器 = 1 时，定时器时钟 = PCLKx；当 APB 预分频器 ≠ 1 时，定时器时钟 = PCLKx × 2。这是因为定时器需要比总线更高的分辨率。例如 APB1 = 42 MHz（分频 = 4），则 TIM2\~TIM5 的时钟 = 84 MHz。

:::


## RCC 寄存器：第一性理解

### 寄存器分组逻辑

RCC 的寄存器不是随意排列的，而是按照"时钟树的数据流"组织：

| 寄存器 | 第一性作用 | 关键位 |
|-|-|-|
| **RCC_CR** | 控制时钟源的"开关"和"就绪状态" | HSION/HSEON/PLLON（使能）， HSIRDY/HSERDY/PLLRDY（就绪） |
| **RCC_PLLCFGR** | 配置 PLL 的分频/倍频参数 | PLLM[5:0], PLLN[8:0], PLLP[1:0], PLLSRC |
| **RCC_CFGR** | 选择系统时钟源 + 配置总线预分频器 | SW[1:0]（系统时钟切换）, HPRE, PPRE1, PPRE2 |
| **RCC_AHB1ENR** | AHB1 总线上外设的时钟门控开关 | GPIOAEN, DMA1EN, ... |
| **RCC_APB1ENR** | APB1 总线上外设的时钟门控开关 | **TIM2EN, USART2EN, SPI2EN, ...** |
| **RCC_APB2ENR** | APB2 总线上外设的时钟门控开关 | TIM1EN, USART1EN, SPI1EN, ADC1EN, ... |

### 时钟门控：功耗的第一性原理

每个外设在不用时，其时钟可以被关闭（门控）。为什么？因为**触发器的翻转是 CMOS 电路动态功耗的主要来源**：

$$P_{dynamic} = \alpha \times C \times V^2 \times f$$

其中 α 是翻转因子，f 是时钟频率。关闭时钟 = f = 0 → 动态功耗 = 0。这就是为什么 STM32 复位后所有外设时钟默认关闭——**不用的东西不耗电**。


::: tip

**新手最常犯的错误**：配置了 GPIO/USART/SPI 的寄存器，但忘记在 RCC 中使能对应外设时钟。现象是"写寄存器没反应"或"外设不工作"。**记住：用任何外设之前，第一步永远是开时钟。**

:::


## 实战：从 0 配置系统时钟

### 配置流程的第一性顺序

时钟配置必须严格按照"先准备源 → 再配置 PLL → 最后切换系统时钟"的顺序，因为每一步都依赖上一步的稳定输出：

1. **使能 HSE**（或 HSI），等待就绪（HSERDY = 1）
2. **配置总线预分频器**（AHB/APB1/APB2），先降频再切源更安全
3. **配置 PLL 参数**（PLLM/PLLN/PLLP/PLLQ），选择 PLL 输入源
4. **使能 PLL**，等待就绪（PLLRDY = 1）
5. **配置 Flash 等待周期**（高频率下必须增加 Latency，否则 Flash 读取出错）
6. **切换系统时钟源到 PLL**（SW = 2），等待切换成功（SWS = 2）

### 寄存器级代码示例（STM32F4，HSE=8MHz→168MHz）

```c
// 1. 使能 HSE 并等待就绪
RCC->CR |= RCC_CR_HSEON;
while (!(RCC->CR & RCC_CR_HSERDY));

// 2. 配置总线预分频器
RCC->CFGR &= ~(RCC_CFGR_HPRE | RCC_CFGR_PPRE1 | RCC_CFGR_PPRE2);
RCC->CFGR |= RCC_CFGR_HPRE_DIV1;   // AHB = SYSCLK = 168MHz
RCC->CFGR |= RCC_CFGR_PPRE1_DIV4;  // APB1 = 168/4 = 42MHz
RCC->CFGR |= RCC_CFGR_PPRE2_DIV2;  // APB2 = 168/2 = 84MHz

// 3. 配置 PLL: HSE=8MHz, PLLM=8, PLLN=336, PLLP=2
RCC->PLLCFGR = (8 << 0) | (336 << 6) | (0 << 16) | RCC_PLLCFGR_PLLSRC_HSE;

// 4. 使能 PLL 并等待就绪
RCC->CR |= RCC_CR_PLLON;
while (!(RCC->CR & RCC_CR_PLLRDY));

// 5. 配置 Flash 等待周期 (168MHz 需要 5WS)
FLASH->ACR = FLASH_ACR_LATENCY_5WS | FLASH_ACR_ICEN | FLASH_ACR_DCEN | FLASH_ACR_PRFTEN;

// 6. 切换系统时钟到 PLL
RCC->CFGR &= ~RCC_CFGR_SW;
RCC->CFGR |= RCC_CFGR_SW_PLL;
while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL);

```

### Flash 等待周期的第一性理解

为什么高频需要增加 Flash 等待周期？因为 Flash 的读取速度是固定的（约 30ns 访问时间），而 CPU 时钟周期在 168 MHz 时只有约 6ns。**CPU 比 Flash 快**，所以 CPU 必须插入等待周期（Wait State），等 Flash 数据准备好再读取。

| SYSCLK 范围 | 等待周期 (WS) | 等效访问时间 |
|-|-|-|
| 0 \~ 30 MHz | 0 WS | 1 周期 ≥ 33ns |
| 30 \~ 60 MHz | 1 WS | 2 周期 ≥ 33ns |
| 60 \~ 90 MHz | 2 WS | 3 周期 ≥ 33ns |
| 90 \~ 120 MHz | 3 WS | 4 周期 ≥ 33ns |
| 120 \~ 150 MHz | 4 WS | 5 周期 ≥ 33ns |
| 150 \~ 168 MHz | 5 WS | 6 周期 ≥ 35ns |

## 外设时钟：从总线到具体外设

### 外设时钟使能的通用模式

```c
// 第一步：在 RCC 中使能外设时钟
RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;   // GPIOA
RCC->APB1ENR |= RCC_APB1ENR_USART2EN;  // USART2
RCC->APB2ENR |= RCC_APB2ENR_ADC1EN;     // ADC1

// 第二步：等待时钟稳定（部分外设需要）
// 一般 GPIO 不需要，但 ADC/USB 等可能需要

// 第三步：配置外设寄存器
GPIOA->MODER = ...;
USART2->BRR = ...;

```

### 常用外设时钟频率速查（SYSCLK=168MHz 时）

| 外设 | 总线 | 时钟频率 | 备注 |
|-|-|-|-|
| GPIOA\~I | AHB1 | 168 MHz | 所有 GPIO 都在 AHB1 |
| DMA1/DMA2 | AHB1 | 168 MHz | DMA 与 CPU 同速 |
| TIM2\~TIM5 | APB1 | 84 MHz | PCLK1=42MHz × 2（定时器倍频） |
| TIM1/TIM8 | APB2 | 168 MHz | PCLK2=84MHz × 2 |
| USART2/3 | APB1 | 42 MHz | 直接用 PCLK1 |
| USART1/6 | APB2 | 84 MHz | 直接用 PCLK2 |
| SPI2/3 | APB1 | 42 MHz | 最大速率 = PCLK1/2 |
| SPI1 | APB2 | 84 MHz | 最大速率 = PCLK2/2 |
| ADC1/2/3 | APB2 | ≤ 36 MHz | ADC 有独立分频，最大 36MHz |
| I2C1/2/3 | APB1 | 42 MHz | 标准模式 100k/快速 400k |

## 低功耗与时钟管理

### 时钟与功耗的第一性关系

从动态功耗公式 $P = \alpha C V^2 f$ 可以得出三个降功耗方向：

1. **降频率（f）**：不需要高性能时降低 SYSCLK，或关闭不用的外设时钟
2. **降电压（V）**：低频率下可以使用更低的内核电压（电压调节器低功耗模式）
3. **关时钟（f=0）**：Stop/Standby 模式下关闭高/低速时钟，仅保留 LSI/LSE 给 RTC/唤醒

### 三种低功耗模式的时钟策略

| 模式 | 时钟状态 | 电压调节器 | 唤醒方式 |
|-|-|-|-|
| **Sleep** | 所有时钟继续运行，CPU 停止 | 正常 | 任何中断/事件 |
| **Stop** | HSI/HSE/PLL 关闭，LSI/LSE 可选 | 低功耗/正常 | 外部中断/事件/RTC |
| **Standby** | 全部时钟关闭，仅 LSE/LSI 给 RTC/IWDG | 关闭 | NRST/WKUP/RTC |

## 常见问题与调试方法论

### 时钟问题排查清单

1. **系统不启动/死机**：检查 PLL 参数是否超出范围（VCO 100\~432MHz），Flash Latency 是否足够
2. **串口波特率不对**：检查 USART 所在 APB 总线时钟频率，BRR 计算是否正确
3. **定时器定时不准**：检查定时器时钟是否为 PCLK×2（当 APB 分频≠1 时）
4. **USB 不枚举**：检查 PLLQ 配置（USB 需要 48MHz 精确时钟），HSE 是否使用晶体
5. **ADC 采样率不对**：检查 ADC 预分频器（ADCPRE），ADC 时钟最大 36MHz
6. **外设完全没反应**：第一步检查 RCC_APBxENR/RCC_AHBxENR 中对应位是否使能

### 验证时钟配置的方法

**方法一：MCO 引脚输出**——将系统时钟或 PLL 时钟输出到 MCO1/MCO2 引脚，用示波器测量实际频率：

```c
// MCO1 输出 HSE/2 到 PA8
RCC->CFGR &= ~(RCC_CFGR_MCO1 | RCC_CFGR_MCO1PRE);
RCC->CFGR |= RCC_CFGR_MCO1_HSE | RCC_CFGR_MCO1PRE_DIV2;
// 配置 PA8 为复用功能 AF0

```

**方法二：读取 RCC_CFGR 的 SWS 位**——确认当前系统时钟源是否真的切换到了 PLL：

```c
while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL) {
    // 等待切换完成，超时则报错
}

```

**方法三：用定时器闪烁 LED 验证**——配置一个定时器按已知频率中断，观察 LED 闪烁频率是否符合预期。

## 知识体系总结


::: tip

**第一性原理学习路径回顾**
1. **为什么需要时钟？**→ 时序逻辑需要同步触发，时钟是数字系统的心跳
2. **时钟从哪来？**→ RC 振荡（内部）或晶体振荡（外部），精度 vs 成本的权衡
3. **频率怎么调？**→ PLL 倍频 + 分频器，从低频源得到高频系统时钟
4. **时钟怎么分配？**→ AHB/APB 总线分层，高速设备挂高速总线，低速设备挂低速总线
5. **外设怎么用？**→ 先开时钟门控，再配寄存器；时钟频率决定外设的时间分辨率
6. **功耗怎么降？**→ 动态功耗 ∝ 频率×电压²，关时钟/降频率/降电压是三大手段

:::


### 核心公式速记卡

| 公式 | 含义 |
|-|-|
| $SYSCLK = \frac{f_{in} \times N}{M \times P}$ | PLL 输出频率 |
| $HCLK = \frac{SYSCLK}{HPRE}$ | AHB 总线时钟 |
| $PCLKx = \frac{HCLK}{PPREx}$ | APB 总线时钟 |
| $TIMCLK = PCLKx \times (PPREx==1 ? 1 : 2)$ | 定时器时钟（APB 分频≠1 时倍频） |
| $P_{dyn} = \alpha C V^2 f$ | CMOS 动态功耗 |
| $WS \geq \frac{f_{SYS} \times t_{Flash&#125;&#125;{1s} - 1$ | Flash 等待周期计算 |

### 学习建议

- **不要死记寄存器位**，理解时钟树后，寄存器的每一位都有其物理意义
- **动手配置一次时钟**，从 HSI 16MHz 一步步升到最高频率，观察每一步的现象
- **用 MCO 引脚验证**，理论计算的频率和示波器实测的频率对上了，才算真正理解
- **读参考手册的时钟树图**，不同系列（F1/F4/F7/H7）的时钟树有差异，但第一性原理相同
- **关注 Errata**，部分芯片的 PLL 或时钟切换有已知问题，需要特殊处理

## 时钟介绍

### 什么是时钟

在交响乐中，之所以能演奏出好听的旋律，是因为有统一的**节拍**。在嵌入式系统中，时钟就起到了节拍的作用——所有数字逻辑的动作都在时钟的节拍下有序进行。


::: tip

**类比理解**：时钟 = 乐队指挥的节拍器。没有节拍器，每个乐手按自己的速度演奏，结果就是噪音；没有时钟，每个触发器按自己的延迟翻转，结果就是亚稳态和数据错误。

:::


### 时钟频率与周期

- **时钟频率（f）**：1 秒钟内时钟信号高低电平变化的次数，单位是 Hz（赫兹）。例如 16 MHz 表示每秒变化 1600 万次。
- **时钟周期（T）**：每完成一次高低电平变换所用的时间，是频率的倒数：$T = \frac{1}{f}$

| 频率 | 周期 | 直觉感受 |
|-|-|-|
| 32.768 kHz | ≈ 30.5 μs | RTC 滴答，慢到可以数 |
| 16 MHz | 62.5 ns | HSI 默认，中等速度 |
| 168 MHz | ≈ 5.95 ns | F407 最高，闪电般快 |

## 基础时钟源

### 振荡器的三种类型

| 类型 | 工作原理 | 优点 | 缺点 |
|-|-|-|-|
| **RC 振荡器** | 电阻电容充放电产生振荡 | 成本低、启动快、无需外部元件 | 精度低，受温度/电压影响大 |
| **无源晶体** | **压电效应 + 共振原理**，需外接振荡电路 | 精度高、稳定性好、成本适中 | 自身不能振荡，需配负载电容 |
| **有源晶体** | **内部集成完整振荡电路**，需外部供电 | 精度最高、信号质量好、使用简单 | 成本高、体积大、需要电源 |


::: tip

**无源晶振的外部电路**：无源晶体需要两个负载电容（通常 10\~25 pF）接到地，以及一个反馈电阻（部分 MCU 内部集成）。负载电容值需要根据晶体的数据手册计算，否则频率会偏移甚至不起振。

:::


### STM32F407 的四个时钟源

STM32F407 共有 **4 个输入时钟源**，分为内部和外部两组：

| 名称 | 类型 | 频率 | 振荡器 | 主要用途 |
|-|-|-|-|-|
| **HSI** | 内部高速 | 16 MHz | RC | 系统启动默认时钟、可直接作系统时钟或 PLL 输入 |
| **HSE** | 外部高速 | 4\~26 MHz | 晶体/有源 | 高精度系统时钟、PLL 输入（常用 8 MHz） |
| **LSI** | 内部低速 | 32 kHz | RC | 独立看门狗（IWDG）、低功耗模式下保持运行 |
| **LSE** | 外部低速 | 32.768 kHz | 晶体/陶瓷 | 实时时钟（RTC）、低功耗高精度计时 |

### HSI 时钟详解

- 由内部 **16 MHz RC 振荡器**生成
- 可**直接用作系统时钟**，或用作 **PLL 输入**
- **优点**：成本低（无需外部组件）、启动速度比 HSE 快（几微秒级）
- **缺点**：即使经过校准，精度也不及外部晶振或陶瓷谐振器（约 ±1%）
- **启动默认**：STM32 上电后默认使用 HSI 作为系统时钟，这保证了即使没有外部晶振，芯片也能启动


::: tip

**HSI 校准**：HSI 的频率可以通过 RCC_CR 寄存器的 HSITRIM[4:0] 位进行微调（步长约 0.5%），出厂时已预校准。如果对精度有一定要求但不想用外部晶振，可以通过测量 MCO 输出或利用定时器捕获来进一步校准。

:::


### HSE 时钟详解

- 高速外部时钟信号，支持**有源晶振**或**无源晶振**两种输入方式
- 频率范围：**4\~26 MHz**（常用 8 MHz）
- 可直接用作系统时钟，或用作 PLL 输入
- **有源晶振输入**：将时钟信号直接输入 OSC_IN 引脚，OSC_OUT 悬空，需在 RCC_CR 中设置 HSEBYP 位。

注：**HSEBYP（HSE Bypass，HSE 旁路）**是 `RCC_CR` 寄存器中的一个控制位，用于告诉 STM32：外部输入的是已经振荡好的时钟信号，不需要芯片内部的振荡放大器。

- **无源晶振输入**：晶体接在 OSC_IN 和 OSC_OUT 之间，配合两个负载电容

### LSI 时钟详解

- 低功耗 RC 振荡器，频率约 **32 kHz**（实际 17\~47 kHz，精度差）
- 可在**停机（Stop）和待机（Standby）模式下保持运行**
- 主要供**独立看门狗（IWDG）**使用——因为 IWDG 独立于主时钟系统，即使主时钟故障也能复位
- 也可作为 RTC 的低精度时钟源

### LSE 时钟详解

- **32.768 kHz**低速外部晶振或陶瓷谐振器
- 作为**实时时钟（RTC）**的时钟源，提供时钟/日历或其他定时功能
- **优点**：功耗低、精度高（±20 ppm）
- **为什么是 32.768 kHz？**因为 32768 = 2^15，经过 15 级二分频正好得到 1 Hz（1 秒），是 RTC 的天然选择

## 系统时钟

### PLL 时钟，锁相环（Phase-Locked Loop）

内部 PLL（锁相环）基于 **HSI 或 HSE 输入的时钟**频率进行**倍频**，从而得到更高频率的系统时钟 SYSCLK。

PLL 的输出频率由以下可编程因子决定：

| 因子 | 寄存器位 | 取值范围 | 作用 |
|-|-|-|-|
| **PLLM** | RCC_PLLCFGR[5:0] | 2\~63  | 输入分频，要求分频后为 1\~2 MHz（降低抖动） |
| **PLLN** | RCC_PLLCFGR[14:6] | 50\~432 | VCO 倍频，VCO 输出 = 输入 × PLLN，要求 100\~432 MHz |
| **PLLP** | RCC_PLLCFGR[17:16] | 2, 4, 6, 8 | 主输出分频，得到 SYSCLK |
| **PLLQ** | RCC_PLLCFGR[27:24] | 4\~15 | USB OTG FS / SDIO / RNG 分频，要求输出 48 MHz |

**PLL 输出公式**：

$$PLLCLK = \frac{f_{input} \times PLLN}{PLLM \times PLLP}$$

**USB 时钟公式**：

$$f_{USB} = \frac{f_{input} \times PLLN}{PLLM \times PLLQ} = 48\ \text{MHz}$$


::: tip

**实例计算（HSE = 8 MHz → SYSCLK = 168 MHz）**
PLLM = 8 → 输入 = 8/8 = 1 MHz ✓
PLLN = 336 → VCO = 1 × 336 = 336 MHz ✓
PLLP = 2 → SYSCLK = 336/2 = 168 MHz ✓
PLLQ = 7 → USB = 336/7 = 48 MHz ✓

:::


### SYSCLK 系统时钟

SYSCLK 即常说的**系统时钟**，**是整个芯片的主时钟**。通过 **System Clock Mux 选择器**（RCC_CFGR 的 SW[1:0] 位）选择输入源：

| SW[1:0] | 时钟源 | 说明 |
|-|-|-|
| 00 | HSI | 上电默认，16 MHz |
| 01 | HSE | 外部高速晶振 |
| 10 | PLLCLK | **PLL 输出，最高 168 MHz** |
| 11 | 禁止 | 不允许使用 |

切换后可通过读取 **SWS[1:0]**（RCC_CFGR[3:2]）位确认当前实际使用的时钟源，确保切换成功。

### HCLK 时钟（AHB 总线时钟）

将 SYSCLK 经过 **AHB Prescaler 分频器**（RCC_CFGR 的 HPRE[3:0]）分频后得到 HCLK 时钟。

- HCLK 为 **AHB 总线**提供时钟信号，最大频率 **168 MHz**
- 主要用于高速外设：**DMA、Cortex System Timer（SysTick）、FCLK、APB1、APB2**
- AHB 预分频器可选：/1, /2, /4, /8, /16, /64, /128, /256, /512


::: tip

**FCLK 是什么？**FCLK 是 Cortex-M4 内核的"自由运行时钟"，频率与 HCLK 相同，但即使在 HCLK 被门控（如睡眠模式）时也保持运行，用于中断唤醒和调试。简单理解：FCLK = HCLK，但不会被睡眠模式关闭。

:::


## 外设时钟

### APB 总线时钟

STM32F407 的 APB 总线时钟分为 **APB1** 和 **APB2**，两者的输入源都是 HCLK，经过各自的 APB Prescaler 分频后得到。

| 总线 | 预分频器 | 最大频率 | 挂载外设数 | 特点 |
|-|-|-|-|-|
| **APB1** | PPRE1[2:0] | 42 MHz | 多（低速） | 低速外设总线，功耗较低 |
| **APB2** | PPRE2[2:0] | 84 MHz | 少（高速） | 高速外设总线，性能优先 |

APB 预分频器可选：/1, /2, /4, /8, /16


::: tip

**定时器时钟的特殊规则（重要！）**：当 APB 预分频器 = 1 时，定时器时钟 = PCLKx；当 APB 预分频器 ≠ 1 时，定时器时钟 = PCLKx × 2。
例如：SYSCLK=168MHz, HCLK=168MHz, APB1 分频=4 → PCLK1=42MHz → TIM2\~TIM5 时钟 = 42×2 = **84 MHz**
这是因为定时器需要比总线更高的时间分辨率，ST 在设计时做了这个倍频处理。

:::


### 外设控制器时钟

STM32F407 的外设控制器时钟主要通过 **AHB、APB1、APB2** 三条总线提供，每条总线上可挂载多个外设控制器。

**AHB1 总线外设**（HCLK = 168 MHz）：

- GPIOA\~GPIOK（所有 GPIO 端口）
- DMA1、DMA2（直接存储器访问）
- CRC（循环冗余校验）
- 以太网 MAC（部分型号）
- USB OTG HS（部分型号）

**APB1 总线外设**（PCLK1 = 42 MHz，定时器 84 MHz）：

- 定时器：TIM2、TIM3、TIM4、TIM5、TIM6、TIM7、TIM12、TIM13、TIM14
- 串口：USART2、USART3、UART4、UART5、UART7、UART8
- SPI：SPI2、SPI3
- I2C：I2C1、I2C2、I2C3
- CAN：CAN1、CAN2
- DAC、PWR（电源控制）

**APB2 总线外设**（PCLK2 = 84 MHz，定时器 168 MHz）：

- 定时器：TIM1、TIM8、TIM9、TIM10、TIM11
- 串口：USART1、USART6
- SPI：SPI1、SPI4、SPI5、SPI6
- ADC：ADC1、ADC2、ADC3（最大 36 MHz，有独立分频）
- SDIO、SYSCFG（系统配置控制器）

### 外设时钟使能（关键操作）

**所有外设复位后时钟默认关闭**，使用前必须在 RCC 寄存器中使能对应时钟。这是新手最常犯的错误——配置了外设寄存器但忘记开时钟，导致外设完全没反应。

```c
// ===== AHB1 总线外设时钟使能 =====
RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;   // 使能 GPIOA
RCC->AHB1ENR |= RCC_AHB1ENR_DMA1EN;    // 使能 DMA1

// ===== APB1 总线外设时钟使能 =====
RCC->APB1ENR |= RCC_APB1ENR_TIM2EN;     // 使能 TIM2
RCC->APB1ENR |= RCC_APB1ENR_USART2EN;   // 使能 USART2
RCC->APB1ENR |= RCC_APB1ENR_SPI2EN;      // 使能 SPI2
RCC->APB1ENR |= RCC_APB1ENR_I2C1EN;      // 使能 I2C1

// ===== APB2 总线外设时钟使能 =====
RCC->APB2ENR |= RCC_APB2ENR_TIM1EN;      // 使能 TIM1
RCC->APB2ENR |= RCC_APB2ENR_USART1EN;    // 使能 USART1
RCC->APB2ENR |= RCC_APB2ENR_ADC1EN;       // 使能 ADC1
RCC->APB2ENR |= RCC_APB2ENR_SYSCFGEN;     // 使能 SYSCFG（外部中断需要）

```


::: tip

**低功耗提示**：不使用的外设一定要保持时钟关闭。CMOS 电路的动态功耗与时钟频率成正比（P = αCV²f），关闭时钟 = f = 0 = 零动态功耗。STM32 默认所有外设时钟关闭，就是出于这个考虑。

:::


### RTC 时钟

RTC（实时时钟）的时钟输入源可以通过 **RTC Clock Mux 选择器**选择：

1. **LSE**（32.768 kHz 外部低速晶振）——推荐，精度高
2. **LSI**（32 kHz 内部低速 RC）——低精度，无需外部元件
3. **HSE 分频**（HSE / 2\~31）——较少使用

选择位在 **RCC_BDCR** 寄存器的 **RTCSEL[1:0]**。

**IWDG（独立看门狗）**的时钟源只有一个：**LSI**。这是设计上的刻意安排——IWDG 必须完全独立于主时钟系统，即使主时钟故障或被软件关闭，看门狗仍能运行并在超时后复位系统。

## 时钟输出（MCO）

### MCO 功能概述

MCO（Microcontroller Clock Output，微控制器时钟输出）是一个可以将内部时钟信号输出到外部引脚的功能。它的作用相当于一个**可配置的有源晶振**，可以对外提供时钟。

STM32F407 有两个 MCO 输出引脚：

- MCO1 → PA8（主要输出内部低速/高速时钟，如 HSI、LSE、HSE、PLLCLK）
- MCO2 → PC9（主要输出系统级时钟，如 SYSCLK、PLLI2SCLK）

| 输出 | 引脚 | 可选时钟源 | 预分频器 |
|-|-|-|-|
| **MCO1** | PA8 | HSI、LSE、HSE、PLLCLK | /1\~/5（MCO1PRE[2:0]） |
| **MCO2** | PC9 | SYSCLK、PLLI2SCLK、HSE、PLLCLK | /1\~/5（MCO2PRE[2:0]） |

### MCO 的典型用途

1. **时钟测量与调试**：将系统时钟或 PLL 时钟输出到引脚，用示波器测量实际频率，验证时钟配置是否正确
2. **为外部芯片提供时钟**：例如为外部 ADC、DAC、以太网 PHY 等芯片提供时钟源，省去外部晶振
3. **时钟校准**：输出 HSI 时钟，用频率计测量后调整 HSITRIM 校准位

### MCO 配置代码示例

```c
// 1. 使能 GPIOA 时钟
RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;

// 2. 配置 PA8 为复用功能模式（AF0 = MCO1）
GPIOA->MODER &= ~GPIO_MODER_MODE8;        // 清除模式位
GPIOA->MODER |= GPIO_MODER_MODE8_1;        // 设置为复用功能模式 (10)
GPIOA->OSPEEDR |= GPIO_OSPEEDR_OSPEED8;    // 高速
GPIOA->PUPDR &= ~GPIO_PUPDR_PUPD8;         // 无上下拉

// 3. 配置 MCO1：选择 HSE，不分频
RCC->CFGR &= ~(RCC_CFGR_MCO1 | RCC_CFGR_MCO1PRE);
RCC->CFGR |= RCC_CFGR_MCO1_HSE;             // MCO1 源 = HSE
// MCO1PRE = 000 表示不分频（注意：0xx 表示不分频，100=/2, 101=/3...）

```

```c
// 1. 使能 GPIOC 时钟
RCC->AHB1ENR |= RCC_AHB1ENR_GPIOCEN;

// 2. 配置 PC9 为复用功能模式（AF0 = MCO2）
GPIOC->MODER &= ~GPIO_MODER_MODE9;
GPIOC->MODER |= GPIO_MODER_MODE9_1;
GPIOC->OSPEEDR |= GPIO_OSPEEDR_OSPEED9;

// 3. 配置 MCO2：选择 PLLCLK，2 分频
RCC->CFGR &= ~(RCC_CFGR_MCO2 | RCC_CFGR_MCO2PRE);
RCC->CFGR |= RCC_CFGR_MCO2_PLL;             // MCO2 源 = PLLCLK
RCC->CFGR |= RCC_CFGR_MCO2PRE_DIV2;         // 2 分频 → 168/2 = 84 MHz

```


::: tip

**MCO 预分频器的编码规则**：MCO1PRE/MCO2PRE 是 3 位，编码为：0xx = 不分频，100 = /2，101 = /3，110 = /4，111 = /5。注意不是简单的二进制数值对应，0xx 全部表示不分频。

:::


## 补充：系统时钟完整配置实战

### 配置流程（6 步法）

1. **使能 HSE**，等待就绪（HSERDY = 1）
2. **配置总线预分频器**（AHB/APB1/APB2）
3. **配置 PLL 参数**（PLLM/PLLN/PLLP/PLLQ，选择 PLL 输入源）
4. **使能 PLL**，等待就绪（PLLRDY = 1）
5. **配置 Flash 等待周期**（高频率下必须增加 Latency）
6. **切换系统时钟到 PLL**（SW = 2），等待切换成功（SWS = 2）

### 完整寄存器级代码

```c
void SystemClock_Config(void)
{
    // ===== 1. 使能 HSE 并等待就绪 =====
    RCC->CR |= RCC_CR_HSEON;                    // 使能 HSE
    while (!(RCC->CR & RCC_CR_HSERDY));         // 等待 HSE 就绪

    // ===== 2. 配置总线预分频器 =====
    RCC->CFGR &= ~(RCC_CFGR_HPRE  |              // 清除 AHB 分频
                    RCC_CFGR_PPRE1 |              // 清除 APB1 分频
                    RCC_CFGR_PPRE2);              // 清除 APB2 分频
    RCC->CFGR |= RCC_CFGR_HPRE_DIV1;             // AHB  = SYSCLK/1 = 168MHz
    RCC->CFGR |= RCC_CFGR_PPRE1_DIV4;            // APB1 = HCLK/4   = 42MHz
    RCC->CFGR |= RCC_CFGR_PPRE2_DIV2;            // APB2 = HCLK/2   = 84MHz

    // ===== 3. 配置 PLL =====
    // PLLM=8, PLLN=336, PLLP=2, PLLQ=7, 源=HSE
    RCC->PLLCFGR = (8  << 0)  |    // PLLM:  8/8   = 1MHz 输入
                    (336 << 6)  |    // PLLN:  1*336 = 336MHz VCO
                    (0  << 16) |    // PLLP:  0 = /2 → 168MHz
                    (7  << 24) |    // PLLQ:  336/7 = 48MHz (USB)
                    RCC_PLLCFGR_PLLSRC_HSE;  // PLL 输入源 = HSE

    // ===== 4. 使能 PLL 并等待就绪 =====
    RCC->CR |= RCC_CR_PLLON;                    // 使能 PLL
    while (!(RCC->CR & RCC_CR_PLLRDY));         // 等待 PLL 锁定

    // ===== 5. 配置 Flash 等待周期 =====
    // 168MHz 需要 5 个等待周期，同时使能预取指、指令缓存、数据缓存
    FLASH->ACR = FLASH_ACR_LATENCY_5WS |
                 FLASH_ACR_PRFTEN   |
                 FLASH_ACR_ICEN     |
                 FLASH_ACR_DCEN;

    // ===== 6. 切换系统时钟到 PLL =====
    RCC->CFGR &= ~RCC_CFGR_SW;                  // 清除 SW 位
    RCC->CFGR |= RCC_CFGR_SW_PLL;                // 选择 PLL 作为系统时钟
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL);
    // 等待切换完成（SWS = 10 表示 PLL 已生效）
}

```

### Flash 等待周期对照表

| SYSCLK 范围（2.7\~3.6V） | 等待周期 (WS) | 说明 |
|-|-|-|
| 0 < f ≤ 30 MHz | 0 WS | 1 个 CPU 周期即可完成 Flash 读取 |
| 30 < f ≤ 60 MHz | 1 WS | 需要 2 个 CPU 周期 |
| 60 < f ≤ 90 MHz | 2 WS | 需要 3 个 CPU 周期 |
| 90 < f ≤ 120 MHz | 3 WS | 需要 4 个 CPU 周期 |
| 120 < f ≤ 150 MHz | 4 WS | 需要 5 个 CPU 周期 |
| 150 < f ≤ 168 MHz | 5 WS | 需要 6 个 CPU 周期 |


::: tip

**致命错误**：如果切换到高频率时钟后没有设置足够的 Flash 等待周期，CPU 从 Flash 读取指令时会得到错误数据，导致**程序跑飞或 HardFault**。必须在切换时钟**之前**或**同时**设置好 Latency。

:::


## 补充：常见问题与调试技巧

### 时钟问题排查清单

| 现象 | 排查方向 |
|-|-|
| 系统不启动 / 死机 | ① PLL 参数是否超出范围（VCO 100\~432MHz）② Flash Latency 是否足够 ③ HSE 是否正常起振 |
| 串口波特率不对 | ① USART 所在 APB 总线时钟频率是否正确 ② BRR 寄存器计算是否正确 ③ HSE 晶振频率是否与代码一致 |
| 定时器定时不准 | ① 定时器时钟是否为 PCLK×2（APB 分频≠1 时）② 自动重装载值和预分频值计算 ③ 时钟源选择是否正确 |
| USB 不枚举 | ① PLLQ 是否配置为 48MHz ② 是否使用 HSE 作为 PLL 源（HSI 精度不够）③ USB 时钟是否使能 |
| ADC 采样率异常 | ① ADC 预分频器（ADCPRE）配置 ② ADC 时钟最大 36MHz ③ PCLK2 频率是否正确 |
| 外设完全没反应 | **① 第一步永远检查 RCC_AHBxENR/RCC_APBxENR 中对应位是否使能 ② 引脚复用配置是否正确** |

### 验证时钟配置的三种方法

**方法一：MCO 引脚输出 + 示波器测量**（最准确）

将 SYSCLK 或 PLLCLK 通过 MCO1/MCO2 输出，用示波器或频率计直接测量。注意 MCO 最大输出频率受引脚速度限制（约 100 MHz），高频时需要分频输出。

**方法二：读取 SWS 状态位**（最简单）

```c
// 检查当前系统时钟源
uint8_t sws = (RCC->CFGR & RCC_CFGR_SWS) >> 2;
// 00=HSI, 01=HSE, 10=PLL, 11=不可用
if (sws == 2) {
    // PLL 已成功切换为系统时钟
}

```

**方法三：SysTick 闪烁 LED 验证**（最直观）

配置 SysTick 为 1ms 中断（假设 HCLK = 168 MHz，则重载值 = 168000-1），在中断中计数，每 500ms 翻转一次 LED。如果 LED 闪烁频率明显不对，说明系统时钟配置有误。

### 时钟安全系统（CSS）

STM32F407 内置**时钟安全系统（Clock Security System）**，可以在 HSE 失效时自动切换到 HSI，并产生不可屏蔽中断（NMI），防止系统因外部晶振故障而完全停止。

```c
RCC->CR |= RCC_CR_CSSON;  // 使能 CSS
// 如果 HSE 失效，硬件自动：
// 1. 将系统时钟切换到 HSI
// 2. 产生 NMI 中断
// 3. 设置 RCC_CIR 寄存器的 CSSF 标志

```

### 核心公式速记

| 公式 | 含义 |
|-|-|
| $T = \frac{1}{f}$ | 周期与频率互为倒数 |
| $SYSCLK = \frac{f_{in} \times PLLN}{PLLM \times PLLP}$ | PLL 输出频率 |
| $HCLK = \frac{SYSCLK}{HPRE}$ | AHB 总线时钟 |
| $PCLKx = \frac{HCLK}{PPREx}$ | APB 总线时钟 |
| $TIMCLK = PCLKx \times (PPREx==1 ? 1 : 2)$ | 定时器时钟（分频≠1 时倍频） |
| $f_{USB} = \frac{f_{in} \times PLLN}{PLLM \times PLLQ} = 48MHz$ | USB 时钟必须精确 48MHz |

### 学习要点回顾

1. **时钟是数字系统的心跳**：没有时钟，所有时序逻辑都不工作
2. **四个时钟源各有定位**：HSI 启动用、HSE 高精度、LSI 看门狗、LSE 实时时钟
3. **PLL 是频率"放大器"**：从低频晶振得到高频系统时钟，注意参数范围
4. **总线分层是性能与功耗的权衡**：高速外设挂 APB2/AHB，低速挂 APB1
5. **外设时钟默认关闭**：用任何外设第一步永远是 RCC 使能时钟
6. **定时器时钟有倍频**：APB 分频≠1 时定时器时钟 = PCLK×2，这是最容易算错的地方
7. **Flash Latency 不能忘**：高频下必须增加等待周期，否则程序跑飞
8. **MCO 是调试利器**：用示波器实测时钟频率，比任何理论计算都可靠
