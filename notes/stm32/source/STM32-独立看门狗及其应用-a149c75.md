# 独立看门狗原理

## 看门狗介绍

看门狗（Watchdog）是嵌入式系统中用于监测程序运行状态的机制。程序运行时若因电磁干扰、软件缺陷等原因出现“跑飞”、死循环等异常，看门狗会在超时后自动产生复位信号，让系统重新恢复正常运行，从而提升系统的可靠性与抗干扰能力。

看门狗工作流程说明：

1. 看门狗输入时钟脉冲，递减计数器每个时钟脉冲减 1；
2. 判断计数是否为 0（是否超时）：
3. 否 → 回到计数器继续递减；
4. 是 → 产生复位信号，经复位管脚作用于 ARM 内核，触发系统复位；
5. ARM 内核正常运行期间，通过“喂狗”操作重置计数器，使计数器不归零，避免触发复位。


::: tip

“喂狗”就是把计数器重新装载为初值。只要程序在超时时间内完成喂狗，就代表程序运行正常；超过设定时间未喂狗，看门狗判定程序异常并触发复位。

:::


## STM32 的 IWDG 使用原理

STM32 内置两个看门狗：独立看门狗（IWDG）和窗口看门狗（WWDG）。IWDG 由专用的低速内部时钟 LSI 驱动，独立于主时钟，属于硬件看门狗；它一旦启动便无法用软件关闭（只能通过系统复位重新配置）。

### IWDG 硬件架构

IWDG 的核心结构位于 VDD 电压域，主要由 LSI 时钟、8 位预分频器、12 位递减计数器以及四个寄存器（IWDG_PR、IWDG_SR、IWDG_RLR、IWDG_KR）组成：

| 模块 / 寄存器 | 说明 |
|-|-|
| LSI | 低速内部时钟，约 32 kHz，独立于主时钟；主时钟故障时仍可工作 |
| IWDG_PR（预分频器寄存器） | 配置 8 位预分频器，选择分频系数（4 / 8 / 16 / 32 / 64 / 128 / 256） |
| IWDG_RLR（重载寄存器） | 存放 12 位重载值，用于装载到递减计数器 |
| IWDG_KR（密钥寄存器） | 写入特定密钥以解锁配置、启动看门狗、喂狗 |
| IWDG_SR（状态寄存器） | 反映预分频值 / 重载值更新状态 |
| 12 位递减计数器 | 每个分频后的时钟脉冲减 1，减到 0 时触发 IWDG 复位 |

### 工作过程

1. LSI 时钟经 8 位预分频器分频后，驱动 12 位递减计数器；
2. 重载寄存器中的 12 位重载值加载进递减计数器；
3. 计数器每个时钟脉冲减 1；
4. 计数减到 0 时产生 IWDG 复位信号，系统复位；
5. 计数归零前执行喂狗（向 IWDG_KR 写入 0xAAAA），重新装载重载值。

### IWDG 寄存器详解（补充）

IWDG 寄存器基地址为 0x40003000：

| 寄存器 | 偏移 | 关键内容 | 作用 |
|-|-|-|-|
| IWDG_KR | 0x00 | 0x5555 / 0xAAAA / 0xCCCC | 0x5555 解除 PR、RLR 写保护；0xAAAA 喂狗（重载计数器）；0xCCCC 启动看门狗 |
| IWDG_PR | 0x04 | PR[2:0] | 分频系数 = 4 × 2^PR（PR 取值 0\~6 对应 4\~256 分频） |
| IWDG_RLR | 0x08 | RL[11:0] | 重载值，范围 0\~4095 |
| IWDG_SR | 0x0C | PVU、RVU 状态位 | 指示预分频值 / 重载值更新状态，更新完成前不可写入新值 |

### 超时时间计算（补充）

IWDG 超时时间（复位周期）计算公式：

$$T_{IWDG} = \frac{4 \times 2^{PR} \times RLR}{f_{LSI&#125;&#125;$$

f\_{LSI} 约为 32 kHz（实际范围约 30\~60 kHz，精确值以数据手册为准）。例如 PR=4（64 分频）、RLR=1000 时：T = 64 × 1000 / 32000 ≈ 2 s。


::: tip

喂狗间隔必须小于超时时间，否则看门狗会误复位；同时应避免只在主循环末尾集中喂狗，防止程序异常卡在中断 / 子程序中时看门狗失效。

:::


### IWDG 配置步骤（补充）

1. 向 IWDG_KR 写入 0x5555，解除 PR 与 RLR 的写保护；
2. 配置 IWDG_PR，设置预分频系数；
3. 配置 IWDG_RLR，设置重载值（决定超时时间）；
4. 等待 IWDG_SR 中 PVU、RVU 清零（更新完成）；
5. 向 IWDG_KR 写入 0xCCCC，启动看门狗；
6. 程序运行中周期性向 IWDG_KR 写入 0xAAAA 喂狗。

### IWDG 与 WWDG 对比（补充）

| 对比项 | 独立看门狗 IWDG | 窗口看门狗 WWDG |
|-|-|-|
| 时钟源 | LSI 内部低速时钟（约 32 kHz） | 主时钟 APB1 分频（PCLK1） |
| 计数器 | 12 位递减计数器 | 7 位递减计数器 |
| 喂狗窗口 | 无窗口限制，只要在超时前喂狗即可 | 有窗口限制，只能在窗口期内喂狗，过早过晚都会复位 |
| 关闭方式 | 一旦启动无法关闭，只能复位 | 一旦启动无法关闭，只能复位 |
| 主要用途 | 监测长时间跑飞、死循环 | 检测程序时序异常（喂狗过早 / 过晚） |
| 中断 | 无，超时直接复位 | 递减到 0x40 时可提前触发中断，再执行复位 |

# 独立看门狗应用

## 实验目的

通过实验掌握 STM32 独立看门狗（IWDG）的配置方法，理解看门狗的工作原理与喂狗机制，学会在程序中正确使用看门狗防止程序跑飞。

## 实验原理

配置 IWDG 并设定超时时间后，主程序正常运行并周期性喂狗，系统不会复位；若程序异常（如死循环、跑飞）导致无法喂狗，IWDG 超时后自动复位系统。实验中可人为停止喂狗，观察系统复位现象（如 LED 状态变化、复位标志位）。

## 实验代码（寄存器版）

```c
void IWDG_Init(void)
{
    // 1. 解除写保护
    IWDG->KR = 0x5555;
    // 2. 预分频：64 分频（PR=4，4 x 2^4 = 64）
    IWDG->PR = 4;
    // 3. 重载值 1000：超时约 64 x 1000 / 32000 = 2 s
    IWDG->RLR = 1000;
    // 4. 等待预分频值、重载值更新完成
    while (IWDG->SR != 0);
    // 5. 启动看门狗
    IWDG->KR = 0xCCCC;
}

void IWDG_Feed(void)
{
    IWDG->KR = 0xAAAA;  // 喂狗：重载计数器
}

```

```c
int main(void)
{
    LED_Init();      // 初始化 LED
    IWDG_Init();     // 启动独立看门狗

    while (1)
    {
        LED_ON;
        Delay_ms(200);
        LED_OFF;
        Delay_ms(200);
        IWDG_Feed();  // 喂狗；若注释掉此行，约 2 s 后系统复位
    }
}

```

## 实验代码（HAL 库版）

```c
IWDG_HandleTypeDef hiwdg;

void MX_IWDG_Init(void)
{
    hiwdg.Instance = IWDG;
    hiwdg.Init.Prescaler = IWDG_PRESCALER_64;  // 64 分频
    hiwdg.Init.Reload = 1000;                  // 重载值 1000，约 2 s 超时
    if (HAL_IWDG_Init(&hiwdg) != HAL_OK)
    {
        Error_Handler();
    }
}

// 喂狗
HAL_IWDG_Refresh(&hiwdg);

```

## 实验现象

1. 正常运行时周期性喂狗，程序持续运行，LED 正常闪烁；
2. 注释掉喂狗语句后，IWDG 超时（约 2 s）触发复位，系统反复重启，可通过 LED 现象或复位标志位观察到；
3. 恢复喂狗后，系统恢复正常运行。

## 复位原因检测（补充）

可通过复位标志位判断系统是否由 IWDG 复位：

```c
if (RCC_GetFlagStatus(RCC_FLAG_IWDGRST) != RESET)
{
    // 系统由独立看门狗复位
    RCC_ClearFlag();  // 清除复位标志
}

```

## 注意事项（补充）

1. 喂狗间隔必须小于超时时间，否则系统会被误复位；
2. IWDG 一旦启动无法用软件关闭，只有系统复位后才能重新配置；
3. LSI 时钟精度有限（约 30\~60 kHz），超时时间为近似值，关键场合需实测校准；
4. 不要在中断服务函数中喂狗，否则主程序卡死时看门狗仍被喂，起不到监测作用；
5. 配置 IWDG 后应先等待 PVU / RVU 状态位清零，再写入新的预分频值或重载值；
6. 低功耗模式下 IWDG 是否继续工作取决于具体芯片型号，需查阅数据手册。
