# LVGL模型器搭建

本章目标：在 Windows PC 上用 Code::Blocks 搭建 LVGL 模拟器，不依赖任何开发板，先把 LVGL 的编译、运行与调试环境跑通，为后续章节的学习提供统一的实验平台。


::: tip

完成标准：用 Code::Blocks 打开模拟器工程能编译通过并弹出 LVGL 演示窗口；随后能在工程中新建自己的 .c/.h 文件并在 main.c 中调用，看到自己写的界面。

:::


## windows PC运行LVGL(codeblocks)

**是什么**：LVGL 模拟器是一套把 LVGL 图形库跑在 PC 上的工程：用窗口模拟“屏幕”，用鼠标/键盘模拟“触摸屏/输入设备”，让 LVGL 的绘制结果直接显示在 Windows 窗口中。本课程用 Code::Blocks（自带 MinGW GCC 编译器）编译这套工程。

**原理**：LVGL 是纯 C 编写的图形库，核心代码与具体硬件解耦，运行时只依赖三样东西：一块“画布”（显示缓冲 + 刷新回调 flush_cb）、一个“时钟”（tick 心跳）、若干“输入设备”（indev 读取回调）。PC 模拟器恰好把这三样都映射到电脑资源上，所以同一套 LVGL 用户代码在模拟器与真实单片机之间几乎不用改，这正是先用模拟器学习的原因。

**步骤一：安装 Code::Blocks（mingw-setup 版）**

1. 打开官网 https://www.codeblocks.org/downloads/
2. 选择 “Download the binary release”（二进制发布版，最稳定的正式安装方式）
3. 在平台列表中选择 Microsoft Windows
4. 下载 codeblocks-20.03-mingw-setup.exe（“mingw”表示内置 MinGW 编译器；不带 mingw 的 setup.exe 不含编译器）
5. 点击下载链接（FossHUB 镜像），页面跳转后会自动开始下载，安装保持默认即可


::: tip

为什么必须选 mingw-setup：Code::Blocks 本身只是 IDE（集成开发环境），真正编译代码的是 C 编译器。mingw-setup 版把 GCC 编译器一并装好，装完即可编译；若装了无编译器版本，打开/新建工程后会因找不到编译器而无法编译。

:::


**步骤二：获取 LVGL 模拟器资源包**

1. 进入 https://lvgl.io/ 获取 Code::Blocks 模拟器资源包（对应 GitHub 仓库 release/v8.3 分支，工程文件为 LittleVGL.cbp）
2. 仓库内含 lvgl 与 lv_drivers 两个子目录，它们是 git 子模块（submodule），分别指向固定版本的提交（示例中 lvgl @ 1c5d4b0、lv_drivers @ 8226621）
3. 注意：如果用网页上的 “Download ZIP” 方式下载压缩包，子模块内容默认不会被打包，必须把 lvgl 和 lv_drivers 两个子项也分别下载并放回对应目录，否则工程会因缺少源码而编译失败

**步骤三：打开并运行工程**

1. 用 Code::Blocks 打开 LittleVGL.cbp（File → Open，或直接双击）
2. 点击 Build and Run（F9）编译运行
3. 首次编译需要几分钟，成功后弹出 LVGL 演示窗口即说明环境就绪

**步骤四：修改模拟器配置**

1. 屏幕分辨率：修改 lv_drv_conf.h（或工程内 monitor 显示驱动配置）中的 horizontal_resolution 与 vertical_resolution；同时把 lv_conf.h 中的 LV_HOR_RES_MAX / LV_VER_RES_MAX 设为相同值，二者不一致会导致坐标越界或显示错位
2. 其它常用配置都在 lv_conf.h：LV_COLOR_DEPTH（颜色深度，16 位即可）、字体开关（LV_FONT_MONTSERRAT\_\*）、组件裁剪（LV_USE\_\* 开关）

**步骤五：添加自己的代码**

1. 在工程中新建自己的 .c/.h 文件（例如 my_ui.c / my_ui.h），编写界面初始化函数
2. 在 main.c 中调用该函数（替换或追加到 demo 调用处），即可看到自己的界面

**怎么判断是否成功**：窗口出现且界面正常显示、控制台无 LVGL_ASSERT 断言报错、修改代码后重新编译能生效，三者同时满足即模拟器搭建成功。

# LVGL概述

本章回答三个递进的问题：LVGL 是什么（GUI 与 GUI 库、LVGL 定位）、对象 lv_obj_t 是什么（LVGL 的面向对象编程思想与结构体实现）、基础对象 lv_obj 怎么用（活动屏幕与父子对象关系）。理解这三层，后续所有部件都只是“对象 + 自己的特性”。

## LVGL介绍

**1、GUI 是什么**：GUI（Graphical User Interface）即图形用户界面，是一种通过图形化的方式呈现操作和数据、使用户可以通过鼠标、键盘等输入设备与计算机设备进行交互的用户界面。与之相对的是纯命令行界面（CLI），只能靠输入命令交互。

**2、GUI 库是什么**：GUI 库是一种用于开发图形用户界面的软件库，把界面里的窗口、下拉菜单、对话框、按键等常见元素封装成可直接调用的接口函数。开发者只需要调用 GUI 库的接口，就能快速绘制出所需界面，而不必自己从画点、画线开始实现每一个控件。

**3、常见嵌入式 GUI 库对比**（课件对比图：emWin / LVGL / TouchGFX / Qt）：

| GUI库 | 授权方式 | 资源需求 | 适用场景 |
|-|-|-|-|
| emWin | SEGGER 商业授权 | 中等 | 商业产品、需要官方支持 |
| LVGL | 开源免费（MIT） | 低，可裁剪 | MCU 小屏嵌入式 GUI，本课程 |
| TouchGFX | ST 生态，商用授权 | 较高（建议带 GPU） | STM32 高性能屏显方案 |
| Qt | 开源/商业双协议 | 高 | 桌面/工业 HMI 等资源充足平台 |

**4、LVGL 是什么**：LVGL 是一个开源的嵌入式图形库，具有轻量级、多功能、灵活和可移植等特点，可以帮助开发者快速、方便地创建美观且功能丰富的 GUI。官网：https://lvgl.io/

**为什么适合嵌入式（补充原理）**：LVGL 用纯 C 编写、与硬件解耦，运行时只依赖显示缓冲、tick 心跳和输入设备三个抽象层；所有功能开关集中在 lv_conf.h，按需裁剪后 ROM/RAM 占用很低；MIT 协议允许免费商用。

**怎么判断用哪个**：单片机 + 小屏 + 追求低成本 → LVGL；需要 ST 官方深度优化或硬件加速 → TouchGFX；产品要商业售后或已在用 SEGGER 生态 → emWin；跑 Linux/高性能处理器 → Qt。

## 对象(lv_obj_t)

**1、LVGL 的编程思想**：LVGL 采用的是面向对象的编程思想，用抽象的“类”进而实例化出不同的“对象”（对象就是 LVGL 的部件，例如 btn、label……）。课件用猫举例：先根据猫的共同特征（嘴巴、鼻子、耳朵、毛发、尾巴、叫声等）抽象出“猫类”，再由“猫类”实例化出一个猫的基本对象（模型）；同一只猫修改属性（毛色、眼睛颜色）就变成另一只猫——不同品种、不同毛色，形态和外观都不一样。

**2、C 语言怎么实现“类”（原理）**：C 语言本身没有“类”的概念，LVGL 用结构体的方式来实现“类”的思想。这里最重要的结构体就是 lv_obj_t：

```c
typedef struct _lv_obj_t {
    const lv_obj_class_t *class_p;   /* 对象所属的类（描述行为与属性） */
    struct _lv_obj_t *parent;        /* 父对象指针 */
    _lv_obj_spec_attr_t *spec_attr;  /* 特殊属性（可选，如滚动等） */
    _lv_obj_style_t *styles;         /* 样式链表 */
#if LV_USE_USER_DATA
    void *user_data;                 /* 用户自定义数据 */
#endif
    lv_area_t coords;                /* 对象在屏幕上的坐标区域 */
    lv_obj_flag_t flags;             /* 行为标志位 */
    lv_state_t state;                /* 状态：默认/按下/选中/禁用等 */
    uint16_t layout_inv : 1;         /* 布局需要重新计算的标记 */
    uint16_t scr_layout_inv : 1;
    uint16_t skip_trans : 1;
    uint16_t style_cnt : 6;          /* 样式数量 */
    uint16_t h_layout : 1;
    uint16_t w_layout : 1;
    uint16_t being_deleted : 1;
};
```

**3、为什么说 lv_obj_t 不是实例化后的对象**：lv_obj_t 只是“类”（类型定义），使用前必须先实例化出一个基类（父类）对象，也就是 lv_obj（基础对象）；其它所有部件都继承自这个基类。

**4、子对象的衍生**（课件继承图）：lv_obj_t 实例化得到 lv_obj（基础对象/父对象），再由父对象衍生出 lv_switch、lv_label、lv_btn 等各类子对象（还有更多，用省略号表示）。所有对象都在 lv_obj_t 这个结构体的基础上演变，所以才能看到各种风格、各种形态的部件。

**补充原理（继承的实现）**：派生结构体（如 lv_label_t）的第一个成员就是 lv_obj_t 父类，因此派生对象的指针可以安全地当作 lv_obj_t\* 使用，这就是 LVGL 的 API 几乎都接收 lv_obj_t\* 参数、同一个函数能作用于任意控件的原因。

**怎么判断**：想创建一个部件，就用对应的 lv_xxx_create(父对象) 去实例化（如 lv_btn_create）；所有部件的共同能力（位置、大小、样式、事件）都来自父类 lv_obj，后面几章讲的就是这些公共能力。

## 基础对象(lv_obj)

**1、基础对象是什么**：基础对象（lv_obj）是 lv_obj_t 实例化出来的基类对象，是所有部件的父对象。它的本质就是一个矩形的部件，其它部件（lv_switch、lv_label、lv_btn……）都以它为父对象创建出来。

**2、基础对象就是当前活动屏幕**：在 LVGL 中，基础对象（lv_obj）对应当前的活动屏幕，通过 lv_scr_act() 可以获取活动屏幕对象，然后以它作为父对象去创建其它部件。

**为什么基础对象是活动屏幕（课件原理）**：LVGL 初始化时，会根据我们所需的屏幕分辨率，实例化出一个“屏幕分辨率大小”的矩形控件，这个矩形控件就是基础对象，之后创建的所有子对象都挂在它下面。也就是说，活动屏幕本质就是一个铺满全屏的矩形基础对象。

**示例**：

```c
lv_obj_t *scr = lv_scr_act();        /* 获取活动屏幕（基础对象） */
lv_obj_t *btn = lv_btn_create(scr);  /* 以活动屏幕为父对象创建按钮 */
lv_obj_t *lbl = lv_label_create(btn);/* 父对象不限于屏幕，按钮也能当父对象 */
```

**3、父子对象的关系**：部件的创建只能以基础对象（lv_obj）作为父对象吗？不是。父对象可以视为其子对象的容器：每个对象都只有一个父对象（活动屏幕除外），但父对象可以有任意数量的子对象，而且父对象的类型没有限制——比如可以把一个按钮作为父对象，在它上面创建标签部件。

**父子关系三条规则**：

1. **子对象会随着父对象移动**：父对象位置变化，子对象也跟着动（课件示意：绿色方块为“父”，黄色圆形为“子”，父动则子随）
2. **子对象的位置是相对于父对象的**：子对象的坐标以父对象为参考系，不是相对屏幕
3. **子对象超出父对象范围的部分不显示**：子对象位置超出父对象边界时，超出部分会被裁剪掉，不显示

**怎么判断**：需要把一组控件当成整体移动/隐藏/删除时，就创建一个容器对象（lv_obj）当它们的父对象，只操作父对象即可整体生效；给控件定位时，先想清楚它的坐标是相对哪个父对象计算的。

# 部件基本属性(一般属性)

本章讲部件最基础的三类“一般属性”：大小（部件占多大）、位置（部件放哪里）、对齐（怎么摆更省事）。这些是所有部件（按钮、标签、滑块……）都具备的公共能力，来自父类 lv_obj。后面几章讲样式和事件，也是这些公共能力的延伸。

## 大小(size)

**是什么**：部件的大小（size）就是它的宽度和高度，单位是像素，决定部件在屏幕上占据的矩形区域大小（课件示意：矩形标注“宽度”和“高度”两个维度）。

**设置大小的 API**（课件原文）：

```c
lv_obj_set_width(obj, width);    /* 设置宽度 */
lv_obj_set_height(obj, height);  /* 设置高度 */
lv_obj_set_size(obj, width, height); /* 同时设置宽度和高度 */
```

**原理**：每个对象在 LVGL 内部都保存一个坐标区域（lv_area_t coords），宽度和高度就是这个区域的大小；修改后对象会标记为“需要重绘”，下一帧按新尺寸绘制。

**怎么判断**：

- 界面需要精确固定尺寸时（如按钮 120×40），直接用 lv_obj_set_size 指定像素值
- 希望尺寸跟随内容变化时（如标签按文字宽度自动撑开），可用特殊值 LV_SIZE_CONTENT，后面章节会讲到
- 同一控件在不同状态（按下/默认）下大小不同，属于样式/状态系统，见第 4 章

## 位置(position)

**是什么**：部件的位置（position）就是它左上角在父对象坐标系中的坐标 (x, y)，单位像素。

**坐标系统**（课件以 800×480 屏幕为例）：

- 原点 (0,0) 在屏幕/父对象的左上角
- x 轴向右增大，y 轴向下增大（注意 y 轴方向和数学坐标系相反）
- 屏幕四个角：左上 (0,0)、右上 (799,0)、左下 (0,479)、右下 (799,479)

**注意（课件强调）**：设置部件的位置时，原点 (0,0) 的位置在**父对象**的左上角——位置坐标是相对父对象计算的，不是相对屏幕。

**设置位置的 API**（课件原文）：

```c
lv_obj_set_x(obj, x);     /* 设置 X 轴坐标 */
lv_obj_set_y(obj, y);     /* 设置 Y 轴坐标 */
lv_obj_set_pos(obj, x, y);/* 同时设置 X 和 Y 轴坐标 */
```

**原理**：x/y 存于对象内部，绘制时以父对象内容区左上角为基准换算成屏幕坐标；所以父对象移动，子对象坐标不变但实际显示位置跟着动（父子规则，见第 2 章）。

**怎么判断**：坐标会随父对象变化而“被动”变化，手动 set_pos 适合简单固定布局；当界面元素多、需要随屏幕尺寸自适应时，优先用对齐（3.3）或布局（Flex/Grid，第 17 章），避免手算坐标。

## 对齐(alignment)

**是什么**：对齐（alignment）是让部件按指定方位摆放的快捷方式，避免手算坐标。

LVGL 有**两种对齐方式**（课件）：

①具有父子关系的部件对齐（参照父对象）

②没有父子关系的部件对齐（参照其它部件）。

**第一种：参照父对象对齐**（有父子关系，课件原文）：

```c
lv_obj_set_align(子对象obj, 对齐模式);   /* 参照父对象对齐 */
lv_obj_align(子对象obj, 对齐模式, x, y); /* 参照父对象对齐，再进行偏移 */
lv_obj_center(子对象obj);                /* 简写：在父对象中居中 */
```

**第二种：参照其它部件对齐**（无父子关系，课件原文）：

```c
lv_obj_align_to(需要进行对齐的部件, 基准部件, 对齐模式, x, y);
```

**对齐模式 LV_ALIGN_xx**（9 宫格，课件表格）：

| 列1（左） | 列2（中） | 列3（右） |
|-|-|-|
| LV_ALIGN_TOP_LEFT | LV_ALIGN_TOP_MID | LV_ALIGN_TOP_RIGHT |
| LV_ALIGN_LEFT_MID | LV_ALIGN_CENTER | LV_ALIGN_RIGHT_MID |
| LV_ALIGN_BOTTOM_LEFT | LV_ALIGN_BOTTOM_MID | LV_ALIGN_BOTTOM_RIGHT |

另有**外部方位** OUT\_ 系列（课件图），用于对齐到基准对象的**外侧**：OUT_TOP_LEFT、OUT_TOP_MID、OUT_TOP_RIGHT、OUT_LEFT_TOP、OUT_RIGHT_TOP、OUT_LEFT_MID、OUT_RIGHT_MID、OUT_LEFT_BOTTOM、OUT_RIGHT_BOTTOM、OUT_BOTTOM_LEFT、OUT_BOTTOM_MID、OUT_BOTTOM_RIGHT。

**原理**：对齐的本质是“计算基准对象上的一个锚点，再把部件自己的对应锚点放上去，最后加上偏移 (x,y)”。lv_obj_align 相对父对象内容区，lv_obj_align_to 相对任意基准部件（包括无父子关系的部件）。

**怎么判断**：

- 部件要放在屏幕/容器的某个位置（如居中、右下角）→ 用 lv_obj_align（相对父对象）
- 部件要贴着另一个部件摆放（如按钮右侧放文本、图标下方放标签）→ 用 lv_obj_align_to + OUT\_ 模式
- 注意：lv_obj_align 是“一次性摆放”，父对象尺寸变化后不会自动跟随，需要自适应时用布局（第 17 章）

# 部件基本属性(样式)

本章讲样式（style）：用样式来设置部件的外观（颜色、阴影、边框等），并控制交互时部件的变化效果。课件围绕四个问题展开：如何添加样式、样式什么时候生效、有哪些样式属性、如何单独设置部件某一部分的样式。

## 概述

**是什么**：样式（style）用于设置部件的外观——颜色、阴影效果、边框等等，从而让界面更加美观，以及控制用户交互时部件呈现的效果（如按下变深、禁用变灰）。

**本章要解决的四个问题**（课件原文）：

1. 如何给部件添加样式？
2. 添加的样式，什么时候生效？
3. 有哪些样式属性可以设置？
4. 如何单独设置部件中某一个部分的样式？

**原理**：LVGL 把“外观”与“控件逻辑”分开管理——一个控件的结构、行为是固定的，但外观由一组“属性→值”的样式决定，可以随时替换。交互效果的本质，就是对象在切换到不同状态时，自动选用对应状态的样式。

**怎么判断**：凡是和“看起来怎么样”有关的（颜色、圆角、边框、阴影、透明度、字体），都通过样式设置；和“放在哪里、占多大”有关的，用第 3 章的大小/位置/对齐。

## 样式添加

**样式添加方式一**（课件原文，分三步）：

**第 1 步：初始化样式**。样式存储在 lv_style_t 结构体中；样式变量应该是静态的、全局的、或者动态分配的——**不能是函数中的局部变量**，因为函数执行结束时会将其销毁。

```c
static lv_style_t style;   /* style: 样式变量（必须 static/全局/动态分配） */
lv_style_init(&style);
```

**第 2 步：给样式变量设置样式属性**。属性设置接口格式为 `lv_style_set_样式名称(&style, 样式值);`：

- 设置背景颜色的样式名称是 bg_color → 接口为 `lv_style_set_bg_color(&style, color);`
- 设置背景透明度的样式名称是 bg_opa → 接口为 `lv_style_set_bg_opa(&style, opa);`

**第 3 步：将样式应用到对象**：

```c
lv_obj_add_style(obj, &style, 生效的条件 | 应用的部分 ...);
```

其中第三个参数是“生效的条件 | 应用的部分”（状态 | 部件部分），详见 4.3 与 4.4。

**样式添加方式二**（课件原文，一步完成）：

```c
lv_obj_set_style_样式名称(obj, 样式值, 生效的条件|应用的部分...);
/* 例如： */
lv_obj_set_style_bg_color(obj, lv_color_hex(0x2196F3), LV_STATE_DEFAULT | LV_PART_MAIN);
```

**方式一的优点：共享性**（课件强调）。同一个样式对象可以 add 到多个部件上：改样式对象一处，所有引用它的部件外观一起变，而且只占一份内存。

**怎么判断**：多个部件需要相同外观（如一组按钮统一样式）→ 用方式一定义共享样式；只改某一个部件 → 用方式二更简洁。注意样式变量声明周期：放函数里会被销毁，务必 static/全局。

## 样式生效状态

**是什么**：添加样式时的“生效条件”就是对象的状态（LV_STATE\_\*）。同一个属性可以为不同状态设置不同值，对象处于哪个状态，就显示哪个状态的样式。

**状态枚举**（课件原文）：

| 状态 | 值 | 含义 |
|-|-|-|
| LV_STATE_DEFAULT | 0x0000 | 默认状态 |
| LV_STATE_CHECKED | 0x0001 | 切换或选中状态 |
| LV_STATE_FOCUSED | 0x0002 | 通过键盘、编码器聚焦，或通过触摸板、鼠标单击 |
| LV_STATE_FOCUS_KEY | 0x0004 | 通过键盘、编码器聚焦 |
| LV_STATE_EDITED | 0x0008 | 由编码器编辑 |
| LV_STATE_HOVERED | 0x0010 | 鼠标悬停（当前版本不支持） |
| LV_STATE_PRESSED | 0x0020 | 已按下 |
| LV_STATE_SCROLLED | 0x0040 | 滚动状态 |
| LV_STATE_DISABLED | 0x0080 | 禁用状态 |

**原理**：状态是位标志，对象的 state 字段记录当前状态；交互或代码切换状态时，LVGL 自动重新计算外观，选用“当前状态下优先级最高的样式值”。通常为 DEFAULT 设置基础外观，再为 PRESSED/CHECKED/DISABLED 等设置交互变体。

**示例**（按下时背景变深、禁用时变灰）：

```c
static lv_style_t st_def, st_pr;
lv_style_init(&st_def);  lv_style_set_bg_color(&st_def, lv_color_hex(0x2196F3));
lv_style_init(&st_pr);   lv_style_set_bg_color(&st_pr,  lv_color_hex(0x1565C0));
lv_obj_add_style(btn, &st_def, LV_STATE_DEFAULT);
lv_obj_add_style(btn, &st_pr,  LV_STATE_PRESSED);
```

**怎么判断**：需要交互反馈（按下变色、选中高亮、禁用置灰）→ 为对应状态单独添加样式；只需静态外观 → 只设 DEFAULT 即可。手动切换状态用 lv_obj_add_state(obj, LV_STATE_CHECKED) / lv_obj_clear_state。

## 部件组成

**是什么**：一个复杂的部件由多个“部分（PART）”组成，每个部分可以单独设置样式。比如滑块（课件示意图）就包含主体（LV_PART_MAIN）、指示器（LV_PART_INDICATOR，已滑过的填充区）、旋钮（LV_PART_KNOB，可拖动的小圆块）三部分。

**部件部分枚举**（课件原文）：

| 部分 | 值 | 含义 |
|-|-|-|
| LV_PART_MAIN | 0x000000 | 主体（所有部件都有） |
| LV_PART_SCROLLBAR | 0x010000 | 滚动条 |
| LV_PART_INDICATOR | 0x020000 | 指示器（如滑块/进度条的填充区） |
| LV_PART_KNOB | 0x030000 | 旋钮（如滑块的拖动块） |
| LV_PART_SELECTED | 0x040000 | 选中（如列表选中的条目） |
| LV_PART_ITEMS | 0x050000 | 条目（如按钮矩阵中的每个按钮） |
| LV_PART_TICKS | 0x060000 | 刻度 |
| LV_PART_CURSOR | 0x070000 | 光标（如文本输入区的光标） |
| LV_PART_CUSTOM_FIRST | 0x080000 | 自定义部分的起始值 |
| LV_PART_ANY | 0x0F0000 | 任意部分 |

**用法**：样式添加接口的第三参数“生效的条件 | 应用的部分”就是**状态（4.3）与部分（4.4）用 | 组合**，例如给滑块旋钮设颜色：

```c
lv_obj_add_style(slider, &style_knob, LV_PART_KNOB | LV_STATE_DEFAULT);
/* 或直接接口： */
lv_obj_set_style_bg_color(slider, lv_color_hex(0xFFFFFF), LV_PART_KNOB);
```

**原理**：每个部件内部把自己的区域划分成若干部分分别绘制；样式按“部分+状态”的 selector 匹配，互不影响。

**怎么判断**：想定制滚动条颜色、滑块填充色、旋钮大小、列表选中背景等局部外观 → 用对应 PART 的 selector；只改整体外观 → LV_PART_MAIN 即可。

# 部件基本属性(事件)

本章讲事件（events）：事件是 LVGL 让用户代码响应交互的核心机制——用户点击、滚动、值变化时，LVGL 触发事件，用户通过回调函数处理。5.1 讲事件是什么、怎么分类、怎么添加；5.2 讲事件回调里怎么取出数据、以及发送/删除事件。

## 事件(events)1

**1、什么是事件**（课件原文）：当用户发生感兴趣的操作时，LVGL 可以触发事件，让用户进行事件的处理。例如：一个对象被点击、被滚动、值发生变化等等。

**2、事件分类**（课件原文，LVGL 中事件分为以下几类）：

- **输入设备事件**：来自触摸、鼠标、键盘、编码器等的输入（按下、释放、点击、长按、滚轮……）
- **绘制事件**：对象绘制前后（LV_EVENT_DRAW_MAIN_BEGIN / DRAW_MAIN_END 等），可用于在绘制阶段加特效
- **其它活动**：对象生命周期与行为相关（创建、删除、布局、滚动、值变化、焦点……）
- **特别活动**：删除对象、释放资源等特殊时刻（LV_EVENT_DELETE 等）
- **自定义事件**：用户自己定义的事件码（LV_EVENT_USER + 偏移），用于对象间通信

**3、添加事件**（课件原文）：

```c
lv_obj_add_event_cb(obj, event_cb, event_code, user_data);
```

- obj：要监听事件的对象
- event_cb：回调函数，原型为 `void event_cb(lv_event_t *e)`
- event_code：要监听的事件码，如 LV_EVENT_CLICKED（点击完成）、LV_EVENT_VALUE_CHANGED（值变化）；传 LV_EVENT_ALL 可监听该对象全部事件
- user_data：用户自定义数据，回调里用 lv_event_get_user_data(e) 取回

**常用输入/活动事件码**（补充）：LV_EVENT_PRESSED（按下）、LV_EVENT_RELEASED（释放）、LV_EVENT_CLICKED（点击完成=按下后释放）、LV_EVENT_VALUE_CHANGED（值改变，滑块/开关/文本框等用）、LV_EVENT_READY（确认输入，如键盘回车）、LV_EVENT_FOCUSED / LV_EVENT_DEFOCUSED（获得/失去焦点）。

**原理**：事件采用“订阅-派发”模式：对象内部维护一个事件回调链表，lv_obj_add_event_cb 把回调挂到链表上；当系统检测到相应动作时调用 lv_event_send 派发事件，链表上的回调按注册顺序依次执行。

**怎么判断**：所有用户交互逻辑（点击按钮做什么、滑块动了怎么响应）都写在事件回调里，不要用轮询循环去查按钮状态。注：课件中写的是 lv_obj_add_eventCb，规范写法是 lv_obj_add_event_cb（全小写下划线）。

## 事件(events)2

**1、lv_event_t 是什么**（课件原文）：lv_event_t 是传递给事件回调函数的唯一参数，它包含有关事件的所有数据，可以在回调中从中获取。

**2、可获取的数据**（课件原文）：

```c
lv_event_get_code(e);       /* 获取当前触发的事件码 */
lv_event_get_target(e);      /* 获取被触发的对象（lv_obj_t*） */
lv_event_get_user_data(e);   /* 获取用户传递的数据（void*） */
```

**3、发送事件与删除事件**（课件原文）：

```c
lv_event_send(obj, event_code, user_data);   /* 向对象手动发送一个事件 */
lv_obj_remove_event_cb(obj, event_cb);        /* 删除对象上的某个事件回调 */
```

**完整示例**（补充，点击按钮后更新标签）：

```c
static void btn_event_cb(lv_event_t *e) {
    lv_event_code_t code = lv_event_get_code(e);   /* 判断事件类型 */
    if (code == LV_EVENT_CLICKED) {
        lv_obj_t *btn = lv_event_get_target(e);    /* 拿到被点击的对象 */
        static int cnt = 0;
        cnt++;
        lv_label_set_text_fmt(label, "点击次数: %d", cnt);
    }
}
lv_obj_add_event_cb(btn, btn_event_cb, LV_EVENT_ALL, NULL);
```

**原理**：回调统一接收一个 lv_event_t\* 参数，事件码、目标对象、用户数据都打包在里面，所以一个回调可以同时监听多个对象、多个事件，用 get_code / get_target 区分即可。事件是沿着对象树冒泡的：子部件触发的事件，父对象的回调也能收到。

**怎么判断**：多个对象共用一个回调（如一排按钮）→ 注册同一个回调，回调里用 lv_event_get_target(e) 判断是哪个对象触发的；需要主动通知别的对象（如滑块变化后通知仪表刷新）→ 用 lv_event_send 手动发事件；不再需要响应 → lv_obj_remove_event_cb 移除。

# 样式属性(部件大小和移动)

上一章的样式接口（lv_style_set_样式名称 / lv_obj_set_style_样式名称）可以设置的属性有哪些？本章先给出总览（大小、位置、填充、背景、阴影、轮廓、边框……），再详细讲与“大小和移动”相关的样式属性：基础尺寸、变换宽高、平移、缩放旋转，最后讲对象的盒子模型。后两章继续讲边框/填充/轮廓和阴影/背景/flags。

## 大小、位置、对齐

**是什么**：第 3 章的大小、位置、对齐，同样可以当作“样式属性”来设置，从而获得“按状态/按部分生效”的能力。

**设置接口**（课件原文，两种方式）：

```c
lv_style_set_样式名称(&style, 样式值);              /* 方式一：设置到样式对象 */
lv_obj_set_style_样式名称(obj, 样式值, 生效的条件|应用的部分...); /* 方式二：直接设置 */
```

**样式名称**（课件原文）：

- width（宽度）、height（高度）
- min_width / max_width（最小/最大宽度）、min_height / max_height（最小/最大高度）
- x、y（位置坐标）
- align（对齐方式）

**示例**：

```c
lv_obj_set_style_width(obj, 200, LV_STATE_DEFAULT);
lv_obj_set_style_height(obj, lv_pct(50), LV_STATE_DEFAULT); /* 高度=父对象50% */
lv_obj_set_style_align(obj, LV_ALIGN_CENTER, LV_STATE_DEFAULT);
```

**原理**：直接 API（lv_obj_set_width 等）内部就是调用对应的样式设置接口，把值写进对象的本地样式；区别在于样式方式可以绑定“状态/部分”，从而同一属性在不同状态下有不同值。

**怎么判断**：只需要固定一个值 → 直接 API 更直观；需要“按下时变大、选中时变位置”这类随状态变化 → 用 lv_obj_set_style\_\* 并指定对应 LV_STATE\_\*。

## 变化宽度和高度

**是什么**：变换宽度和高度——在不改变对象“真实布局尺寸”的前提下，绘制时临时把宽高扩大或缩小。

**样式名称**（课件原文）：

```c
lv_obj_set_style_transform_width(obj, 值, LV_STATE_DEFAULT);   /* 绘制时宽度增加/减少 */
lv_obj_set_style_transform_height(obj, 值, LV_STATE_DEFAULT);
```

值为正表示向外扩大，为负表示向内收缩（单位像素）。

**原理**：以 transform 开头的属性都属于“绘制期变换”——只在渲染阶段对图形做几何变形，对象记录的实际 coords（坐标区域）不变，因此不影响兄弟对象的布局位置，也不会触发父对象重新布局。

**示例**（按钮按下时四周各放大 3 像素）：

```c
lv_obj_set_style_transform_width(btn, 3, LV_STATE_PRESSED);
lv_obj_set_style_transform_height(btn, 3, LV_STATE_PRESSED);
```

**怎么判断**：想要“按下的瞬间鼓一下”这类动态反馈 → 用 transform_width/height 配合 PRESSED 状态；想要真正改变布局尺寸（影响兄弟对象）→ 用 6.1 的 width/height。

## 部件移动

**是什么**：部件移动——在对象当前位置基础上做“平移偏移”，不修改对象记录的真实坐标。

**样式名称**（课件原文）：

```c
lv_obj_set_style_translate_x(obj, 值, LV_STATE_DEFAULT);  /* 相对当前位置水平偏移 */
lv_obj_set_style_translate_y(obj, 值, LV_STATE_DEFAULT);  /* 相对当前位置垂直偏移 */
```

值为正向右/向下偏移，为负向左/向上偏移（单位像素）。

**原理**：translate_x/y 是绘制期平移，和对象的 x/y 坐标叠加后才是实际显示位置；它不改变 x/y 本身，也不影响兄弟对象布局（类似 6.2 的 transform 系列）。

**示例**（按钮按下时下沉 2 像素，模拟“被按下去”）：

```c
lv_obj_set_style_translate_y(btn, 2, LV_STATE_PRESSED);
```

**怎么判断**：瞬时/交互性位移（按下下沉、悬停浮起）→ translate_x/y（不破坏布局）；永久改变位置 → lv_obj_set_pos / style x/y（改真实坐标，见 3.2 与 6.1）。

## 缩放和旋转

**是什么**：对象的缩放与旋转，用于制作放大缩小、旋转等视觉变换效果。

**样式名称**（课件原文）：

```c
lv_obj_set_style_transform_zoom(obj, 256, LV_STATE_DEFAULT);  /* 缩放：256=100% */
lv_obj_set_style_transform_angle(obj, 300, LV_STATE_DEFAULT); /* 旋转：单位0.1°，300=30° */
```

补充两个配合属性：

- transform_pivot_x / transform_pivot_y：旋转与缩放的中心点（默认是对象中心）

**示例**（图标持续旋转效果配合动画）：

```c
lv_obj_set_style_transform_angle(icon, 450, LV_STATE_DEFAULT); /* 旋转45° */
lv_obj_set_style_transform_zoom(icon, 384, LV_STATE_DEFAULT);  /* 放大150% */
```

**原理**：transform_zoom/angle 同属绘制期变换，渲染时对像素做缩放/旋转，对象实际坐标区域不变，兄弟对象不受影响。zoom 的基准值 256 表示 100%（2 的 8 次方，用整数避免浮点运算）。

**怎么判断**：做图标旋转、按钮按压缩放、加载动画 → 用 transform_zoom/angle；注意变换不影响点击判定区域（命中测试仍按原矩形），需要精确点击时配合事件处理；想要真正的布局尺寸变化还是用 width/height。

## 对象的盒子模型

**是什么**：对象的盒子模型描述一个对象的空间构成（课件 CSS 盒模型图）：

1. Content area 内容区：真正放内容（文字/子对象）的区域，示例 230×80 px
2. Padding 内边距：内容区到边框的距离，示例四边各 30 px
3. Border 边框：最外层边缘线，示例 5 px
4. Outline 轮廓：画在边框之外的一圈描边，示例 5 px（不参与空间计算）

**尺寸关系**（课件示例：总宽 300 px、总高 150 px）：

- 总宽度 = 内容区宽 + 2×左/右内边距 + 2×左/右边框 = 230 + 60 + 10 = 300 px
- 总高度 = 内容区高 + 2×上/下内边距 + 2×上/下边框 = 80 + 60 + 10 = 150 px
- 轮廓（Outline）画在最外层，不占布局空间、不改变对象尺寸

**原理**：LVGL 的布局计算与 CSS 盒模型一致：子对象的坐标原点在父对象的内容区左上角（内边距内侧）；父对象自适应大小时（LV_SIZE_CONTENT）也会把内边距和边框计算进去。

**怎么判断**：给控件定位或计算父对象大小时，先分清“对象总尺寸”和“内容区尺寸”——加了 padding 后内容区变小，子对象/文字会整体内缩；轮廓不影响布局，适合做不改变尺寸的描边装饰。

# 样式属性(边框、填充和轮廓)

本章继续讲样式属性，围绕盒子模型的三层：边框（border）、填充（padding）、轮廓（outline）。结合第 6 章的盒模型图理解：Content（内容区）→ Padding（内边距）→ Border（边框）→ Outline（轮廓），其中 border 和 padding 参与空间计算，outline 只是装饰。

## 边框

**是什么**：边框（border）是画在对象边缘的一圈线，对应盒模型中的 Border 层（课件图：5 px）。边框占据布局空间——它会计算进对象的总体尺寸。

**样式名称**（课件原文）：

```c
lv_obj_set_style_border_color(obj, 颜色, LV_STATE_DEFAULT); /* 边框颜色 */
lv_obj_set_style_border_opa(obj, 透明度, LV_STATE_DEFAULT); /* 边框透明度 */
lv_obj_set_style_border_width(obj, 宽度, LV_STATE_DEFAULT); /* 边框宽度 */
lv_obj_set_style_border_side(obj, 边, LV_STATE_DEFAULT);    /* 显示哪些边 */
```

**border_side 取值**（补充）：LV_BORDER_SIDE_NONE（无）、LV_BORDER_SIDE_LEFT / RIGHT / TOP / BOTTOM（单边）、LV_BORDER_SIDE_FULL（四边，默认）、LV_BORDER_SIDE_INTERNAL（内部格线，表格等用）。多边用 | 组合。

**示例**（给按钮画 2px 蓝色圆角边框）：

```c
lv_obj_set_style_border_width(btn, 2, LV_STATE_DEFAULT);
lv_obj_set_style_border_color(btn, lv_color_hex(0x2196F3), LV_STATE_DEFAULT);
lv_obj_set_style_border_side(btn, LV_BORDER_SIDE_FULL, LV_STATE_DEFAULT);
```

**原理**：边框画在 padding 之外、对象最外缘；设置了 border_width 后对象总尺寸 = 内容区 + 2×padding + 2×border_width（见 6.5 盒模型计算）。

**怎么判断**：需要真实描边、分组框、表格线 → 用 border；如果只是“加一圈不占空间的装饰线”，用 7.3 的 outline 更合适。

## 填充

**是什么**：填充（padding）即内边距，是内容区与边框之间的距离，对应盒模型中的 Padding 层（课件图：四边各 30 px）。它决定“内容被挤出多远、子对象从哪里开始放”。

**样式名称**（课件原文）：

```c
/* 所有部件适用 */
lv_obj_set_style_pad_top(obj, 值, LV_STATE_DEFAULT);    /* 上内边距 */
lv_obj_set_style_pad_bottom(obj, 值, LV_STATE_DEFAULT); /* 下内边距 */
lv_obj_set_style_pad_left(obj, 值, LV_STATE_DEFAULT);   /* 左内边距 */
lv_obj_set_style_pad_right(obj, 值, LV_STATE_DEFAULT);  /* 右内边距 */
/* 针对弹性(Flex)和网格(Grid)布局适用 */
lv_obj_set_style_pad_row(obj, 值, LV_STATE_DEFAULT);    /* 行间距 */
lv_obj_set_style_pad_column(obj, 值, LV_STATE_DEFAULT); /* 列间距 */
```

**示例**（容器四周留 20px，让子控件不贴边）：

```c
lv_obj_set_style_pad_all(box, 20, LV_STATE_DEFAULT); /* LVGL 提供的快捷接口，四边一起设 */
```

**原理**：padding 直接决定内容区大小——内容区 = 对象总尺寸 − 2×padding − 2×border；子对象的坐标原点在父对象内容区的左上角，所以 padding 越大，子对象整体越往内缩；父对象用 LV_SIZE_CONTENT 自适应大小时，也会把 padding 计算进去。

**怎么判断**：文字/子控件“贴边”难看 → 加 pad_top/left/right/bottom；Flex/Grid 布局里想让子项之间有固定间隔 → 用 pad_row / pad_column（第 17 章配合使用）。

## 轮廓

**是什么**：轮廓（outline）是画在边框之外的一圈描边，对应盒模型最外层的 Outline 层（课件图：5 px）。它只是装饰，**不参与布局计算、不改变对象尺寸**。

**样式名称**（课件原文）：

```c
lv_obj_set_style_outline_color(obj, 颜色, LV_STATE_DEFAULT); /* 轮廓颜色 */
lv_obj_set_style_outline_opa(obj, 透明度, LV_STATE_DEFAULT); /* 轮廓透明度 */
lv_obj_set_style_outline_width(obj, 宽度, LV_STATE_DEFAULT); /* 轮廓宽度 */
lv_obj_set_style_outline_pad(obj, 间距, LV_STATE_DEFAULT);   /* 轮廓与边框的距离 */
```

**示例**（焦点时出现外圈高亮）：

```c
lv_obj_set_style_outline_width(btn, 3, LV_STATE_FOCUSED);
lv_obj_set_style_outline_color(btn, lv_color_hex(0xFFC107), LV_STATE_FOCUSED);
lv_obj_set_style_outline_pad(btn, 4, LV_STATE_FOCUSED);
```

**原理**：outline_pad 控制轮廓与边框之间的空隙；绘制时画在对象最外层，但对象的 coords（坐标区域）不含它，所以兄弟对象位置、父对象自适应尺寸都不受影响。

**怎么判断**：需要焦点指示圈、发光描边，又不希望它挤压布局 → 用 outline；需要真实占空间的边线 → 用 7.1 的 border。

# 样式属性(阴影、背景和flags)

本章继续外观类样式属性：阴影（shadow）、背景（background）和两个常用属性（圆角 radius、整体透明度 opa）；后半部分讲对象标志（Flags）——用开关控制对象能力，以及运行时删除对象的三个 API。背景和阴影决定“长什么样”，Flags 决定“能不能点、能不能滚”。

## 阴影

**样式名称**（课件原文）：

```c
lv_obj_set_style_shadow_color(obj, 颜色, LV_STATE_DEFAULT);  /* 阴影颜色 */
lv_obj_set_style_shadow_opa(obj, 透明度, LV_STATE_DEFAULT);  /* 阴影透明度 */
lv_obj_set_style_shadow_width(obj, 宽度, LV_STATE_DEFAULT);  /* 阴影宽度(模糊范围) */
lv_obj_set_style_shadow_spread(obj, 值, LV_STATE_DEFAULT);   /* 阴影扩展(向四周撑大) */
lv_obj_set_style_shadow_ofs_x(obj, 值, LV_STATE_DEFAULT);    /* 阴影水平偏移 */
lv_obj_set_style_shadow_ofs_y(obj, 值, LV_STATE_DEFAULT);    /* 阴影垂直偏移 */
```

**示例**（给卡片加一个向右下偏移的柔和阴影）：

```c
lv_obj_set_style_shadow_color(card, lv_color_hex(0x000000), LV_STATE_DEFAULT);
lv_obj_set_style_shadow_opa(card, LV_OPA_30, LV_STATE_DEFAULT);
lv_obj_set_style_shadow_width(card, 12, LV_STATE_DEFAULT);
lv_obj_set_style_shadow_ofs_x(card, 3, LV_STATE_DEFAULT);
lv_obj_set_style_shadow_ofs_y(card, 4, LV_STATE_DEFAULT);
```

**原理**：shadow_width 决定阴影边缘的模糊扩散范围（类似 CSS 的 blur），shadow_spread 决定阴影区域整体向四周扩展的大小，ofs_x/ofs_y 决定阴影相对对象偏移的方向和距离。阴影画在对象边界外，不占布局空间。

**怎么判断**：想做出“悬浮”的卡片层级感 → 阴影 + 偏移；想要整体淡一点 → 降低 shadow_opa；阴影模糊太重/太轻 → 调 shadow_width。

## 背景

**样式名称**（课件原文）：

```c
lv_obj_set_style_bg_color(obj, 颜色, LV_STATE_DEFAULT);      /* 背景颜色 */
lv_obj_set_style_bg_opa(obj, 透明度, LV_STATE_DEFAULT);      /* 背景透明度 */
lv_obj_set_style_bg_grad_dir(obj, 方向, LV_STATE_DEFAULT);   /* 渐变方向 */
lv_obj_set_style_bg_main_stop(obj, 百分比, LV_STATE_DEFAULT);/* 渐变起始色位置 */
lv_obj_set_style_bg_grad_color(obj, 颜色, LV_STATE_DEFAULT); /* 渐变结束色 */
lv_obj_set_style_bg_grad_stop(obj, 百分比, LV_STATE_DEFAULT);/* 渐变结束色位置 */
```

**原理**：bg_grad_dir 可选 LV_GRAD_DIR_NONE（无渐变）/ HOR（水平渐变）/ VER（垂直渐变）。设了渐变方向后，背景从 main_stop 处的 bg_color 渐变到 grad_stop 处的 bg_grad_color；main_stop/grad_stop 用百分比控制两个颜色的位置。不设渐变时只用 bg_color。

**示例**（从上到下的蓝→青渐变背景）：

```c
lv_obj_set_style_bg_color(obj, lv_color_hex(0x1565C0), LV_STATE_DEFAULT);
lv_obj_set_style_bg_grad_color(obj, lv_color_hex(0x00BCD4), LV_STATE_DEFAULT);
lv_obj_set_style_bg_grad_dir(obj, LV_GRAD_DIR_VER, LV_STATE_DEFAULT);
```

**怎么判断**：纯色背景只设 bg_color + bg_opa；需要层次感/视觉引导 → 加渐变（多数场景只需设方向+两个颜色）。

## 其它

**样式名称**（课件原文）：

```c
lv_obj_set_style_radius(obj, 值, LV_STATE_DEFAULT); /* 圆角半径，像素；LV_RADIUS_CIRCLE=圆形 */
lv_obj_set_style_opa(obj, 值, LV_STATE_DEFAULT);    /* 对象整体透明度 0-255 */
```

**原理**：radius 同时作用于背景、边框、阴影的圆角；opa 是“整体透明度”，作用于对象自身及其所有绘制内容（不同于 bg_opa 只作用于背景）。

**怎么判断**：做圆角卡片/胶囊按钮 → radius；做整块淡入淡出/半透明遮挡层 → opa。

## 对象的标志(flags)

**是什么**：在 LVGL 中，部件的某些属性可以通过控制 Flags 来启用/禁用。Flags 是对象能力的总开关，用 `lv_obj_add_flag / lv_obj_clear_flag` 开关。

- **显示与交互**：LV_OBJ_FLAG_HIDDEN（隐藏对象，就像它根本不存在一样）、LV_OBJ_FLAG_CLICKABLE（使对象可被输入设备点击）、LV_OBJ_FLAG_CLICK_FOCUSABLE（单击时为对象添加聚焦状态）、LV_OBJ_FLAG_CHECKABLE（当对象被点击时切换选中状态）、LV_OBJ_FLAG_PRESS_LOCK（即使按压装置从物体上滑落，也能保持物体被按压）
- **滚动相关**：LV_OBJ_FLAG_SCROLLABLE（使对象可滚动）、LV_OBJ_FLAG_SCROLL_ELASTIC（允许内部滚动，但速度较慢）、LV_OBJ_FLAG_SCROLL_MOMENTUM（让物体在“抛出”时滚动得更远）、LV_OBJ_FLAG_SCROLL_ONE（仅允许滚动一个可捕捉的子元素）、LV_OBJ_FLAG_SCROLL_CHAIN_HOR（允许将水平滚动传播到父级）、LV_OBJ_FLAG_SCROLL_CHAIN_VER（允许将垂直滚动传播到父级）、LV_OBJ_FLAG_SCROLL_CHAIN（简单包装为 SCROLL_CHAIN_HOR | SCROLL_CHAIN_VER）、LV_OBJ_FLAG_SCROLL_ON_FOCUS（自动滚动对象以使其在聚焦时可见）、LV_OBJ_FLAG_SCROLL_WITH_ARROW（允许使用箭头键滚动焦点对象）
- **其它**：LV_OBJ_FLAG_SNAPPABLE（如果父对象上启用了滚动捕捉，它可以捕捉到此对象）

**添加 / 取消 Flag**（课件原文）：

```c
lv_obj_add_flag(obj, flag);   /* 添加/启用某个标志 */
lv_obj_clear_flag(obj, flag); /* 取消/禁用某个标志 */
```

**示例**（默认创建的对象带 HIDDEN，创建后通常要清掉；让容器可滚动、子对象可捕捉）：

```c
lv_obj_clear_flag(obj, LV_OBJ_FLAG_HIDDEN);      /* 让隐藏的对象显示出来 */
lv_obj_add_flag(cont, LV_OBJ_FLAG_SCROLLABLE);   /* 让容器可滚动 */
lv_obj_add_flag(child, LV_OBJ_FLAG_SNAPPABLE);   /* 让子对象参与滚动捕捉 */
```

**怎么判断**：对象“看不见/点不到/滚不动”时，先检查对应 Flag 是否被清掉或没加；HIDDEN 与透明（opa=0）不同——HIDDEN 对象完全不参与布局和交互，opa=0 的对象仍占位。

**删除对象**（课件原文，LVGL 支持在运行时动态创建和删除对象）：

```c
lv_obj_del(obj);              /* 删除对象及其所有子对象 */
lv_obj_clean(obj);            /* 删除对象的所有子对象，但不删除对象本身 */
lv_obj_del_delayed(obj, ms);  /* 一段时间后删除对象，延迟以毫秒为单位 */
```

**原理**：删除对象时，LVGL 会向对象发送 LV_EVENT_DELETE 事件并释放其内存；lv_obj_clean 常用于“清空一个容器重新填充内容”。

**怎么判断**：页面切换/动态列表 → lv_obj_del 整棵删除；只刷新内容、容器还在 → lv_obj_clean；提示框等需要先显示再消失 → lv_obj_del_delayed 延迟删除，比手动计时器简单。

# 核心部件(标签和按钮)

从本章起进入核心部件。课件《01_核心部件》是一个总课件（Label、Button、Switch、Line、Checkbox、Slider……共 23 个部件），对应飞书第 9～16 章；本章只处理其中的**标签 lv_label** 和**按钮 lv_btn**，其余部件在后续章节对应展开。核心部件的学习主线是固定的：创建 → 设置数据 → 样式 → 事件。

## 重新配置工程

本节课件未包含“重新配置工程”的正文内容，该环节属于工程实践操作（在第 1 章模拟器工程基础上配置字体/分辨率等），课件在此直接进入标签部件讲解。如工程配置遇到问题，可回看第 1 章的模拟器搭建与 lv_conf.h 配置。

## 标签(lv_label)\_1

**概述**（课件原文）：标签部件是用于显示文本的基本对象类型，其实就是用于显示文本，例如标题、提示信息等。

**组成**（课件原文，标签由三个部分构成）：

- **主体 LV_PART_MAIN**：就是一个矩形的背景
- **滚动条 LV_PART_SCROLLBAR**：当文本的长度超过标签部件本身的大小时，会出现滚动条
- **所选文本 LV_PART_SELECTED**：被选中的文本部分

**创建标签部件**（课件原文）：

```c
lv_obj_t *label1 = lv_label_create(parent);
```

**设置文本的 4 种方式**（课件原文）：

```c
lv_label_set_text(label1, "text");                 /* 直接设置文本，存储文本的内存动态分配 */
lv_label_set_text_static(label1, "text");          /* 文本不存储在动态内存，而是在指定的缓冲区中 */
lv_label_set_text_fmt(label1, "占位符", val);       /* 格式化文本显示，如 lv_label_set_text_fmt(l, "%d 个", cnt) */
lv_label_set_text(label1, "line1\nline2\nline3"); /* 换行显示，\n 分隔各行 */
```

**怎么判断用哪种**：文本会反复改（倒计时、计数）→ set_text 动态分配最省事，但频繁调用会产生内存碎片；文本是固定常量（标题、按钮文字）→ set_text_static 直接指向常量区，不占堆内存；要拼变量 → set_text_fmt 格式化最方便。

## 标签(lv_label)\_2

**文本样式**（课件原文，标签的样式属性）：

- 背景颜色：bg_color
- 字体类型：text_font
- 文本颜色：text_color
- 文本对齐：text_align

**对齐取值**（课件原文枚举）：LV_TEXT_ALIGN_AUTO（自动）/ LV_TEXT_ALIGN_LEFT（左对齐）/ LV_TEXT_ALIGN_CENTER（居中）/ LV_TEXT_ALIGN_RIGHT（右对齐），类型为 lv_text_align_t（uint8_t）。

**文字装饰**（课件原文枚举）：LV_TEXT_DECOR_NONE = 0x00（无装饰）/ LV_TEXT_DECOR_UNDERLINE = 0x01（下划线）/ LV_TEXT_DECOR_STRIKETHROUGH = 0x02（删除线），多个装饰用 | 组合。

```c
lv_obj_set_style_text_color(label1, lv_color_hex(0xFF0000), LV_STATE_DEFAULT);
lv_obj_set_style_text_align(label1, LV_TEXT_ALIGN_CENTER, LV_STATE_DEFAULT);
lv_obj_set_style_text_decor(label1, LV_TEXT_DECOR_UNDERLINE, LV_STATE_DEFAULT);
```

**单独给个别文本着色**（课件原文，recolor 功能）：

```c
lv_label_set_recolor(label1, true);            /* 开启重着色 */
lv_label_set_text(label1, "#ff0000 红字# 和普通字"); /* 两个 # 之间的文本用 # 后颜色显示 */
```

**原理**：recolor 开启后，LVGL 在渲染文本时解析 `#颜色值 文本#` 片段，把该片段按指定颜色绘制，其余文本用默认 text_color——同一行文字可以出现多种颜色，而不用拆成多个 label。

## 标签(lv_label)\_3

**长文本模式**（课件原文）：默认情况下，如果没有设置标签的大小，它的大小会根据文本的大小自动扩充。文本长度超过部件大小时，用 lv_label_set_long_mode 设置显示方式：

| 模式 | 行为 |
|-|-|
| LV_LABEL_LONG_WRAP | 自动换行（默认模式） |
| LV_LABEL_LONG_DOT | 将标签右下角最后 3 个字符替换为省略号 … |
| LV_LABEL_LONG_SCROLL | 文本来回滚动 |
| LV_LABEL_LONG_SCROLL_CIRCULAR | 文本循环滚动 |
| LV_LABEL_LONG_CLIP | 直接剪切掉部件外面的文本 |

**文本选择**（课件原文）：如果启用 LV_LABEL_TEXT_SELECTION，则可进行 label 的文本选择（类似 PC 上用鼠标选择文本）。但选择交互只在文本框 lv_textarea 中实现；label 只能事先通过代码手动选择：

```c
lv_label_set_text_sel_start(label1, start_char_index); /* 设置选择起点（字符索引） */
lv_label_set_text_sel_end(label1, end_char_index);     /* 设置选择终点 */
```

**显示中文字体**（课件原文）：使用 LVGL 内置的中文字体库，或添加自己的中文字体库：1）准备字体文件；2）使用 LVGL 官网的字体转换工具进行转换；3）将转换出来的字体文件移植到工程中。

**怎么判断**：长文本固定区域 → WRAP 或 DOT；滚动字幕 → SCROLL / SCROLL_CIRCULAR；只想截断 → CLIP。中文不显示/显示方块 → 字体没包含中文字形，需换中文字体。

## 按钮(lv_btn)

**概述**（课件原文）：按键与基础对象(obj)相比，没有新增加新的功能和样式属性。

**组成**（课件原文）：主体 LV_PART_MAIN，就是一个矩形的背景。

**创建部件与功能描述**（课件原文）：

```c
lv_obj_t *btn1 = lv_btn_create(parent);          /* 创建按钮 */
lv_obj_t *label = lv_label_create(btn1);         /* 按钮上放一个标签 */
lv_label_set_text(label, "确定");                /* 按键的功能描述信息，需要通过 label 标签部件完成 */
```

**添加样式**（课件原文）：利用前面所讲的样式属性（背景、边框等）进行添加即可——按钮没有专属样式，主体背景/边框/圆角/阴影都走通用样式接口。

**事件**（课件原文）：LV_EVENT_VALUE_CHANGED：当 LV_OBJ_FLAG_CHECKABLE 标志被开启时，该事件在选中/未选中状态发生转换时产生（即按钮变成可切换的“开关式”按钮）。

```c
lv_obj_add_flag(btn1, LV_OBJ_FLAG_CHECKABLE);    /* 开启可选中，点击后保持选中态 */
lv_obj_add_event_cb(btn1, btn_cb, LV_EVENT_VALUE_CHANGED, NULL); /* 状态切换时回调 */
```

**怎么判断**：按钮的“功能”全部靠事件回调实现（第 5 章），创建+文字只是外观；要“按下去后保持按下”的开关效果 → 加 CHECKABLE 标志并监听 VALUE_CHANGED。

## 综合示例

本节课件未提供独立综合示例，下面补充一个“标签 + 按钮”的联动小例子（按钮点击，标签计数 +1）：

```c
static lv_obj_t *count_label;

static void btn_cb(lv_event_t *e) {
    static int cnt = 0;
    cnt++;
    lv_label_set_text_fmt(count_label, "点击次数: %d", cnt);  /* 格式化更新标签 */
}

void demo_label_btn(lv_obj_t *parent) {
    count_label = lv_label_create(parent);
    lv_label_set_text(count_label, "点击次数: 0");
    lv_obj_align(count_label, LV_ALIGN_CENTER, 0, -40);

    lv_obj_t *btn = lv_btn_create(parent);
    lv_obj_t *lb = lv_label_create(btn);
    lv_label_set_text(lb, "点我");
    lv_obj_center(lb);
    lv_obj_align(btn, LV_ALIGN_CENTER, 0, 20);
    lv_obj_add_event_cb(btn, btn_cb, LV_EVENT_CLICKED, NULL);  /* 点击事件 */
}
```

**拆解**：① label 先建、对齐在上方；② 按钮内嵌 label 显示文字，按钮本身用样式属性做外观；③ 事件回调里用 lv_label_set_text_fmt 动态改文本——正好用上 9.2 的格式化接口。这个组合就是绝大多数界面“按钮 + 文案反馈”的基本套路。

# 核心部件(开关、线条和复选框)

核心部件第二讲：开关（lv_switch）、线条（lv_line）、复选框（lv_checkbox）。三者学习主线与前章相同：创建 → 设置数据 → 样式 → 事件；区别在于各自“部件特有”的组成部分和 API。

## 开关(lv_switch)

**概述**（课件原文）：开关看起来像一个小滑块，可以用来打开或者是关闭某些东西。

**组成**（课件原文）：主体 LV_PART_MAIN（矩形背景）、指示器 LV_PART_INDICATOR、句柄 LV_PART_KNOB。

```c
lv_obj_t *sw1 = lv_switch_create(parent);
```

**样式与事件**（课件原文）：样式利用前面所讲的样式属性（背景、边框等）添加即可；LV_EVENT_VALUE_CHANGED 事件在选中/未选中状态发生转换时产生。

```c
static void sw_cb(lv_event_t *e) {
    lv_obj_t *sw = lv_event_get_target(e);
    bool on = lv_obj_has_state(sw, LV_STATE_CHECKED);  /* CHECKED=打开 */
    /* 根据 on 做业务处理，如点亮图标/改标签 */
}
lv_obj_t *sw1 = lv_switch_create(parent);
lv_obj_add_event_cb(sw1, sw_cb, LV_EVENT_VALUE_CHANGED, NULL);
```

**怎么判断**：开关没有自己的“值”接口，状态就看 LV_STATE_CHECKED（选中=开）；想改滑块/轨道颜色 → 分别给 LV_PART_KNOB / LV_PART_INDICATOR 设样式。

## 线条(lv_line)

**概述**（课件原文）：line 对象，可以在一组坐标点之间，依次绘制直线。

**组成**（课件原文）：主体 LV_PART_MAIN。

**创建与坐标点**（课件原文）：用 lv_point_t 定义数组存储坐标点，再通过 lv_line_set_points 传给对象：

```c
lv_obj_t *line1 = lv_line_create(parent);          /* 创建线条 */
static lv_point_t points[] = {{10, 10}, {50, 90}, {90, 20}}; /* 坐标点数组 */
lv_line_set_points(line1, points, 3);              /* 传递点数组与点数，依次连线 */
```

**线条样式属性**（课件原文）：

- line_width：线条宽度
- line_rounded：线条两端圆角
- line_color：线条颜色
- line_opa：线条透明度

**翻转 Y 坐标**（课件原文）：`lv_line_set_y_invert(line, true);`——默认 y 轴向下（与屏幕一致），翻转后 y 坐标向上增长，方便按数学坐标系绘图。

**虚线**（课件原文）：仅限水平和垂直方向，通过样式属性设置：line_dash_width（各点宽度）、line_dash_gap（间隙大小）。

```c
lv_obj_set_style_line_dash_width(line1, 5, LV_STATE_DEFAULT);
lv_obj_set_style_line_dash_gap(line1, 3, LV_STATE_DEFAULT);
```

**怎么判断**：画折线/波形 → line + 点数组（点数组变量要一直存活）；要画斜虚线 → 不支持，虚线只限横/竖方向。

## 复选框(lv_checkbox)

**概述**（课件原文）：复选框常用于进行功能的选中，单击复选框时进行状态的切换；checkbox 由复选框和标签创建。

**组成**（课件原文）：主体 LV_PART_MAIN（包括矩形背景和标签）、指示器 LV_PART_INDICATOR（正方形勾选框）。

**创建与常用操作**（课件原文）：

```c
lv_obj_t *checkbox = lv_checkbox_create(lv_scr_act());          /* 1. 创建 */
lv_checkbox_set_text(checkbox, "文本");                          /* 2. 修改复选框文本 */
lv_obj_set_style_pad_column(checkbox, 40, LV_STATE_DEFAULT | LV_PART_MAIN); /* 3. 调整复选框和标签的距离 */
```

**指示器（勾选框）外观定制**（课件原文）：

```c
lv_obj_set_style_pad_all(checkbox, 10, LV_STATE_DEFAULT | LV_PART_INDICATOR); /* 4. 设置指示器大小（padding 越大框越大） */
lv_obj_set_style_radius(checkbox, LV_RADIUS_CIRCLE, LV_STATE_DEFAULT | LV_PART_INDICATOR); /* 5. 修改指示器为圆形 */
lv_obj_set_style_bg_img_src(checkbox, NULL, LV_STATE_CHECKED | LV_PART_INDICATOR); /* 6. 取消勾选状态时的 √ */
```

**手动添加 / 取消状态**（课件原文）：

```c
lv_obj_add_state(checkbox, LV_STATE_CHECKED | LV_STATE_DISABLED); /* 手动勾选并禁用 */
lv_obj_clear_state(checkbox, LV_STATE_DISABLED);                  /* 取消禁用 */
```

**原理**：勾选框是基础对象 + 一个正方形指示器（INDICATOR）+ 一个标签的组合；勾选状态用 LV_STATE_CHECKED 表达，√ 是指示器背景图（bg_img_src），所以“取消√”就是把该状态下的背景图设为 NULL。

**怎么判断**：读勾选状态用 lv_obj_has_state(chk, LV_STATE_CHECKED)；监听切换用 LV_EVENT_VALUE_CHANGED（与开关一致）。

# 核心部件(滑动条、进度条和圆弧)

核心部件第三讲：滑动条（lv_slider）、进度条（lv_bar）、圆弧（lv_arc）。三者都是“有值、有范围、有指示器”的部件，区别在于：slider 可交互调值，bar 只显示进度，arc 用圆弧显示/调节。

## 滑动条(lv_slider)

**概述**（课件原文）：滑块部件常用于调节某个参数的值，可以通过拖动旋钮的方式来进行调节。

**组成**（课件原文）：主体 LV_PART_MAIN、指示器 LV_PART_INDICATOR、操作句柄 LV_PART_KNOB。

**创建与基本设置**（课件原文）：

```c
lv_obj_t *slider = lv_slider_create(lv_scr_act());                      /* 1. 创建 */
lv_obj_set_style_pad_all(slider, 4, LV_STATE_DEFAULT | LV_PART_MAIN);  /* 2. 改变指示器大小：主体填充越大，指示器越小 */
lv_obj_set_style_pad_all(slider, 10, LV_STATE_DEFAULT | LV_PART_KNOB); /* 3. 改变旋钮大小：改旋钮的填充即可 */
```

**值与范围**（课件原文）：

```c
lv_slider_set_range(slider, min, max);        /* 4. 指定滑块值的范围 */
lv_slider_get_value(slider);                  /* 5. 获取滑块的当前值 */
lv_slider_set_value(slider, 150, LV_ANIM_OFF);/* 6. 设置滑块的当前值 */
```

**模式与高级项**（课件原文）：

- 模式：LV_SLIDER_MODE_NORMAL（普通）/ LV_SLIDER_MODE_SYMMETRICAL（对称，0 在中间）/ LV_SLIDER_MODE_RANGE（区间，可设左右两个值）
- 左右值（RANGE 模式）：`lv_slider_set_left_value(slider, 100, LV_ANIM_OFF);` / `lv_slider_get_left_value(slider);`
- 仅旋钮模式：`lv_obj_add_flag(slider, LV_OBJ_FLAG_ADV_HITTEST);`（只有旋钮区域可点击拖动）
- 扩展旋钮可点击区域：`lv_obj_set_ext_click_area(slider, value);`

**事件**（补充）：拖动改变值时触发 LV_EVENT_VALUE_CHANGED，回调里用 lv_slider_get_value 取当前值。

**怎么判断**：需要用户拖拽调节 → slider；只是展示进度不交互 → 用 11.2 的 bar。

## 进度条(lv_bar)

**概述**（课件原文）：进度条部件常用于显示某个任务的完成进度。

**组成**（课件原文）：主体 LV_PART_MAIN、指示器 LV_PART_INDICATOR。

**创建与设置**（课件原文）：

```c
lv_obj_t *bar = lv_bar_create(lv_scr_act());                          /* 1. 创建 */
lv_bar_set_range(bar, min, max);                                      /* 2. 设置范围 */
lv_bar_set_value(bar, new_value, LV_ANIM_ON);                         /* 2. 设置当前值（LV_ANIM_ON=动画过渡） */
lv_obj_set_style_pad_all(bar, 4, LV_STATE_DEFAULT | LV_PART_MAIN);    /* 3. 改变指示器大小：主体填充越大，指示器越小 */
lv_obj_set_style_anim_time(bar, 3000, LV_STATE_DEFAULT | LV_PART_MAIN); /* 4. 更改绘制动画时间（3000ms） */
```

**原理**：bar 与 slider 结构几乎一样（MAIN + INDICATOR），但默认不可拖拽——它是“只读”的进度展示；设置值带 LV_ANIM_ON 时，指示器会按 anim_time 平滑增长到目标值，适合做下载进度、音量条等。

**怎么判断**：任务进度展示（下载/加载）→ bar；需要用户操作调值 → slider。

## 圆弧(lv_arc)

**概述**（课件原文）：以圆弧滑动的形式来调节某些参数和显示数据，由前景弧和背景弧组成。

**组成**（课件原文）：主体 LV_PART_MAIN（背景弧）、指示器 LV_PART_INDICATOR（前景弧）、句柄 LV_PART_KNOB（旋钮）。

**创建与尺寸**（课件原文）：

```c
lv_obj_t *arc = lv_arc_create(lv_scr_act());                          /* 1. 创建 */
lv_obj_set_size(arc, 100, 100); /* 2. 宽高必须相同；若不同，以最小的值进行设置 */
lv_obj_set_style_pad_all(arc, 20, LV_STATE_DEFAULT | LV_PART_KNOB);   /* 2. 设置旋钮的大小和形状 */
```

**圆弧样式**（课件原文）：arc_width（圆弧宽度）、arc_color（圆弧颜色）、arc_opa（圆弧透明度）、arc_rounded（圆弧终端圆角）。

```c
lv_obj_set_style_arc_width(arc, 10, LV_STATE_DEFAULT | LV_PART_INDICATOR); /* 前景弧宽度 */
lv_obj_set_style_arc_rounded(arc, true, LV_STATE_DEFAULT | LV_PART_INDICATOR);
```

**值与范围**（课件原文）：`lv_arc_set_range(obj, min, max);`（默认 0-100）；`lv_arc_get_value(obj);`；`lv_arc_set_value(obj, val);`。

**角度与旋转**（课件原文）：

```c
/* 背景弧：整体起止角 / 单独起角 / 单独止角 */
lv_arc_set_bg_angles(arc, start_angle, end_angle);
lv_arc_set_bg_start_angle(arc, angle);
lv_arc_set_bg_end_angle(arc, angle);
/* 前景弧：同理 */
lv_arc_set_angles(arc, start_angle, end_angle);
lv_arc_set_start_angle(arc, angle);
lv_arc_set_end_angle(arc, angle);
lv_arc_set_rotation(arc, deg); /* 旋转：相对于 0 度位置的偏移 */
```

**模式**（课件原文）：LV_ARC_MODE_NORMAL（指示弧从最小值画到当前值）/ LV_ARC_MODE_REVERSE（从最大值按逆时针画到当前值）/ LV_ARC_MODE_SYMMETRICAL（从中间点画到当前值），用 `lv_arc_set_mode(obj, mode);` 设置。注意：REVERSE 模式请用 lv_arc_set_value 设置值，用触摸设置可能出现显示异常；可 `lv_obj_clear_flag(arc, LV_OBJ_FLAG_CLICKABLE)` 禁用弧的点击。

**其它**（课件原文）：变化率 `lv_arc_set_change_rate(obj, rate);`（单位 度/秒）；把另一个对象放到旋钮上跟踪角度 `lv_arc_align_obj_to_angle(arc, obj_to_align, radius_offset);`。

**怎么判断**：圆形进度/环形调参（音量环、仪表）→ arc；直线进度 → bar。

# 核心部件(滚轮、文本区域和按钮矩阵)

核心部件第四讲：滚轮（lv_roller，滚动选一）、文本区域（lv_textarea，文本输入框）、按钮矩阵（lv_btnmatrix，行列排布多按钮）。

## 滚轮(Iv_roller)

**概述**（课件原文）：Roller 部件可以通过滚动从列表中选择一个选项。

**组成**（课件原文）：主体 LV_PART_MAIN（矩形背景）、被选中部分 LV_PART_SELECTED（中间的选定选项）。

**创建与设置**（课件原文）：

```c
lv_obj_t *roller = lv_roller_create(lv_scr_act());                      /* 1. 创建 */
lv_obj_set_size(roller, 200, 100);                                      /* 2. 设置部件大小 */
lv_obj_set_style_text_line_space(roller, 50, LV_PART_MAIN);             /* 2. 行距，可设置被选中部分的高度 */
lv_roller_set_options(roller, "First\nSecond\nThird", LVROLLER_MODE_NORMAL); /* 3. 选项用 \n 分隔；NORMAL=普通，INFINITE=无限滚动 */
```

**获取与选择**（课件原文）：

```c
lv_roller_get_selected(roller);                      /* 4. 获取当前选中选项的索引号 */
lv_roller_get_selected_str(target, buff, sizeof(buff)); /* 4. 获取选中选项的字符串，拷贝到 buff */
lv_roller_set_selected(roller, 2, LV_ANIM_OFF);      /* 5. 根据索引手动选择 */
lv_roller_set_visible_row_count(roller, 2);          /* 6. 调整可见行数 */
/* 3. 文本样式设置：用 text_* 系列样式属性（text_color / text_font / text_line_space 等） */
```

**事件**（补充）：选中项变化时触发 LV_EVENT_VALUE_CHANGED。

**怎么判断**：多选一的滚动选择（时/分/秒、地区）→ roller；选项数量少且固定 → 也可以考虑用按钮矩阵或下拉列表。

## 文本区域(lv_textarea)\_1

**概述**（课件原文）：文本区域是一个带有标签和光标的基础对象，可以向其中添加文本或字符；长行会换行，文本足够长时可滚动；支持单行模式和密码模式。

**组成**（课件原文）：主体 LV_PART_MAIN、滚动条 LV_PART_SCROLLBAR、所选文本 LV_PART_SELECTED、光标 LV_PART_CURSOR、占位符文本 LV_PART_TEXTAREA_PLACEHOLDER。

**创建、文本与占位符**（课件原文）：

```c
lv_obj_t *textarea = lv_textarea_create(lv_scr_act());   /* 1. 创建 */
lv_textarea_set_text(textarea, "This is textarea");      /* 2. 设置文本 */
lv_textarea_add_char(textarea, 'A');                     /* 2. 将字符插入当前光标位置 */
lv_textarea_add_text(textarea, "insert this text");      /* 2. 将文本插入当前光标位置 */
lv_textarea_get_text(textarea);                          /* 2. 获取文本 */
lv_textarea_set_placeholder_text(textarea, "Please enter password"); /* 3. 占位符（内容为空时显示） */
```

**光标控制**（课件原文）：

```c
lv_textarea_set_cursor_click_pos(textarea, true); /* 4. true: 光标跳转到单击位置；false: 关闭 */
lv_textarea_set_cursor_pos(textarea, 0);           /* 4. 设置光标当前位置 */
lv_textarea_cursor_right(textarea);                /* 4. 光标右移 */
lv_textarea_cursor_left(textarea);                 /* 4. 光标左移 */
lv_textarea_cursor_down(textarea);                 /* 4. 光标下移 */
lv_textarea_cursor_up(textarea);                   /* 4. 光标上移 */
```

**删除字符**（课件原文）：`lv_textarea_del_char(textarea);`（删除光标左侧字符）/ `lv_textarea_del_char_forward(textarea);`（删除光标右侧字符）。

## 文本区域(lv_textarea)\_2

**单行模式**（课件原文）：`lv_textarea_set_one_line(textarea, true);`——配置为单行（回车不会换行，适合用户名/密码框）。

**密码模式**（课件原文）：

```c
lv_textarea_set_password_mode(textarea, true); /* 7. 文本区域支持密码模式 */
lv_textarea_set_password_bullet(textarea, "x"); /* 7. 设置覆盖字符（默认可能是 *，可自定义） */
```

**接受的字符与最大长度**（课件原文）：

```c
lv_textarea_set_accepted_chars(textarea, "0123"); /* 8. 只接受列表中的字符，其他字符被忽略 */
lv_textarea_set_max_length(textarea, 4);           /* 9. 设置最大文本长度 */
```

**怎么判断**：账号/密码框 → 单行 + 密码模式 + max_length；只允许数字 → accepted_chars；占位提示 → set_placeholder_text。

## 文本区域(lv_textarea)\_3

**文本选择**（课件原文）：`lv_textarea_set_text_selection(textarea, true);`——启用后可以在文本区域中选择文本（label 的文本选择在这里才真正可交互）。

**样式设置**（课件原文）：如何设置各部分的样式？——用前面学的“状态 | 部分”组合给对应部分设样式：

```c
lv_obj_set_style_text_color(textarea, lv_color_hex(0x333333), LV_STATE_DEFAULT | LV_PART_MAIN);
lv_obj_set_style_text_color(textarea, lv_color_hex(0x999999), LV_STATE_DEFAULT | LV_PART_TEXTAREA_PLACEHOLDER); /* 占位符颜色 */
lv_obj_set_style_bg_color(textarea, lv_color_hex(0xFFFFFF), LV_STATE_DEFAULT | LV_PART_MAIN);
```

**事件**（课件原文）：LV_EVENT_INSERT（插入字符或文本时触发）、LV_EVENT_VALUE_CHANGED（文本区域内容发生改变）。

```c
static void ta_cb(lv_event_t *e) {
    const char *txt = lv_textarea_get_text(lv_event_get_target(e));
    /* 每次内容变化都从这里读取最新文本 */
}
lv_obj_add_event_cb(textarea, ta_cb, LV_EVENT_VALUE_CHANGED, NULL);
```

**怎么判断**：实时校验/联动（如输入时更新标签）→ 监听 VALUE_CHANGED；按回车提交 → 监听 LV_EVENT_READY（配合键盘）。

## 按钮矩阵(lv_btnmatrix)

**概述**（课件原文）：Button Matrix 对象是一种以行和列形式显示多个按钮的轻量级方法。

**组成**（课件原文）：主体 LV_PART_MAIN、按钮 LV_PART_ITEMS。

**创建与映射**（课件原文）：

```c
lv_obj_t *btnmatrix = lv_btnmatrix_create(lv_scr_act()); /* 1. 创建 */
static const char *map[] = {"文本", "文本", "\n", "文本", NULL}; /* 2. 定义描述按钮的字符串数组：最后一个必须是 NULL；"\n" 用于换行 */
lv_btnmatrix_set_map(btnmatrix, map);                    /* 2. 设置按钮 */
lv_btnmatrix_set_btn_width(btnmatrix, id, width);        /* 3. 设置按钮的相对宽度，默认 width 是 1 */
```

**获取索引**（课件原文）：`lv_btnmatrix_get_selected_btn(btnmatrix);`（最近释放或聚焦的按钮索引）/ `lv_btnmatrix_get_btn_text(btnmatrix, btn_id);`（通过索引获取按钮文本）。

**按钮属性控制**（课件原文）：

```c
lv_btnmatrix_set_btn_ctrl(btnmatrix, btn_id, LV_BTNMATRIX_CTRL_HIDDEN);    /* 根据按键 id 设置属性 */
lv_btnmatrix_clear_btn_ctrl(btnmatrix, btn_id, LV_BTNMATRIX_CTRL_HIDDEN);  /* 根据按键 id 取消属性 */
lv_btnmatrix_set_btn_ctrl_all(btnmatrix, LV_BTNMATRIX_CTRL_CHECKABLE);     /* 所有按键添加某个属性 */
lv_btnmatrix_clear_btn_ctrl_all(btnmatrix, LV_BTNMATRIX_CTRL_CHECKABLE);   /* 取消所有按键的某个属性 */
```

**常用属性**（课件原文）：

LV_BTNMATRIX_CTRL_HIDDEN（隐藏，仍占布局空间）

O_REPEAT（长按不重复）

DISABLED（禁用）

CHECKABLE（可切换选中）

CHECKED（处于选中态）

CLICK_TRIG（单击时发 VALUE_CHANGED；禁用=按下时发）

POPOVER（按下时弹窗显示标签）

RECOLOR（启用 # 文本重着色）

CUSTOM_1、CUSTOM_2（自定义旗帜）。

**单次选中**（课件原文）：`lv_btnmatrix_set_one_checked(btnmatrix, true);`——每次只能有一个按钮被选中。

**怎么判断**：计算器、数字键盘、设置面板等成排按钮 → btnmatrix（比逐个创建 lv_btn 轻量得多）。

## 综合示例

本节课件未提供独立综合示例，补充一个“按钮矩阵 + 文本区域”的小例子（数字键盘输入）：

```c
static void kbd_cb(lv_event_t *e) {
    lv_obj_t *bm = lv_event_get_target(e);
    uint16_t id = lv_btnmatrix_get_selected_btn(bm);   /* 拿到按下的按钮索引 */
    const char *txt = lv_btnmatrix_get_btn_text(bm, id);
    lv_textarea_add_text(ta, txt);                      /* 把按钮文本插入输入框 */
}
static const char *map[] = {"1", "2", "3", "4", "5", "6", "7", "8", "9", "\n", "0", "C", NULL};
lv_obj_t *bm = lv_btnmatrix_create(parent);
lv_btnmatrix_set_map(bm, map);
lv_obj_add_event_cb(bm, kbd_cb, LV_EVENT_VALUE_CHANGED, NULL);
```

**拆解**：① map 数组定义按键布局，\n 换行；② 点击事件里用 get_selected_btn + get_btn_text 取回按了哪个键；③ 文本区域负责显示与编辑。这正是第 12 章 btnmatrix 与 textarea 配合的标准套路。

# 核心部件(键盘、表格和图片)

核心部件第五讲：键盘（lv_keyboard，虚拟键盘）、表格（lv_table，文本表格）、图片（lv_img，图像显示）。

## 键盘(lv_keyboard)

**概述**（课件原文）：键盘对象是一个特殊的按钮矩阵，具有预定义的键映射和其他功能，可实现虚拟键盘以将文本写入文本区域。

**组成**（课件原文）：主体 LV_PART_MAIN、按钮 LV_PART_ITEMS。

**创建与使用**（课件原文）：

```c
lv_obj_t *keyboard = lv_keyboard_create(lv_scr_act());        /* 1. 创建 */
lv_keyboard_set_mode(keyboard, LV_KEYBOARD_MODE_NUMBER);      /* 2. 模式：TEXT_LOWER(默认小写)/TEXT_UPPER/SPECIAL/NUMBER */
lv_keyboard_set_textarea(keyboard, textarea);                 /* 3. 为键盘分配文本区域，输入的数据写入该区域 */
lv_keyboard_set_popovers(keyboard, true);                     /* 4. 启用按键弹出功能（按下时放大显示） */
```

**事件**（课件原文）：LV_EVENT_READY（单击“确定”按钮）/ LV_EVENT_CANCEL（单击“取消”按钮）。

```c
static void kb_cb(lv_event_t *e) {
    lv_event_code_t code = lv_event_get_code(e);
    if (code == LV_EVENT_READY) { lv_obj_del(lv_event_get_target(e)); } /* 点确定：收起键盘 */
}
lv_obj_add_event_cb(keyboard, kb_cb, LV_EVENT_ALL, NULL);
```

**怎么判断**：需要屏幕内输入（触摸屏无物理键盘）→ keyboard + textarea 成对使用；键盘本身会按 textarea 的类型（密码框等）自动切换模式。

## 表格(lv_table)

**概述**（课件原文）：表格由包含文本的行、列和单元格构成，它的单元格中只能存放文本形式的内容。

**组成**（课件原文）：主体 LV_PART_MAIN、按钮 LV_PART_ITEMS。

**创建与设置**（课件原文）：

```c
lv_obj_t *table = lv_table_create(lv_scr_act());      /* 1. 创建 */
lv_table_set_row_cnt(table, row_cnt);                 /* 2. 设置行数 */
lv_table_set_col_cnt(table, col_cnt);                 /* 2. 设置列数 */
lv_table_set_col_width(table, col_id, width);         /* 3. 设置列的宽度（行高根据单元格样式自动计算） */
lv_table_set_cell_value(table, row, col, "Content");  /* 4. 按行列位置为单元格设置文本 */
lv_table_set_cell_value_fmt(table, row, col, const char *fmt, ...); /* 4. 格式化设置单元格内容 */
```

**怎么判断**：展示纯文本数据（参数表、成绩单）→ table；需要放控件（按钮/滑块）的网格 → 用 grid 布局或 btnmatrix。

## 图片(lv_img)\_1

**概述**（课件原文）：

图像是显示来自 C 像素数组或文件图像的基本对象，也可以显示文本符号 LV_SYMBOL\_\*\*；

通过图像解码器接口可支持自定义图像格式。

图片的来源可以是：代码中的变量（C 像素数组）、外部存储的文件（如 SD 卡）、符号文本 LV_SYMBOL\_\*\*。

**组成**（课件原文）：主体 LV_PART_MAIN。

**创建与图片来源**（课件原文）：

```c
lv_obj_t *img = lv_img_create(lv_scr_act());   /* 1. 创建图片部件 */
lv_img_set_src(img, src);                      /* 2. 设置图片来源（这里讲解 C 像素数组） */
LV_IMG_DECLARE(converted_img_var)              /* 使变量在 C 文件中可见，使用前需要声明 */
```

**像素数组来源**（课件原文）：包含像素的 C 数组可以从 PNG、JPG 或 BMP 图像生成，直接使用 LVGL 官网的图片转换工具转换即可。

**转换的颜色格式**（课件原文）：

- CF_ALPHA_1/2/4/8 BIT：只存 1/2/4/8 位 Alpha 值，源图必须有 Alpha 通道，适合字体类位图（整个图像一种颜色）
- CF_INDEXED_1/2/4/8 BIT：用 2/4/16/256 色调色板，每像素存 1/2/4/8 位
- CF_TRUE_COLOR：存 RGB 颜色（原图像数据）
- CF_TRUE_COLOR_ALPHA：同 TRUE_COLOR，但每像素多一个 alpha（透明度）字节

位数越高，转换出来的像素数组越大、越占空间资源，但显示更平滑、色彩更丰富。通过属性 img_recolor 可重新着色图片部件，img_recolor_opa 设置重新着色的透明度。

**怎么判断**：图标/Logo 用 ALPHA 或 INDEXED（体积小）；照片类用 TRUE_COLOR / TRUE_COLOR_ALPHA；需要缩放旋转的图，必须转成 TRUE_COLOR 系（见 13.4）。

## 图片(lv_img)\_2

**图像偏移**（课件原文）：

`lv_img_set_offset_x(img, x_ofs);` / `lv_img_set_offset_y(img, y_ofs);`——把图像内容相对部件移动（常用于裁剪显示大图的一部分）。

**图片变换**（课件原文）：

```c
lv_img_set_zoom(img, factor);                          /* 图片缩放：256=100% */
lv_img_set_angle(img, angle);                          /* 角度旋转：单位 0.1°，300=30° */
lv_img_set_pivot(img, pivot_x, pivot_y);               /* 旋转的枢轴点；修改前先 lv_obj_update_layout(img) 更新布局 */
```

**注意**（课件原文）：

被转换为 **CF_TRUE_COLOR 和 CF_TRUE_COLOR_ALPHA 颜色格式**的图片，才能进行**缩放/旋转**等变换操作。

**怎么判断**：做大图局部显示 → offset；做动效（放大镜、旋转加载）→ zoom/angle + pivot；缩放前先确认图片颜色格式为 TRUE_COLOR 系。

## 综合示例

本节课件未提供独立综合示例，补充一个“图片缩放 + 旋转”的动效示例（配合定时器或动画）：

```c
lv_obj_t *img = lv_img_create(parent);
lv_img_set_src(img, &img_logo);        /* 使用转换好的 C 像素数组（TRUE_COLOR 格式才能变换） */
lv_img_set_zoom(img, 256);             /* 初始 100% */
lv_img_set_angle(img, 450);            /* 旋转 45° */
lv_img_set_pivot(img, 50, 50);         /* 绕图片中心旋转 */

/* 之后在定时器/动画里递增 zoom 与 angle 即可实现缩放旋转动效 */
```

**拆解**：图片变换三步——设来源（保证 TRUE_COLOR 系）、设 zoom/angle、设 pivot 枢轴；zoom 与 angle 的单位与 6.4 样式变换一致（256=100%、0.1°）。

## 图片按钮(lv_imgbtn)

**概述**（课件原文）：图像按钮与简单的“按钮”对象非常相似，唯一的区别是它在每个状态下显示用户定义的图像，而不是绘制矩形。

**组成**（课件原文）：主体 LV_PART_MAIN。

**创建与图片来源**（课件原文）：

```c
lv_obj_t *imgbtn = lv_imgbtn_create(lv_scr_act());      /* 1. 创建 */
/* 2. 按状态设置图片（左/中/右三段，可传 NULL） */

```

**状态**（课件原文）：LV_IMGBTN_STATE_RELEASED（释放）/ PRESSED（按下）/ DISABLED（禁用）/ CHECKED_RELEASED（选中+释放）/ CHECKED_PRESSED（选中+按下）/ CHECKED_DISABLED（选中+禁用）。

**怎么判断**：按钮外观需要贴图（开机键、音量键皮肤）→ imgbtn；纯色/样式按钮 → 普通 lv_btn。

## LED(Iv_led)

**概述**（课件原文）：LED 是矩形（或圆形）物体，其亮度可调。亮度越低，LED 的颜色就越暗。

**组成**（课件原文）：主体 LV_LED_PART_MAIN。

**创建与操作**（课件原文）：

```c
lv_obj_t *led1 = lv_led_create(lv_scr_act());   /* 1. 创建 */
lv_led_set_color(led, color);                   /* 2. 设置 LED 的颜色 */
lv_led_set_brightness(led, bright);             /* 3. 设置亮度：0（最暗）~ 255（最亮） */
lv_led_off(led);                                /* 4. 状态切换：设为预定义的 OFF */
lv_led_on(led);                                 /* 4. 状态切换：设为预定义的 ON */
lv_led_toggle(led);                             /* 4. 在 ON 和 OFF 之间切换 */
```

**怎么判断**：状态指示灯（运行/告警/连接）→ led + toggle；想要自定义形状 → 用基础对象加背景样式代替。

**概述**（课件原文）：色环部件其实就是一个颜色选择器，可以分别选择颜色的色调、饱和度和明度。长按对象，色轮将切换到模式，双击将重置参数。

```c
lv_obj_t *colorwheel = lv_colorwheel_create(parent, knob_recolor); /* 1. 创建；knob_recolor=true 时旋钮背景色=当前颜色 */
lv_colorwheel_set_rgb(colorwheel, color);   /* 2. 设置当前选中的颜色 */
lv_colorwheel_get_rgb(colorwheel);          /* 3. 获取当前选中的颜色 */
```

**模式**（课件原文）：`lv_colorwheel_set_mode(colorwheel, mode);`（色相、饱和度、明度）；`lv_colorwheel_set_mode_fixed(colorwheel, true);`（固定模式）。

## 列表(lv_list)

**概述**（课件原文）：列表基本上是一个垂直布局的矩形，可以添加按钮和文本。常用于多选一的场景，默认会展现多个选项。

```c
lv_obj_t *list = lv_list_create(lv_scr_act());       /* 1. 创建 */
```

**组成**（课件原文）：按钮 LV_PART_MAIN + LV_PART_INDICATOR；列表 LV_PART_MAIN + LV_PART_SCROLLBAR + LV_PART_SELECTED。

**创建与选项**（课件原文）：

```c
lv_obj_t *dropdown = lv_dropdown_create(lv_scr_act());     /* 1. 创建 */
lv_dropdown_set_options(dropdown, "First\nSecond\nThird"); /* 2. 设置选项（\n 分隔） */

lv_dropdown_add_option(dropdown, "New option", pos);       /* 2. 在 pos 位置插入新选项 */
```

**选中项**（课件原文）：

```c
lv_dropdown_set_selected(dropdown, id);                        /* 3. 设置当前所选项（索引） */
lv_dropdown_get_selected(dropdown);                            /* 4. 获取当前所选项的 id */
lv_dropdown_get_selected_str(dropdown, buf, buf_size);         /* 5. 获取所选项文本 */

```

**事件**（补充）：选中变化触发 LV_EVENT_VALUE_CHANGED。

**怎么判断**：选项多、界面空间有限 → dropdown（平时只占一行）；选项希望一直可见 → list。

**概述**（课件原文）：选项卡部件可以实现多页面的切换，用户可在不同的页面添加内容。

**组成**（课件原文）：主体 lv_obj、按钮矩阵 lv_btnmatrix（顶部标签条）。

**创建与使用**（课件原文）：

```c
lv_obj_t *tabview = lv_tabview_create(parent, tab_pos, tab_size); /* 1. 创建；tab_pos=标签条位置，tab_size=标签条大小 */
lv_obj_t *tab1 = lv_tabview_add_tab(tabview, "Tab name");         /* 2. 添加标签页，返回该页容器，往里放内容 */

lv_tabview_set_act(tabview, id, LV_ANIM_ON);                      /* 4. 手动设置当前所选标签页（带动画） */
```

# 布局

布局（layout）解决“子对象怎么自动摆放”的问题，分两大类：**弹性布局 Flex**（一维：一行/一列排布）和**网格布局 Grid**（二维：行列网格排布）。课件只有 Flex 正文，Grid 仅标题，本节 Flex 按课件整理，Grid 做补充。

## 弹性布局(Flex)

**1、开启并设置 Flex 布局**（课件原文）：flex 布局功能需要通过 lv_conf.h 中的 LV_USE_FLEX 全局启用；然后对容器调用：

```c
lv_obj_set_flex_flow(obj, flex_flow);   /* obj=容器，flex_flow=排列方式 */
```

**flex_flow 取值**（课件原文，8 种 = 方向 × 是否换行 × 是否反转）：

| 取值 | 含义 |
|-|-|
| LV_FLEX_FLOW_ROW | 子项排成一行，不换行 |
| LV_FLEX_FLOW_COLUMN | 子项排成一列，不换行 |
| LV_FLEX_FLOW_ROW_WRAP | 子项排成一行，允许换行 |
| LV_FLEX_FLOW_COLUMN_WRAP | 子项排成一列，允许换行 |
| LV_FLEX_FLOW_ROW_REVERSE | 一行排列，不换行，顺序反转 |
| LV_FLEX_FLOW_COLUMN_REVERSE | 一列排列，不换行，顺序反转 |
| LV_FLEX_FLOW_ROW_WRAP_REVERSE | 一行排列，换行，顺序反转 |
| LV_FLEX_FLOW_COLUMN_WRAP_REVERSE | 一列排列，换行，顺序反转 |

**2、Flex 布局对齐**（课件原文）：

```c
lv_obj_set_flex_align(obj, main_place, cross_place, track_cross_place);
```

- **main_place（主轴，水平方向）**：LV_FLEX_ALIGN_START（靠左）/ LV_FLEX_ALIGN_END（靠右）/ LV_FLEX_ALIGN_CENTER（居中）
- **cross_place（行内子项之间的对齐）**：LV_FLEX_ALIGN_START（顶部）/ LV_FLEX_ALIGN_END（底部）/ LV_FLEX_ALIGN_CENTER（居中）
- **track_cross_place（交叉轴，垂直方向，多行时的整体位置）**：LV_FLEX_ALIGN_START（顶部）/ LV_FLEX_ALIGN_END（底部）/ LV_FLEX_ALIGN_CENTER（居中）

**3、内部填充**（课件原文）：设置子项目之间的行间距和列间距，属性为 pad_row、pad_column（见第 7 章填充）：`lv_obj_set_style_pad_row(box, 10, 0);` / `lv_obj_set_style_pad_column(box, 10, 0);`

**4、样式界面**（课件原文）：也可以通过样式属性来设置布局类型和对齐方式——对应样式属性为 \_FLEX_FLOW、\_FLEX_MAIN_PLACE、\_FLEX_CROSS_PLACE、\_FLEX_TRACK_PLACE（用 lv_obj_set_style_flex_flow 等接口设置）。

**5、弹性增长**（课件原文）：设置子项的弹性增长值，可用空间将按比例分配：

```c
lv_obj_set_flex_grow(child, value);   /* value 越大分到的剩余空间越多；都设 1 则均分 */
```

**6、强制换行**（课件原文）：`lv_obj_add_flag(child, LV_OBJ_FLAG_FLEX_IN_NEW_TRACK);`——强制该子项从新的一行/列开始。

```c
lv_obj_t *box = lv_obj_create(parent);
lv_obj_set_flex_flow(box, LV_FLEX_FLOW_ROW_WRAP);              /* 一行排布，放不下换行 */
lv_obj_set_flex_align(box, LV_FLEX_ALIGN_CENTER, LV_FLEX_ALIGN_CENTER, LV_FLEX_ALIGN_CENTER);
lv_obj_set_style_pad_row(box, 10, 0);                           /* 行间距 */
lv_obj_set_style_pad_column(box, 10, 0);                        /* 列间距 */
for (int i = 0; i < 6; i++) {
    lv_obj_t *btn = lv_btn_create(box);
    lv_obj_set_flex_grow(btn, 1);                               /* 子项等分剩余空间 */
    lv_obj_set_size(btn, 80, 40);
}
```

**怎么判断**：子项按一行/一列自动排列、需要均分或换行 → Flex；要“表格状”二维摆放 → 17.2 的 Grid。

## 网格布局(Grid)

课件未包含“网格布局”的正文内容（仅标题），以下为补充：网格布局（Grid）把容器按“列描述 + 行描述”划分成网格，子项指定自己占据的格子，适合二维排布。需在 lv_conf.h 中启用 LV_USE_GRID。

```c
/* 1. 定义列与行：LV_GRID_FR(n)=按比例分配剩余空间，LV_GRID_CONTENT=按内容自适应，也可写固定像素 */
static lv_coord_t col_dsc[] = {LV_GRID_FR(1), LV_GRID_FR(2), LV_GRID_FR(1), LV_GRID_TEMPLATE_LAST};
static lv_coord_t row_dsc[] = {LV_GRID_CONTENT, LV_GRID_FR(1), LV_GRID_TEMPLATE_LAST};

/* 2. 给容器设置网格描述 */
lv_obj_set_grid_dsc_array(box, col_dsc, row_dsc);

/* 3. 子项指定位置：第 x 列 / 第 y 行，可跨列跨行 */
lv_obj_set_grid_cell(btn1, LV_GRID_ALIGN_STRETCH, 0, 1, LV_GRID_ALIGN_STRETCH, 0, 1);
lv_obj_set_grid_cell(btn2, LV_GRID_ALIGN_STRETCH, 1, 1, LV_GRID_ALIGN_STRETCH, 0, 1);
```

**拆解**：① 描述数组以 LV_GRID_TEMPLATE_LAST 结尾；② FR(n) 是“比例单位”——1:2:1 表示三列宽度比为 1:2:1；③ set_grid_cell 的第 3、6 个参数是起始列/行，第 4、7 个参数是跨度（跨 1 列/行）。

**怎么判断**：仪表盘、键盘、图表类需要严格行列对齐 → Grid；只是简单一行/一列 → Flex 更省事。

# LVGL移植(裸机)

**本章目标**：把 LVGL 从 PC 模拟器搬到真实硬件上。本文以 **STM32F407 核心板 + 裸机（无 RTOS）+ MDK-ARM（Keil uVision5）**为主线，按“移植要求 → 源码获取与裁剪 → LCD 驱动 → LVGL 源码移植 → 注册显示驱动 → 触摸驱动 → 注册触摸驱动 → CubeIDE 移植 → lv_conf.h 配置 → 虚拟仿真”的顺序逐步推进。每个小节都给出可照做的步骤清单、关键代码和验证方法。课件正文覆盖 18.1、18.2、18.4、18.6，其余小节课件无正文，标注“补充”。


::: tip

**完成标准**：① LCD 能点亮并显示纯色块；② LVGL 工程编译通过，屏幕显示 LVGL 界面；③ 触摸屏点击控件有响应；④ 会通过 lv_conf.h 裁剪功能与调优。

:::


**总体流程**：先让屏幕能亮（18.3），再把 LVGL 源码编译进工程（18.4），注册显示驱动让画面刷上屏（18.5），接着注册触摸驱动让屏幕能“点”（18.6-18.7）。LCD 与触摸都搞定后，LVGL 在裸机上就能完整工作。

## 移植要求

**Minimal requirements**（课件原文）：LVGL runs on any modern MCU or MPU——任何现代 MCU/MPU 都能跑，最低要求如下：

| 类别 | 最低要求 |
|-|-|
| 架构 | 16、32 或 64 位 MCU / 处理器 |
| 时钟 | > 64MHz |
| Flash | 约 100kB（取决于启用的功能） |
| RAM | > 4KB |
| 帧缓冲 | 至少 1 个帧缓冲（显示控制器 / 内部或外部 RAM） |
| 绘制缓冲 | 大于屏幕总分辨率的 1/10 |
| 构建系统 | 无外部依赖，拷贝进工程直接编译 |
| 编译器 | C99 或更高版本 |

**为什么是“1/10 缓冲”**（补充）：LVGL 先把要显示的内容画进绘制缓冲，再整块交给显示驱动刷新。缓冲越小，一次能画的区域越小，需要分块重绘的次数越多、越慢；1/10 是“能跑”和“不卡”的折中点——缓冲越大越流畅（见下方优化）。

**配套硬件示例**（课件原文）：本系列用 STM32F407 核心板——ARM Cortex-M4F（带 FPU），主频最高 168MHz，1MB Flash、192+4KB SRAM，支持 LCD 并行接口（8080/6800 模式）。封装从 LQFP64（10×10mm）到 LQFP176（24×24mm）、UFBGA176（10×10mm）。

**运行效果优化**（课件原文 04 小节，四条）：① 提高芯片主频；② 增大 SRAM 容量、提高读写速度；③ 增大图形缓冲区、使用双缓冲区；④ 减小需要刷新的总像素。

**判断**：界面卡顿先加绘制缓冲（改成双缓冲），仍不够再考虑降分辨率或超频。


::: tip

**移植前自检清单**：① MCU 主频 ≥ 64MHz；② Flash 可用空间 ≥ 100kB；③ SRAM ≥ 4KB（建议 ≥ 32KB，跑界面更从容）；④ 有一块可刷屏的显示控制器（FSMC/SPI 均可）；⑤ 编译器支持 C99。逐条确认后再动手，能少走很多弯路。

:::

- git clone：git clone https://github.com/lvgl/lvgl.git（推荐，便于切换版本与后续更新）

**步骤 4：确认移植环境**（课件原文）：本系列介绍两种环境下的 LVGL 移植——Keil uVision5（MDK-ARM，裸机）与 STM32CubeIDE。裸机主线走 18.3-18.7（MDK），CubeIDE 见 18.8。


::: tip

**最小拷贝清单**：移植时只拷 src/、lv_conf_template.h（改名 lv_conf.h）、lvgl.h 三部分；examples/ 与 docs/ 不需要。src 里用不到的模块（如 extra 的个别部件）通过 LV_USE\_\* 关掉，可进一步减小体积。

## LCD驱动移植(MDK-ARM)

LCD 驱动是让屏幕先亮起来的前置工作，和 LVGL 本身无关——LVGL 只负责在内存里画图，画完由 LCD 驱动把像素刷到屏上。所以先单独把 LCD 跑通，再谈 LVGL。

**步骤 1：确认硬件连接与接口**：本系列 LCD 使用 8080 并行接口，由 STM32 的 FSMC（灵活的静态存储控制器）驱动。确认屏的数据线 DB0-DB15、片选/写/读/复位等信号已按 FSMC 引脚接好。

**步骤 2：用 CubeMX 或厂商例程配置 FSMC**：在 CubeMX 中打开 FSMC，选 NOR/PSRAM 的 Bank，按 LCD 控制器的时序（8080 模式）配置地址建立时间、数据建立时间等参数；同时在 GPIO 里把背光、复位引脚配置为输出。

**步骤 3：把 LCD 驱动文件加入工程**：将厂商提供的 LCD 驱动（如 lcd.c / lcd.h）拷入工程，加入 MDK 分组（如 Hardware），并添加头文件路径。

**步骤 4：确认三个关键接口**（补充）：LVGL 后续只需要“初始化”和“填充区域”两个函数：

```c
/* 初始化：GPIO + FSMC(8080 并口)时序 + LCD 控制寄存器配置 */
void LCD_Init(void);

/* 画一个颜色块到屏幕指定区域（LVGL 刷新就是反复调它） */
void LCD_Fill(uint16_t x1, uint16_t y1, uint16_t x2, uint16_t y2, uint16_t *color);

/* 可选：单点/字符函数，调试用 */
```

**步骤 5：验证**：在 main 里先调用 LCD_Init()，再用 LCD_Fill 依次填充红 / 绿 / 蓝纯色，屏幕能整屏变色即 LCD 驱动 OK。

**判断**：MDK 下先用厂商 LCD 例程把 LCD_Init / LCD_Fill 跑通（屏幕能显示颜色块），再做 18.4-18.5 的 LVGL 源码移植与显示驱动注册。若屏幕不亮：先查 FSMC 时序参数、引脚是否复用冲突、背光是否点亮。

## LVGL源码移植(MDK-ARM)

目标：让 LVGL 源码进入 MDK 工程并能编译通过。共 6 步：

**步骤 1：拷贝 LVGL 源码进工程**（课件原文）：把 lvgl 源码拷贝到工程中，建议放在工程根目录下的 Middlewares/lvgl 文件夹，与用户代码分开管理。

**步骤 2：生成配置文件 lv_conf.h**（课件原文）：把 lv_conf_template.h 修改为 lv_conf.h（改名即生效，LVGL 编译时按 lv_conf.h 找配置）。

**步骤 3：激活配置**（课件原文）：打开 lv_conf.h，修改文件开头条件编译指令，把 #if 0 修改为 #if 1（激活配置）。注意该文件位置要与步骤 6 的 Include Paths 对应。

**步骤 4：在 MDK 中添加分组**（课件原文）：在 MDK 左侧 Project 窗口新建以下分组：

- Middlewares/lvgl/porting —— 显示 / 输入设备移植文件
- Middlewares/lvgl/src/core、src/draw、src/extra、src/font、src/hal、src/misc、src/widgets
- Middlewares/lvgl/config —— lv_conf.h 所在目录

**步骤 5：把对应目录下的所有 .c 文件添加到对应的分组里**（课件原文）：逐个分组右键 → Add Existing Files…，选中该目录下所有 .c 文件加入。lv_conf.h 里已关闭的模块（如 LV_USE_CHART），其对应目录下的 .c 可以不添加。

**步骤 6：添加头文件路径**（课件原文）：打开 Options for Target → C/C++ 选项卡 → Include Paths，加入 lvgl 根目录、src 各子目录与 config 目录，否则 #include "lvgl.h" 找不到。示例（相对工程文件所在目录）：

```text

Middlewares/lvgl/src
Middlewares/lvgl/src/core
Middlewares/lvgl/src/draw
Middlewares/lvgl/src/extra
Middlewares/lvgl/src/font
Middlewares/lvgl/src/hal
Middlewares/lvgl/src/misc
Middlewares/lvgl/src/widgets
Middlewares/lvgl/porting
Config
```

**验证**：全量编译（Build）。报 lv_conf.h 找不到 → 检查 Include Paths 与 lv_conf.h 位置；报 LV_USE\_\* 未定义 → lv_conf.h 未激活（#if 0 没改成 #if 1）。

**为什么要分组**（补充）：MDK 的“分组”只是工程管理视图，真正决定是否编译的是“把 .c 加进工程”。lv_conf.h 里关掉的模块，其 .c 不加入工程即可减小体积。

## 注册显示驱动(MDK-ARM)

课件无正文，以下为补充：LVGL 通过“显示驱动”结构体知道自己该往哪刷、怎么刷。注册分四步：初始化绘制缓冲 → 写刷新回调 → 填驱动结构体并注册 → 提供心跳。

**步骤 1：定义绘制缓冲**：在 lv_port_disp.c 中定义 lv_disp_draw_buf_t 结构体和一个颜色数组，数组大小 = LV_HOR_RES_MAX × 行数（40 行是常见起点）。lv_color_t 的大小由 lv_conf.h 的 LV_COLOR_DEPTH 决定（16bit = 2 字节）。

**步骤 2：写刷新回调 flush_cb**：LVGL 画完一块区域就调用它，把像素数据交给 LCD。回调末尾必须调用 lv_disp_flush_ready 通知 LVGL 可以画下一块。

**步骤 3：填驱动结构体并注册**：初始化 lv_disp_drv_t，填写屏幕宽高、刷新回调、绘制缓冲，然后 lv_disp_drv_register 注册。

```c
/* 1. 绘制缓冲：lv_conf.h 的 LV_HOR_RES_MAX*行数 大小的数组 */
static lv_disp_draw_buf_t draw_buf;
static lv_color_t buf[LV_HOR_RES_MAX * 40];

/* 2. 刷新回调：LVGL 画完一区，就调它把像素写给 LCD */
static void my_flush_cb(lv_disp_drv_t *drv, const lv_area_t *area, lv_color_t *color_p)
{
    LCD_Fill(area->x1, area->y1, area->x2, area->y2, (uint16_t *)color_p);
    lv_disp_flush_ready(drv);   /* 通知 LVGL 刷新完成，可继续画下一块 */
}

void lv_port_disp_init(void)
{
    lv_disp_draw_buf_init(&draw_buf, buf, NULL, LV_HOR_RES_MAX * 40);
    static lv_disp_drv_t disp_drv;
    lv_disp_drv_init(&disp_drv);
    disp_drv.hor_res = 800;          /* 屏幕宽 */
    disp_drv.ver_res = 480;          /* 屏幕高 */
    disp_drv.flush_cb = my_flush_cb; /* 刷新回调 */
    disp_drv.draw_buf = &draw_buf;
    lv_disp_drv_register(&disp_drv); /* 注册，返回的指针就是屏幕对象 */
}
```

**步骤 4：提供两个“心跳”**：LVGL 需要时间基准和处理入口，在 main 的主循环（或 1ms 定时器中断）里调用：

```c
lv_tick_inc(1);      /* 每 1ms 调用一次，给 LVGL 提供时间基准（动画/长按用） */
lv_timer_handler();  /* 周期调用，LVGL 在这里处理事件、动画和重绘 */
```

**验证**：在 main 里依次调用 lv_init() → lv_port_disp_init()，创建一个标签（lv_label）并设置文本，主循环里调 lv_timer_handler()。屏幕出现文字即显示驱动注册成功。

**为什么双缓冲更快**（补充）：单缓冲时 LVGL 画完一块必须等 LCD 刷完才能画下一块（串行）；双缓冲时 LVGL 往缓冲 A 画，同时 LCD 刷缓冲 B，两个环节并行，帧率接近翻倍——这就是 18.1 优化第三条。实现时把 lv_disp_draw_buf_init 的第二个缓冲参数从 NULL 改成第二个数组即可。

## 触摸驱动移植(MDK-ARM)

目标：让触摸芯片能读出坐标。先不接 LVGL，用串口验证数据正确，再交给 18.7 注册。

**步骤 1：引脚配置**（课件原文）：触摸屏走 I2C，用两个 IO 做中断 / 复位，串口用于调试打印坐标：

- 中断引脚 GPIOI2
- 复位引脚 GPIOC7
- IIC_SCL 引脚 GPIOB6
- IIC_SDA 引脚 GPIOB7
- 调试串口 USART6（PG14 → USART6_TX，PG9 → USART6_RX）

在 CubeMX 中把上述引脚分别配置为：GPIO 输出（复位）、GPIO 输入（中断）、I2C 引脚、USART6 串口。

**步骤 2：调试串口重定向**（课件原文）：重定向 fputc，printf 就能从 USART6 输出：

```c
int fputc(int ch, FILE *f)
{
    HAL_UART_Transmit(&huart6, (uint8_t *)&ch, 1, 500);
    return ch;
}
```

同时在 MDK 的 Options for Target 里勾选 Use MicroLIB，否则 printf 重定向可能不生效（半主机模式会卡死）。

**步骤 3：工程添加触摸屏驱动程序**（课件原文）：把厂商提供的触摸驱动（I2C 读写、读坐标寄存器）加入工程，并确认 I2C 初始化已调用。

**步骤 4：读取触摸坐标点，通过调试串口打印**（课件原文）：写一个 tp_scan(&x, &y) 形式的函数，循环里调用并 printf 打印，在串口助手里观察：

```c
uint16_t x = 0, y = 0;
while (1) {
    if (tp_scan(&x, &y)) {            /* 有触摸时返回 1 */
        printf("x=%d, y=%d\r\n", x, y);
    }
    HAL_Delay(20);
}
```

**验证**：手指点在屏幕不同位置，串口输出的坐标随之变化且稳定。若一直无输出：先查 I2C 引脚与驱动初始化、复位时序（触摸芯片上电后要复位并延时）。

## 注册触摸驱动(MDK-ARM)

课件仅标题无正文，以下为补充：把触摸屏注册成 LVGL 的输入设备（指针型），LVGL 就能把触摸点转成点击 / 拖动事件。

**步骤 1：写读取回调 read_cb**：LVGL 每次事件循环都会调它，问“现在手指在哪、按没按”：

```c
/* 读取回调：LVGL 每次事件循环都会调它问“现在手指在哪、按没按” */
static void my_touchpad_read(lv_indev_drv_t *drv, lv_indev_data_t *data)
{
    uint16_t x = 0, y = 0;
    if (tp_scan(&x, &y)) {                 /* 触摸屏驱动返回是否有触摸 */
        data->point.x = x;
        data->point.y = y;
        data->state = LV_INDEV_STATE_PRESSED;   /* 按下 */
    } else {
        data->state = LV_INDEV_STATE_RELEASED;  /* 松开 */
    }
}

void lv_port_indev_init(void)
{
    static lv_indev_drv_t indev_drv;
    lv_indev_drv_init(&indev_drv);
    indev_drv.type = LV_INDEV_TYPE_POINTER;   /* 指针型：触摸屏/鼠标 */
    indev_drv.read_cb = my_touchpad_read;
    lv_indev_drv_register(&indev_drv);
}
```

**步骤 2：在 main 里调用 lv_port_indev_init()**：顺序放在 lv_init() 和 lv_port_disp_init() 之后。

**步骤 3：坐标换算**（补充）：LVGL 不直接操作触摸芯片，只认 indev 回调给的 (x, y) + 按下状态。触摸屏分辨率与屏幕分辨率不一致时，在 read_cb 里做线性换算：x = touch_x \* screen_w / touch_w，y 同理。

**验证**：给按钮绑定 LV_EVENT_CLICKED 回调，触摸点击按钮能触发事件。若点按错位 → 检查坐标换算；若点击无反应 → 检查 PRESSED / RELEASED 状态是否正常上报。

## STM32CubeIDE下移植

课件仅提到“两种环境下的 LVGL 移植”（Keil 与 STM32CubeIDE），以下为补充：CubeIDE 下流程与 MDK 完全同构，只是工程操作不同：

- CubeIDE 会自动把目录下的 .c 纳入构建（无需手动分组）；在项目属性 C/C++ Build → Settings → Include paths 添加 lvgl 相关头文件路径

## lv_conf.h介绍

课件无正文，以下为补充：lv_conf.h 是 LVGL 的唯一总配置，控制资源占用与功能范围。常用开关：

| 配置项 | 作用 |
|-|-|
| LV_COLOR_DEPTH | 颜色深度 16/32 位，决定每像素字节数与显存占用 |
| LV_HOR_RES_MAX / LV_VER_RES_MAX | 最大分辨率，决定绘制缓冲数组大小 |
| LV_MEM_SIZE | LVGL 内部内存池大小（动态分配的上限） |
| LV_USE_FLEX / LV_USE_GRID | 布局功能开关（第 17 章） |
| LV_USE\_\*（各部件） | 各部件/功能开关，关掉即不编译、省 Flash/RAM（18.2 裁剪） |
| LV_TICK_CUSTOM | 使用外部 tick 源（如 SysTick），代替 lv_tick_inc 手动喂 |

**启用方法**（课件原文）：lv_conf_template.h 改名为 lv_conf.h，打开文件把顶部条件编译 #if 0 改成 #if 1，配置即生效。

**推荐起步配置**（补充）：LV_COLOR_DEPTH 选 16（与 LCD 一致，显存减半）；LV_HOR_RES_MAX / LV_VER_RES_MAX 填屏幕实际分辨率；LV_MEM_SIZE 从 32KB 起步，跑复杂界面再加大；LV_USE_FLEX / LV_USE_GRID 等用不到就先关。改配置后需重新编译。

**裁剪与调优顺序**（补充）：先保证能跑 → 逐个打开需要的部件 → Flash / RAM 超了再回头关，不要一次性全开。

**lv_port_disp.c**（显示驱动注册，对应 18.5）：

```c
/* lv_port_disp.c —— 显示驱动移植 */
#include "lvgl.h"
#include "lcd.h"      /* 提供 LCD_Init / LCD_Fill */

static lv_disp_draw_buf_t draw_buf;
static lv_color_t buf[LV_HOR_RES_MAX * 40];   /* 缓冲1：40 行，够跑 */
static lv_color_t buf2[LV_HOR_RES_MAX * 40];  /* 缓冲2：想要双缓冲就留着，不要可删 */

static void my_flush_cb(lv_disp_drv_t *drv, const lv_area_t *area, lv_color_t *color_p)
{
    LCD_Fill(area->x1, area->y1, area->x2, area->y2, (uint16_t *)color_p);
    lv_disp_flush_ready(drv);                 /* 必须调用：告诉 LVGL 这块刷完了 */
}

void lv_port_disp_init(void)
{
    LCD_Init();                               /* 先让屏幕亮起来 */

    lv_disp_draw_buf_init(&draw_buf, buf, buf2, LV_HOR_RES_MAX * 40);

    static lv_disp_drv_t disp_drv;
    lv_disp_drv_init(&disp_drv);
    disp_drv.hor_res = LV_HOR_RES_MAX;        /* 屏幕宽（来自 lv_conf.h） */
    disp_drv.ver_res = LV_VER_RES_MAX;        /* 屏幕高 */
    disp_drv.flush_cb = my_flush_cb;
    disp_drv.draw_buf = &draw_buf;
    lv_disp_drv_register(&disp_drv);
}
```

**lv_port_indev.c**（触摸驱动注册，对应 18.7；坐标换算按你的触摸芯片分辨率改）：

```c
/* lv_port_indev.c —— 触摸驱动移植 */
#include "lvgl.h"
#include "touch.h"   /* 提供 tp_scan(&x, &y) */

static void my_touchpad_read(lv_indev_drv_t *drv, lv_indev_data_t *data)
{
    uint16_t x = 0, y = 0;
    if (tp_scan(&x, &y)) {                    /* 有触摸 */
        /* 坐标换算：触摸原始分辨率 → 屏幕分辨率（4095 按实际触摸芯片改） */
        x = x * LV_HOR_RES_MAX / 4095;
        y = y * LV_VER_RES_MAX / 4095;
        data->point.x = x;
        data->point.y = y;
        data->state = LV_INDEV_STATE_PRESSED; /* 按下 */
    } else {
        data->state = LV_INDEV_STATE_RELEASED;/* 松开 */
    }
}

void lv_port_indev_init(void)
{
    static lv_indev_drv_t indev_drv;
    lv_indev_drv_init(&indev_drv);
    indev_drv.type = LV_INDEV_TYPE_POINTER;   /* 指针型：触摸屏 */
    indev_drv.read_cb = my_touchpad_read;
    lv_indev_drv_register(&indev_drv);
}
```

**main.c**（关键片段；顺序不要变）：

```c
/* main.c 关键片段 */
#include "lvgl.h"
extern void lv_port_disp_init(void);
extern void lv_port_indev_init(void);

static void btn_event_cb(lv_event_t *e);      /* 前置声明 */

int main(void)
{
    HAL_Init();
    SystemClock_Config();   /* CubeMX 生成：168MHz */
    MX_GPIO_Init();
    MX_FSMC_Init();         /* LCD 并口 */
    MX_I2C1_Init();         /* 触摸 */
    MX_USART6_UART_Init();  /* 调试串口 */

    lv_init();              /* 1. 初始化 LVGL */
    lv_port_disp_init();    /* 2. 注册显示驱动 */
    lv_port_indev_init();   /* 3. 注册触摸驱动 */

    lv_obj_t *btn = lv_btn_create(lv_scr_act());          /* 4. 创建界面 */
    lv_obj_set_pos(btn, 100, 100);
    lv_obj_set_size(btn, 120, 50);
    lv_obj_t *label = lv_label_create(btn);
    lv_label_set_text(label, "Hello LVGL");
    lv_obj_center(label);
    lv_obj_add_event_cb(btn, btn_event_cb, LV_EVENT_CLICKED, NULL);

    while (1) {
        lv_timer_handler(); /* 5. 处理事件/动画/重绘（必须周期调用） */
        HAL_Delay(5);
    }
}

static void btn_event_cb(lv_event_t *e)
{
    static uint8_t cnt = 0;
    cnt++;
    printf("btn clicked: %d\r\n", cnt);   /* 串口观察，需要先做 18.6 的 fputc 重定向 */
}
```

| 现象 | 原因 | 处理 |
|-|-|-|
| 编译报 lv_conf.h 找不到 | Include Paths 漏了 lvgl 目录 | 把 Middlewares/lvgl 及其子目录都加进 Include Paths |

## 动画_1

源码（01_动画.c，DEMO_3）演示的是**动画时间轴 lv_anim_timeline**：把多个 lv_anim 按“开始时间”排成一条时间线，一次启动、按序播放。

**1、先造 3 个普通动画**（和前几章一样：init → var → values → exec_cb → time）：

```c
lv_anim_t a;
lv_anim_init(&a);
lv_anim_set_var(&a, obj1);
lv_anim_set_values(&a, 50, 200);          /* 高度从 50 到 200 */
lv_anim_set_exec_cb(&a, anim_set_height); /* 执行回调：lv_obj_set_height(var, val) */
lv_anim_set_time(&a, 1000);
```

**2、创建时间轴并添加动画，指定每个动画的开始时间**（毫秒）：

```c
anim_timeline = lv_anim_timeline_create();
lv_anim_timeline_add(anim_timeline, 4000, &a);  /* a 在第 4000ms 开始播（1000ms 播完） */
lv_anim_timeline_add(anim_timeline, 400, &b);   /* b 在第 400ms 开始播（300ms 播完） */
lv_anim_timeline_add(anim_timeline, 1000, &c);  /* c 在第 1000ms 开始播 */
printf("total time = %d\n", lv_anim_timeline_get_playtime(anim_timeline)); /* 总时长 */
```

**3、控制接口**：

- `lv_anim_timeline_start(timeline);`——启动整条时间轴
- `lv_anim_timeline_set_progress(timeline, 33000);`——直接跳到某个进度（demo 里 btn1 点击即跳转）
- `lv_anim_timeline_del(timeline);`——删除时间轴（demo 里 btn2 点击删除）
- `lv_anim_timeline_set_reverse(timeline, true);`——整体反向播放（demo 中注释未启用）

**为什么演示里时间故意不连续**（补充）：4000/400/1000 毫秒展示了“交错编排”能力——时间轴不要求动画按顺序连播，可以随意指定每个动作的起始时刻，适合做多部件组合动效（先弹窗、再列表、再按钮逐个出现）。

**怎么判断**：多个部件要“先后/交错”动 → 时间轴；单个对象动 → 直接 lv_anim_start（见 19.2）。

## 动画_2

源码（02_动画.c）DEMO_1 展示**单个动画的完整参数**，DEMO_2 展示**动画驱动进度条**。

**1、一个动画的完整生命周期**（DEMO_1，动画在 obj1 上从 start_pos 平移到 x=400）：

```c
lv_anim_t a;
lv_anim_init(&a);
lv_anim_set_var(&a, obj1);                    /* 作用对象 */
lv_anim_set_values(&a, start_pos, 400);        /* 起始值 → 结束值 */
lv_anim_set_time(&a, 1000);                    /* 正向播放时长 1000ms */
lv_anim_set_delay(&a, 200);                    /* 启动前延迟 200ms */
lv_anim_set_path_cb(&a, lv_anim_path_linear);  /* 变化曲线：线性（还有 ease_in/out、bounce 等） */
lv_anim_set_playback_time(&a, 1000);           /* 反向播放时长（回放） */
lv_anim_set_playback_delay(&a, 500);           /* 反向前停顿 500ms */
lv_anim_set_repeat_count(&a, LV_ANIM_REPEAT_INFINITE); /* 重复次数：无限循环 */
lv_anim_set_repeat_delay(&a, 1000);            /* 每轮之间停顿 1000ms */
lv_anim_set_start_cb(&a, start_cb);            /* 动画开始时回调（demo 打印 start） */
lv_anim_set_exec_cb(&a, anim_pos_x);           /* 每帧执行：lv_obj_set_x(var, val) */
lv_anim_set_deleted_cb(&a, deleted_cb);        /* 动画被删除时回调（demo 打印 has del） */
lv_anim_start(&a);
```

**时间线顺序**（补充）：delay（延迟）→ 正向播放 time → playback_delay → 反向 playback_time → repeat_delay → 下一轮……repeat_count 控制轮数，LV_ANIM_REPEAT_INFINITE 表示无限循环。

**2、同一个动画对象复用**（demo 原样）：start 之后又 `lv_anim_set_values(&a, 50, 200); lv_anim_set_exec_cb(&a, anim_set_height); lv_anim_start(&a);`——改 values 和 exec_cb 后再 start，同一结构体可以另开一段新动画。

**3、动画驱动进度条**（DEMO_2）：动画的执行回调里调 `lv_bar_set_value(var, val, LV_ANIM_ON);`，让动画数值（-20→100，3000ms）驱动 bar 指示器增长；bar 指示器配了红→蓝渐变（bg_grad_dir / bg_grad_color，见第 8 章）。

**4、工具函数**（demo 注释）：`lv_anim_speed_to_time(speed, start, end);`——由“速度”反推动画时长，如 lv_anim_speed_to_time(20, 0, 100) 表示以 20px/秒 走 0→100 需要多久。

**怎么判断**：想让数值随时间平滑变化（位置、尺寸、进度、颜色）都可以用 lv_anim + 自定义 exec_cb 实现；曲线选 linear 之外还有 ease 系，想有“缓动感”就换 path_cb。

## 定时器

源码（03_定时器.c，TIMER）演示 LVGL 定时器 lv_timer：周期调用回调，用于轮询、闪烁、超时等场景。

```c
timer1 = lv_timer_create(timer1_cb, 500, NULL);
/* 回调签名：void timer1_cb(lv_timer_t *timer) */
/* 参数：回调函数、周期 500ms、user_data（这里 NULL） */
```

**暂停 / 恢复 / 重置**（demo 用按钮切换）：

```c
lv_timer_pause(timer1);   /* 暂停：不再触发，但保留计数状态 */
lv_timer_resume(timer1);  /* 恢复：从暂停处继续 */
lv_timer_reset(timer1);   /* 重置：重新从 0 计周期（demo 里另一个定时器回调中调用） */
```

**demo 拆解**：按钮加 LV_OBJ_FLAG_CHECKABLE（可选中），点击回调里 `lv_obj_has_state(target, LV_STATE_CHECKED)` 判断按钮是否处于选中态——选中则暂停 timer1，取消选中则恢复，用同一个按钮做开关。

**其它接口**（demo 中注释掉的部分）：

- `lv_timer_create_basic();`——创建默认周期（LV_DEF_REFR_PERIOD）的定时器，再用 lv_timer_set_cb / lv_timer_set_period 改
- `lv_timer_set_period(timer, 300);`——改周期；`lv_timer_set_repeat_count(timer, 0);`——设置重复次数（0=不限制）
- `lv_async_call(async_call_cb, NULL);`——异步调用：不是定时器，而是“下次事件循环执行一次”，适合在回调里改对象后想安全推迟操作
- `lv_timer_ready(timer);`——让定时器在下一次事件循环立即执行（不等满周期）

**怎么判断**：周期轮询（读传感器）、让对象闪烁/呼吸 → lv_timer；只想延迟执行一次 → lv_async_call；注意 lv_timer 的回调里不要做耗时操作，否则会拖慢 lv_timer_handler 的整个事件循环。

# LVGL本质串讲与体系补全

前面 19 章把 LVGL 的各部分学完了，本章把它们**串成一条主线讲本质**：LVGL 到底是什么、一帧画面怎么产生、三大主线（对象/样式/事件）如何贯穿全部部件，再补上文档缺失的关键知识（样式优先级、事件设计、内存性能、中文字体、版本差异与常见坑）。

## 本质：一个“对象树 + 事件循环”的重绘型 GUI 框架

**一句话本质**：LVGL 是跑在 MCU/MPU 上的**“对象树 + 事件循环”**嵌入式 GUI 框架——你用对象（lv_obj_t）搭建界面，改动对象的属性/样式后，框架在 lv_timer_handler 里检测到变化，把需要重绘的区域画进绘制缓冲，再交给显示驱动刷到屏幕。

**三个关键词展开**：

- **对象树**：一切皆对象（lv_obj_t）。根是活动屏幕 lv_scr_act()，子对象相对父对象定位，删除父对象会连带删除所有子对象（第 2 章父子三规则）。
- **事件循环**：不是“死循环逐帧画屏”，而是**有变化才重绘**（事件驱动 + 脏区域刷新）——这决定了它能在低端 MCU 上跑。
- **硬件抽象层**：LVGL 不直接碰硬件，只通过显示驱动（disp_drv）和输入设备驱动（indev_drv）的回调与硬件解耦——这就是第 18 章“移植”的本质：把 LVGL 的画图能力接上你的屏，把触摸接上你的输入。

**为什么这样设计**（原理）：MCU 的 CPU 和内存都有限，逐帧全屏重绘（像 PC 游戏那样）扛不住，所以用“脏矩形局部刷新”；GUI 状态复杂，所以用对象模型管理界面、用事件回调处理交互——这是嵌入式 GUI 与桌面 GUI 最大的不同：**省着画、按需画**。

## 一帧画面是怎么产生的（运转链路）

把前面所有章节串起来，一次交互到最终显示的全过程：

| 环节 | 谁负责 | 对应章节 |
|-|-|-|
| ① 触摸/按键产生输入 | indev read_cb 读坐标（触摸芯片） | 18.6-18.7 |
| ② 命中对象并发事件 | LVGL 按坐标找对象，触发 LV_EVENT\_\* | 第 5 章 |
| ③ 回调修改对象属性/样式/文本 | 你的代码（lv_obj_add_event_cb 注册） | 第 3-8 章 |
| ④ 对象被标记“需要重绘” | LVGL 内部（属性变化自动标记） | — |
| ⑤ 处理动画与定时器 | lv_timer_handler（动画按 tick 推进、定时器回调） | 第 19 章 |
| ⑥ 绘制脏区域到绘制缓冲 | LVGL 绘制引擎（draw） | 18.1/18.5 |
| ⑦ flush_cb 把缓冲写给 LCD | 你的 LCD 驱动（LCD_Fill） | 18.3/18.5 |

**两个“心跳”为什么必须**：lv_tick_inc(1) 每毫秒给 LVGL 喂时间（动画/长按计时都靠它）；lv_timer_handler() 周期性执行，一切“看不见的运转”（动画推进、定时器回调、重绘检查）都在它里面完成——忘了调它，界面就“冻住”。

**动画为什么能动**：lv_anim 在 timer_handler 里按 tick 时间推进，每帧调用 exec_cb 修改对象属性（如 lv_obj_set_x），属性变化自动标记重绘，于是屏幕上一帧帧动起来——动画的本质是“定时改属性 + 触发重绘”。

## 贯穿全书的三大主线

第 9-16 章那么多“部件”，本质都是**“基础对象 + 预设样式 + 预设事件行为”的组合**。吃透三条主线，任何新部件你都能自己看懂：

- **主线一：对象**——创建（lv_xx_create）→ 设大小/位置/对齐（第 3 章）→ 放子对象 → 删除。每个部件都有一套自己的“专属 API”（lv_slider_set_value 等），其实内部还是改对象属性。
- **主线二：样式**——用样式属性描述“怎么画”（第 6-8 章），用“状态 | 部分”定位画哪里（第 4 章）。部件外观差异 = 不同样式属性组合。
- **主线三：事件**——交互行为都通过事件回调实现（第 5 章），部件只是把常用事件预绑好了（如 btnmatrix 的 VALUE_CHANGED）。

**各章在体系中的位置**：第 1-2 章搭环境、建立“对象树”世界观；第 3-8 章是三大主线的方法论；第 9-16 章是“部件库”——全是方法论的实例；第 17 章布局是对象树的自动化排列；第 18 章移植是接硬件；第 19 章动效是给对象加时间维度。

## 样式系统的本质与优先级（补全）

样式不是“把值写死到对象上”，而是**一份“按状态查表、按部分应用”的绘制说明**：

- **状态**（LV_STATE\_\*）：同一属性在不同状态下可有不同值（如按下变亮、禁用变灰）——UI 反馈的本质就是“状态切换 → 样式表切换”。
- **部分**（LV_PART\_\*）：一个部件由多个可分别绘制的部分构成（slider 的 MAIN/INDICATOR/KNOB），样式按部分分别设置。
- **组合**：LV_STATE_DEFAULT | LV_PART_INDICATOR 表示“默认状态、指示器部分”的样式——这是全文最常用的写法。

**样式来源与优先级**（补充，前面章节未系统讲）：同一个属性可能有多个来源，取优先级最高的：

| 优先级（高→低） | 来源 | 说明 |
|-|-|-|
| 1 | 对象自身 local 样式 | lv_obj_set_style\_\* 直接设的 |
| 2 | 父对象继承样式 | 文本类属性（颜色/字体）可被子对象继承 |
| 3 | 主题（lv_theme） | 全局默认外观，换肤机制 |

**判断**：想单独改一个对象 → local 样式；想统一一批同款外观 → 定义共享样式变量（注意：样式变量必须全局/静态，不能是局部变量，见第 4 章）；想整套换肤 → 改主题。

## 事件系统的设计哲学（补全）

**为什么回调签名是 (lv_event_t \*e) 而不直接传对象**：解耦——同一个回调函数可以绑定多个对象，回调里用 lv_event_get_target(e) 区分是谁触发的；lv_event_get_user_data(e) 取注册时传入的自定义数据（如按钮 id）。这就是第 5 章 get_target/user_data 的由来。

**事件不会自动冒泡**（重要补充）：LVGL（v8）的事件只发给**注册了回调的那个对象**，父对象不会自动收到子对象的事件（和网页 DOM 的事件冒泡不同）。想让父容器统一处理子项点击：给每个子项注册同一个回调，或对容器用 LV_EVENT_ALL 监听。

**回调里删对象的坑**：在回调里直接 lv_obj_del 当前正在处理事件的对象可能崩溃——LVGL 还在用这个对象。安全做法：lv_obj_del_delayed（延迟到下一帧删）或 lv_async_call 推迟。

**最常用的信号**：LV_EVENT_VALUE_CHANGED——“值变了”，slider/textarea/btnmatrix/dropdown 等所有“有值”的部件都用它通知你，是回调里最常监听的事件。

## 内存、生命周期与性能（补全）

- **内存池**：LVGL 用内部内存池（lv_conf.h 的 LV_MEM_SIZE 配置），对象、样式、字体都从池里分配；lv_mem_monitor() 可查看使用量与碎片，调试必备。
- **生命周期**：lv_obj_create 创建 → 使用 → lv_obj_del 删除（连带删全部子对象）；lv_obj_clean 只删子对象、保留自身；lv_obj_del_delayed 延迟删除（事件回调里用）。
- **性能回顾**（串起 18.1 优化四招）：绘制缓冲越大/双缓冲越快；LV_COLOR_DEPTH 越低越省内存；界面动得越少（脏区域越小）越快；大图缩放旋转最贵，能少用就少用；关闭不用的 LV_USE\_\* 裁剪体积。
- **排查套路**：画面不动先查两个心跳（tick/timer_handler）；闪烁/撕裂查缓冲与刷新；内存不足查 LV_MEM_SIZE 与内存泄漏（创建了没删）。

## 中文与字体方案（补全）

**为什么中文字体“大”**：一个汉字字形 = 一张小位图，常用汉字几千个 × 每个字形占内存，整套中文字体动辄几百 KB——嵌入式里不能像 PC 一样直接全量加载。第 9 章“中文字体三步骤”的底层逻辑就是**“只加载用得到的字”**：

- 用 LVGL 官方字体转换工具（font converter / lv_font_conv）把 ttf 转成 C 数组，**只勾选用到的字符**（子集化）
- LV_FONT_DECLARE 声明、lv_obj_set_style_text_font 应用（第 9 章步骤）
- 图标字符不用转：LV_SYMBOL\_\* 已内置

**判断**：界面固定几十个字 → 子集字体（首选）；需要动态输入任意汉字 → 全量字体或外置存储加载，同时注意内存占用；只要图标 → 直接用 LV_SYMBOL。

## 版本与常见坑（补全）

**本课程基于 LVGL 8.3.x**（特征 API：lv_anim_set_time、lv_obj_set_style_pad_all、lv_obj_align）。若你遇到 LVGL 9.x 的资料，API 名有变化，对照查官方文档/头文件即可，常见差异：

| v8（本课程） | v9 |
|-|-|
| lv_anim_set_time / set_playback_time | lv_anim_set_duration / set_playback_duration |
| lv_anim_timeline\_\*（8.3 新增） | 保留，接口基本一致 |
| lv_obj_set_style_pad_all(obj, v, sel) | 接口保留，选择器类型有变化 |
| lv_obj_add_event_cb / get_target | 保留，事件机制基本一致 |

**常见坑清单**（来自前 19 章踩过的点）：

- 样式变量写成局部变量 → 函数返回后指针失效，界面错乱（第 4 章）
- 忘调 lv_tick_inc / lv_timer_handler → 画面完全不动（第 18 章）
- lv_conf.h 分辨率与实际屏不符 → 缓冲越界、花屏
- 图片想缩放旋转但颜色格式不是 TRUE_COLOR 系 → 无效（第 13 章）
- 回调里直接删正在处理事件的对象 → 崩溃，用 del_delayed
- 文本/选项数组忘记 NULL 结尾或 \n 换行格式错 → 内容显示异常（第 12/13 章）

## 学习路径建议

你现在已经具备“看懂任何 LVGL 代码”的能力。继续深入的建议顺序：

1. **读官方 examples**：lvgl 源码 examples/ 目录每个部件都有 demo，现在你能直接看懂并改造
2. **做综合小项目**：把学过的部件组合起来（如：时钟界面 = 标签 + 定时器 + 动画；设置页 = 列表 + 开关 + 下拉框），这是把“知识点”变“能力”的关键一步
3. **自定义外观**：用 lv_theme 定制全局风格，用样式属性调细节——这就是“换肤”
4. **深入 draw 层**（可选）：lv_obj 上挂自定义绘制回调（LV_EVENT_DRAW_MAIN），可以画任意图形，做仪表、图表类控件
5. **保持这套学习法**：遇到新 API 先看头文件注释与官方示例，再问“它是什么、为什么、什么时候用”——和这份笔记的组织方式一致

## 四、宏体系对照

LVGL 大量使用“LV\_ + 类别 + 含义”的宏，类别前缀决定用途。常用类别如下：

### 1. 事件：LV_EVENT\_\*

| 宏 | 含义 | 触发场景 |
|-|-|-|
| LV_EVENT_PRESSED | 按下 | 对象被按下 |
| LV_EVENT_RELEASED | 释放 | 按下后松开 |
| LV_EVENT_CLICKED | 点击 | 按下并释放，完成一次点击 |
| LV_EVENT_VALUE_CHANGED | 值改变 | 部件值发生变化（滑块/开关等） |
| LV_EVENT_INSERT | 插入文本 | 文本类部件插入字符 |
| LV_EVENT_READY | 就绪 | 操作完成（如键盘确认输入） |
| LV_EVENT_CANCEL | 取消 | 操作取消 |
| LV_EVENT_DELETE | 删除 | 对象删除前触发 |
| LV_EVENT_FOCUSED | 获得焦点 | 键盘/编码器聚焦到对象 |
| LV_EVENT_DEFOCUSED | 失去焦点 | 对象失焦 |
| LV_EVENT_DRAW_MAIN_BEGIN | 主绘制开始 | 绘制阶段开始（可用于加特效） |
| LV_EVENT_ALL | 全部 | 监听所有事件 |
| LV_EVENT_USER | 用户自定义 | 自定义事件从此值开始 |

### 2. 状态：LV_STATE\_\*

| 宏 | 含义 | 说明 |
|-|-|-|
| LV_STATE_DEFAULT | 默认 | 对象初始状态 |
| LV_STATE_CHECKED | 选中 | 开关/复选框被选中 |
| LV_STATE_PRESSED | 按下 | 正在被按压 |
| LV_STATE_FOCUSED | 聚焦 | 通过键盘/编码器获得焦点 |
| LV_STATE_FOCUS_KEY | 键盘聚焦 | 由键盘聚焦产生 |
| LV_STATE_EDITED | 编辑中 | 文本编辑状态 |
| LV_STATE_HOVERED | 悬停 | 鼠标悬停在对象上 |
| LV_STATE_SCROLLED | 滚动中 | 对象正在滚动 |
| LV_STATE_DISABLED | 禁用 | 不可交互 |

### 3. 部件组成：LV_PART\_\*（样式作用在部件的哪一块）

| 宏 | 含义 | 说明 |
|-|-|-|
| LV_PART_MAIN | 主体 | 背景、边框等主要区域 |
| LV_PART_INDICATOR | 指示器 | 进度条/滑动条的填充部分 |
| LV_PART_KNOB | 旋钮 | 滑动条/圆弧可拖动的手柄 |
| LV_PART_SCROLLBAR | 滚动条 | 滚动条本身 |
| LV_PART_SELECTED | 选中项 | 列表/下拉框中选中的条目 |
| LV_PART_ITEMS | 条目 | 按钮矩阵、表格中的条目 |
| LV_PART_CURSOR | 光标 | 文本区域的光标 |
| LV_PART_TICKS | 刻度 | 圆弧等部件的刻度 |
| LV_PART_TEXTAREA_PLACEHOLDER | 占位符 | 文本区域的提示文字 |
| LV_PART_CUSTOM_FIRST | 自定义起点 | 自定义部件的第一个部分 |
| LV_PART_ANY | 任意 | 任意部分 |

### 4. 对象标志：LV_OBJ_FLAG\_\*（对象的行为开关）

| 宏 | 含义 | 说明 |
|-|-|-|
| LV_OBJ_FLAG_CHECKABLE | 可选中 | 可切换选中状态（如开关式按钮） |
| LV_OBJ_FLAG_CLICKABLE | 可点击 | 可响应点击 |
| LV_OBJ_FLAG_HIDDEN | 隐藏 | 隐藏对象 |
| LV_OBJ_FLAG_SCROLLABLE | 可滚动 | 内容可滚动 |
| LV_OBJ_FLAG_SNAPPABLE | 可吸附 | 滚动时可吸附对齐 |
| LV_OBJ_FLAG_CLICK_FOCUSABLE | 点击可聚焦 | 点击后获得焦点 |
| LV_OBJ_FLAG_PRESS_LOCK | 按下锁定 | 按下后滑动不退出按下态 |
| LV_OBJ_FLAG_SCROLL_ELASTIC | 滚动回弹 | 滚动有回弹效果 |
| LV_OBJ_FLAG_SCROLL_MOMENTUM | 滚动惯性 | 松手后继续滑行 |
| LV_OBJ_FLAG_ADV_HITTEST | 精确命中 | 按实际形状判断是否点到 |
