# GCC编译

```bash
gcc -c main.c -o main.o
gcc main.o utils.o -o app

```

| 选项 | 作用 |
|-|-|
| `-o` | 指定输出文件名 |
| `-c` | 只编译不链接 |
| `-I` | 指定头文件路径 |
| `-g` | 生成调试信息 |

# Makefile

```makefile
app: main.o utils.o
	gcc main.o utils.o -o app

main.o: main.c
	gcc -c main.c

clean:
	rm *.o app

```

# 文件IO编程

```c
int fd = open("test.txt", O_RDWR | O_CREAT, 0644);
write(fd, "hello", 5);
read(fd, buf, 5);
close(fd);

```

# 进程与线程

|  | 进程 | 线程 |
|-|-|-|
| 内存 | 独立地址空间 | 共享地址空间 |
| 开销 | 大 | 小 |
| 通信 | 需IPC机制 | 直接共享变量 |

# 网络编程

```c
int sockfd = socket(AF_INET, SOCK_STREAM, 0);
bind(sockfd, ...);
listen(sockfd, 10);
int clientfd = accept(sockfd, ...);
read(clientfd, buf, 1024);

```
