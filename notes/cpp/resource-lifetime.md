# C++ 怎样用对象管理 SPI 片选

一次 SPI 事务开始时拉低片选，结束时释放片选。函数中如果有配置错误、发送超时等提前返回路径，每条路径都需要交还片选。可以让一个局部对象负责这项工作，这种做法属于 RAII。

## 顺着一次事务走

1. 事务开始前构造一个局部对象，由它拉低片选线。
2. 在对象的作用域里执行收发。收发失败时，调用方按驱动接口处理错误。
3. 离开作用域时执行析构，由对象释放片选线。显式 `return` 也会结束作用域。

## 看清所有权

在简单的片选保护类里，复制或移动局部对象会让片选归属变得含糊，可以让类禁止复制和移动。析构负责把 GPIO 恢复为释放状态。SPI 总线如果还被多个任务共享，要另有总线互斥的约定。

如果使用中断或 DMA 异步传输，对象要活到真实传输完成或错误恢复结束。在启动 DMA 后立即离开作用域会过早释放片选。
