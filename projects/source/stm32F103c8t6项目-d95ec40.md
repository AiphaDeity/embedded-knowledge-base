# 基础点灯项目

1. 打开STM32CubeMX，选择对应的芯片
2. 设置Project Manager中的项目名称、项目路径、堆栈大小、官方的固件库版本。
3. 选择CubeIDE工具
4. 点击GENERATE CODE生成代码，关闭CobeMX
5. 打开STMCubeIDE，选择文件File-- Import-- General-- Existing Projects into Workspace --select root directory选择项目文件夹 --选择完成
6. 打开汇编文件，找到main之前
7. 使能GPIO控制器时钟，打开参考手册找到存储器和总线架构中存储器映射，找到要控制的GPIO属于的总线
8. 找到复位和时钟控制（RCC），找到外设时钟使能寄存器
