# Stm32中英文对照手册

[飞书原文](https://hcn4ticlccda.feishu.cn/docx/WkO7dzltWo6RVtx8AC5cblcGnch)

本手册以 STM32F407 参考手册（RM0090）为模板，汇总参考手册中常见缩写的中英文对照，按类别整理，便于快速查阅与背诵。每张表列为：缩写、中文、英文全称。个别缩写在不同 STM32 系列中含义略有差异，使用时以对应系列手册为准。


::: tip

背诵建议：先攻克「一、常用核心术语」，再按模块逐章背诵；查阅时可直接用搜索功能（Ctrl+F）在本手册内查找缩写。

:::
