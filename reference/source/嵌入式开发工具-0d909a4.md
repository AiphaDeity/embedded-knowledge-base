# CubeMX+CubeIDE

## 开发详细流程

适合 STM32 全系列开发，官方一体化方案，工程配置、编译、调试在同一环境完成。

1. **安装环境**：安装 STM32CubeIDE（较新版本内置 CubeMX 插件）与 ST-LINK 驱动。
2. **新建工程**：File → New → STM32 Project，用 MCU Selector 选择芯片型号，或用 Board Selector 选择开发板。
3. **图形化配置**：Pinout 页分配引脚（GPIO、UART、I2C、SPI 等）；Clock 页配置外部晶振与 PLL 得到系统时钟；Peripherals 页设置外设参数（如波特率、模式）。
4. **生成代码**：Project Manager 设置工程名、工具链与生成选项（勾选“Keep user code when regenerating”），点击 GENERATE CODE 生成初始化代码（main.c、HAL 初始化、启动文件等）。
5. **编写应用代码**：在 main.c 的 USER CODE BEGIN/END 注释区内写业务逻辑，重新生成代码时不会被覆盖。
6. **编译**：点击 Build 编译（arm-none-eabi-gcc），报错在 Problems 窗口定位。
7. **下载与调试**：ST-LINK 接 SWD 口，Run → Debug 一键下载并进入调试，支持断点、寄存器、外设寄存器视图与变量实时值。


::: tip

关键习惯：业务代码只写在 USER CODE 区域内，这是 CubeMX 重新生成代码而不被覆盖的前提。

:::


# CubeMX+VS Code

## 开发详细流程

适合习惯 VS Code 生态、想要轻量 IDE 与灵活扩展的开发者。

1. **安装工具链**：VS Code 及扩展（C/C++、CMake Tools、Cortex-Debug，官方 STM32 VS Code Extension 最省事）+ 编译调试工具（STM32CubeCLT，或自装 arm-none-eabi-gcc 与 OpenOCD）。
2. **CubeMX 配置**：引脚、时钟、外设配置与 CubeIDE 方案相同。
3. **生成工程**：Project Manager 中 Toolchain/IDE 选择 Makefile（新版也可选 CMake），点击 GENERATE CODE 生成带 Makefile/CMakeLists 的工程。
4. **VS Code 打开工程**：配置编译任务（.vscode/tasks.json）、头文件路径与宏定义（c_cpp_properties.json）；官方扩展会自动识别 CubeMX 工程并完成配置。
5. **编写用户代码**：同样只在 USER CODE 区写应用逻辑。
6. **编译**：终端执行 make 或 CMake Build，或扩展快捷键 F7。
7. **烧录调试**：官方扩展一键下载调试（F5，自动识别 ST-LINK/J-Link）；手动方案用 Cortex-Debug 与 OpenOCD 配置 launch.json，或用 STM32CubeProgrammer CLI 单独烧录。


::: tip

关键一步：CubeMX 工具链必须选 Makefile 或 CMake，否则 VS Code 无法直接构建该工程。

:::


# Keil uVision5(Keil5)

## 开发详细流程

经典 ARM Cortex-M 开发环境，教程与资料最丰富，常用于教材教学与老项目维护。

1. **安装**：安装 MDK-ARM（uVision5）；用 Pack Installer 安装芯片器件包（如 STM32F1xx_DFP）与 CMSIS，没有器件包就选不到芯片。
2. **新建工程**：Project → New μVision Project → 在 Select Device 中选择芯片型号（如 STM32F103C8）。
3. **管理运行环境**：Manage Run-Time Environment 勾选 CMSIS Core、Device Startup、HAL/标准库等组件；也可先用 CubeMX 生成 Keil 工程再打开。
4. **Target 配置**（魔术棒）：Target 页设晶振与微库；C/C++ 页填宏定义（如 STM32F103xB）与 Include 路径；Output 页勾选 Create HEX File（烧录需要）。
5. **调试器配置**：Debug 页选择 ST-Link Debugger（或 J-Link）→ Settings：端口选 SW，Flash Download 页添加芯片编程算法并勾选 Reset and Run。
6. **编写与编译**：将 main.c 等加入 Source Group，Build（F7）编译并修复错误。
7. **下载调试**：Load（F8）把程序烧进 Flash；Ctrl+F5 进入调试：断点、Watch、寄存器、内存、外设窗口与逻辑分析仪。

# MounRiver Studio Ⅱ(MRS2)

## 开发详细流程

WCH 沁恒 RISC-V 芯片（CH32V003/V103/V203/V307、CH32X035 等）的官方 IDE，常用于国产替代 STM32 方案。

1. **安装**：从沁恒官网下载 MRS2（基于 VS Code 框架，内置 RISC-V GCC 交叉工具链），并安装 WCH-Link 驱动。
2. **新建工程**：File → New → MRS Project → 选择芯片型号（如 CH32V307）→ Finish；内置裸机与 RTOS 模板，编译、下载、调试参数已配好，可一键建工程。
3. **编写代码**：使用沁恒外设库（如 ch32v30x 系列库），在模板的 main.c 中编写逻辑。
4. **编译**：点击 Build 编译，产物在 obj 目录；可在工程属性中调整优化等级、链接脚本（.ld）等。
5. **下载**：接 WCH-Link（SWD）点 Download 一键烧录；部分芯片可用 WCHISPTool 走串口/USB BOOT 的 ISP 方式烧录。
6. **调试**：进入 RISC-V 调试界面，支持断点、变量监控、内存、外设与反汇编窗口。

# 选型对比

| 工具链 | 芯片生态 | 上手难度 | 代码生成 | 调试器 | 适合场景 |
|-|-|-|-|-|-|
| CubeMX+CubeIDE | STM32 全系 | 低（图形化） | HAL 自动生成 | ST-LINK | 官方推荐、功能全、新手友好 |
| CubeMX+VS Code | STM32 全系 | 中（需配环境） | HAL + Makefile/CMake | ST-LINK/J-Link | 熟悉 VS Code、Git 协作、插件化工作流 |
| Keil uVision5 | ARM Cortex-M 通用 | 中低 | 启动文件+库手动搭 | ST-Link/J-Link/ULINK | 教材教学、老项目维护 |
| MounRiver Studio Ⅱ | WCH RISC-V CH32 | 低（模板一键） | 沁恒外设库+模板 | WCH-Link | CH32 国产替代、RISC-V 入门 |
